## 1. 五层框架

一个可用的精读工具要合五层，缺一层都不够：

1. **提取 + 效度评估**：抽出研究问题、假设、设计、对照、指标、统计与作者自述局限，再按设计匹配的检查表判断内部效度、外部效度、构念效度、统计结论效度与可复现性。
2. **第一性原理拆解**：去掉继承的表述，把主张拆到基本假设，逐个检验承重假设，再从 surviving 的部分重建。
3. **剃刀 / 简约性**：只在解释力相等时选假设最少的解释；奥卡姆是启发式 / 平局裁决，不是证明。
4. **逻辑链 / 论证图**：把前提 → 证据 → 结论画成显式树，找出隐藏共前提，标出最弱一环。
5. **分阶段读法 + 固定模板**：Keshav 三遍法是流程，SQ3R / Cornell 是笔记脚手架，A–H 模板是输出，保证两个人读同一份报告能产出可对照、可核查的记录。

最重要的一条设计原则：**“未报告 / 说不清”要明确记下来，并附页码 / 章节位置**。CASP、NeurIPS、CONSORT 都把“没报告”当作一个发现，而不是留白。

v2.0 在第 2 层（第一性原理）加入 §6A 的为什么链，在第 5 层模板里加入科学问题还原五问与科学价值四维 verdict；借鉴的现有工具与逐项借用清单见 §6B。

## 2. 三遍法（Keshav，2007）

- **第 1 遍（5–10 分钟）**：标题、摘要、引言、章节标题、结论、参考文献。回答五 C：Category（类型）、Context（背景）、Correctness（假设看起来成立吗）、Contributions（贡献）、Clarity（清晰度）。
- **第 2 遍（约 1 小时）**：认真读，跳过证明；仔细看图——坐标轴标对了吗？有没有误差棒，结论在统计上站得住吗？标出没读过的参考文献。
- **第 3 遍（轻量版）**：尝试“虚拟重实现”——按作者的假设重建工作，对照原文找出创新点、隐藏失败与假设。对前沿大模型报告，轻量版指：按所述方法重推关键表 / 图，或列出重实现需要什么。

## 3. 第一性原理：七步

1. 不带解决方案地重述问题 / 主张，先用作者原话，再去掉方案语言。
2. 列出所有假设，显式和隐式的都列；划出暗示约束的词（“必须”“不可能”“总是”“唯一办法”）。
3. 给每个假设分类：

| 类型 | 检验 | 做法 |
|---|---|---|
| 硬约束 | 违反会打破物理、数学或逻辑 | 接受为 ground truth |
| 软约束 | 基于政策、惯例、法规或习惯 | 挑战，它可以变 |
| 未验证 | 论文里没给证据 | 标出，不让结论悄悄建立在它上面 |

4. 画假设依赖图：有的假设依赖别的假设；根假设倒了，上面全塌，从底往上挑战。
5. 逐个检验 surviving 的假设：这篇论文里的证据是什么？什么实验 / 消融能打破它？如果它是错的，什么会变？
6. 从 surviving 的部分重建：“如果今天从零设计，会怎么做？”再把重建结论与论文结论对照，差距就是论文真正的（而非声称的）贡献。
7. 停止规则：问“为什么”到答案变基本为止，不是无尽追问；只用在承重主张上。v2.0 的操作化见 §6A：为什么链每层都要落到可检验的事实、承重假设或明确的“未回答”，不许用套话收尾。

AI 报告里常要 interrogate 的继承假设（合成，未核实为一手来源）：基准分高 = 能力强；基线调参公平；测试集没见过；效果随规模外推；人类评估就是 ground truth。

## 4. 剃刀：怎么用，边界在哪

- **奥卡姆剃刀**：“如无必要，勿增实体”。只在两个假设预测相同、覆盖数据相同时选假设少的那个；它是归纳启发式，不是逻辑证明，也不是“简单的一定对”。分两种简单：句法简单（基本原理少而简洁）与本体简单（假设的实体种类少），两者可以不一致。
- **Hitchens 剃刀**：无证据即可主张的，无证据即可驳回。报告里没给证据、实验或推导的主张，标“待证据驳回”，不用另行反驳。
- **Alder 剃刀 / 牛顿的火焰激光剑**：不能用实验或观察裁决的，不值得争论。把不可检验的主张（如对模型“理解”的断言且无操作化）放进“不可检验，先搁置”一类；这把剃刀本身也要谨慎用。
- **Hume 剃刀（因果充分性）**：原因必须足以产生效果。检查机制够不够大，能不能解释观测到的效应量。
- **Hume 的断头台（是–应当）**：描述性发现推不出规范性结论（“应该部署 / 监管 / 扩展”需要另加前提）。
- **Popper 可证伪性**：一个理论要算科学，必须能被可设想的观测反驳；为救理论而加的特设假设会降低可检验性，是弱点标记。
- **Sagan 标准**：非凡主张需要非凡证据，主张越强，证据门槛越高。
- **Hanlon 剃刀**：能用错误解释的，别归因于恶意；结果“好得离谱”时先查泄漏、bug、调参不对称。

未核实：AIC / BIC / MDL 作为奥卡姆的形式化版本只在二手来源核实；“爱因斯坦剃刀”等 listicle 剃刀未核实归属，不要引用为爱因斯坦原话。

## 5. 逻辑链 / 论证图：六步

1. 写出 contention（要建立的主张）。
2. 列出 reasons（直接支持主张的前提）。
3. 补出 co-premises（每个 reason 默默需要、否则撑不住结论的未明说假设，最弱处多半在这里）。
4. 加上最强的 objections（针对主张或具体 reason），以及论文给出的 rebuttals（如果有）。
5. 标出最弱一环：按承重程度 × 证据强度打分，高承重 × 低证据就是最弱一环。
6. 以树 / 图输出，不只是散文；每个节点附页码 / 章节。

找隐藏前提的办法：对每个 reason 写一句“这个 reason 能支持结论，当且仅当 ___”，把空填出来。常见断裂：范围跳跃（一个数据集 → “一般来说”）、层级跳跃（表现 → 能力 → 理解）、相关 → 因果、循环论证（结论的改述出现在前提里）。

记号建议：Argdown（开源，`[…]` 表陈述，`<…>` 表论证，`+` 支持 / `-` 反对）。有效结构不等于前提为真，图只显示结构，不显示真假。

## 6. 效度与检查表

四种效度（Campbell 传统）：

- **内部效度**：干预（而非混杂）是否造成了效应。ML 版威胁：数据泄漏、训练/测试污染、基线不对称、挑种子/挑 split、在测试集上调参、评估 harness 版本不同。
- **外部效度**：结果能推广到哪些人群 / 任务 / 分布 / 规模 / 部署条件，哪些不能。
- **构念效度**：指标 / 操作是否真的代表声称的理论构念（基准分到底量的是“推理”还是模式匹配 / 记忆）。
- **统计结论效度**：分析是否支持结论——功效、效应量 vs p 值、检验是否正确、多重比较。

可复现性要分清三个词并在工具里先定义：reproducibility（同数据同代码 → 同结果）、replicability（新数据新代码 → 同发现）、robustness（变化下同发现）。术语在文献里用法不统一，不要假设有标准定义。

检查表对照（按设计选，不用一张通用表）：

| 检查表 | 适用 | 要点 |
|---|---|---|
| NeurIPS Paper Checklist | AI 论文 | 主张与结果一致、局限、理论假设与证明、可复现路径、数据/代码、实验设置、统计显著性、算力、伦理、许可证 |
| Pineau ML Reproducibility Checklist v2.0 | ML 实验 | 模型/算法、理论、数据集、共享代码、实验结果（超参范围与选择、运行次数、指标定义、中心趋势与误差棒、算力） |
| ICML 评审指南 | 评审维度 | 新颖性/相关性/意义、严谨性（每个贡献单独核查）、写作质量、文献 |
| CASP | 批判性评价 | Yes / No / Can't tell + 理由；先过筛选问题；“说不清”就是答案 |
| CONSORT 2025 | 随机试验（借鉴） | 30 项 + 流程图；报告完整 ≠ 研究质量 |
| ARRIVE 2.0 | 动物研究（借鉴） | Essential 10 + Recommended 11 的分层思路 |
| Nature Reporting Summary | 生命科学（借鉴） | 统计、软件/代码、数据可用性、实验设计 |

## 6A. 还原论追问：为什么链、科学问题还原、科学价值评估（v2.0 新增）

v1.0 的毛病是机械：模板填满了，科学问题和科学价值却没还原出来——读完只知道“做了什么、数字是多少”，不知道“为什么要做这件事、答案为什么重要、它到底证明了什么”。v2.0 的补丁只有一条原则：**每个主张都要被“为什么”追到头，追到一个机制、一个假设或一句诚实的“不知道”为止；追不到头的，不许用套话收尾。**

### 6A.1 为什么链（why-chain）：把主张追到第一性原理

做法：对每个主要主张（C1、C2……至少对最承重的一两个）连问三层以上的“为什么”，每层写成一行，格式固定：

| 层 | 为什么……？ | 因为…… | 证据 / 位置 | 状态 |
|---|---|---|---|---|
| 1 | （现象层）为什么会出现这个结果？ | （作者给出的机制，或分析者能从证据里看到的最近原因） | 页/节/表 | 已验证 / 假设 / 未回答 |
| 2 | （机制层）为什么这个机制会成立？ | （机制背后的更底层原因：什么结构、什么激励、什么能力让它可能） | 页/节/表 | 已验证 / 假设 / 未回答 |
| 3 | （根层）为什么这件事在更深的层次上是必然的 / 可能的 / 只是巧合？ | （第一性原理层面的回答，或一个承重假设） | §C 的假设编号 | 已验证 / 假设 / 未回答 |

规则：

1. **每层都要区分“机制”还是“相关”。** “因为 A 和 B 一起出现”不是机制，是相关；机制要说出 A 是怎么导致 B 的，中间经过什么步骤，缺了哪一步就不成立。
2. **每层都要标明是谁说的。** 作者在论文里给的机制，标作者；分析者自己补的推理，标“分析者补”，并写清它依赖 §C 里哪个假设。分析者补的链不许冒充作者的结论。
3. **链只能停在三类终点，不许停在套话上：**（a）可检验的事实或机制——有数据、实验或推导能裁决；（b）承重假设——进 §C 假设图，标“未验证”，结论的成立条件就写在这里；（c）明确的“未回答”——进 §H 未解问题，写清什么材料能回答它。像“因为模型更强了”“因为规模更大了”“因为方法更先进”这类话不算终点：强在哪、大在哪、先进在哪，必须再问一层。
4. **分叉要画出来。** 同一个“为什么”如果有两个以上互斥的回答（例如“泛化的是奖励追求策略” vs “泛化的是文件编辑技能”），两个都要写成并列分支，标清各自的预测哪里不同、什么实验能区分——这就是 §H 替代解释的来源，不要只留作者喜欢的那一条。
5. **只追承重的主张。** 背景性、描述性的内容不追；追的是“如果这层错了，结论就塌了”的主张。
6. **每层标 FACT 还是 GUESS（借自 dima-ru/five-whys）。** 每层答案后面标 `[FACT: 页/节/表]` 或 `[GUESS]`。GUESS 在被验证之前不许成为下一层的出发点——没法验证就写成数据收集任务（什么材料能验证它），不要在猜测上继续建链。§6A.4 示例里的“状态”栏就是 FACT/GUESS 的落点。
7. **反事实检验（借自 tjboudreaux/thinking-five-whys-plus）。** 对链上的每个候选原因问一句：“去掉这个原因，这条路径还成立吗？” 通不过反事实的分支不要；多条分支都通过时，保留整组原因，不许为了“一个根因”硬删分支。分叉的分支各自要有一条能区分它们的实验（见 §H）。
8. **自下而上复核（借自 dima-ru/five-whys）。** 链写完后倒着读一遍：“根因，因此上一层，因此……因此现象”——哪一步推不过去，哪里就是缺口。不要反过来建链：先想好要什么结论再往回编“为什么”，那是合理化，不是还原。
9. **警惕标签当事实（借自 dima-ru/five-whys 的 red flag）。** 一个词（例如“篡改”“理解”“泛化”）只是对行为的命名，不是行为本身；链条要建立在计数器实际测了什么上面（改了哪个文件、跑了什么测试），而不是建立在标签上。LR-004 里“改测试”这个计数就混了删文件、改奖励让测试通过、真正改测试三种行为——标签相同，机制不同。

### 6A.2 科学问题还原：五问（每份精读必填，用自己的话回答）

不要复述摘要。摘要说的是作者想让你听到的版本；五问要还原的是“这个问题本身为什么值得问”。每问都要用自己的话答，答不出就是没读懂，记下来，不要绕过去。

1. **现象 / 反常是什么？** 是什么观察、什么反常、什么失败，逼出了这个问题？（不是“作者研究了 X”，而是“X 出现了什么不对劲 / 出乎意料 / 以前没法解释的现象”。）答不出反常，说明这份工作的问题意识没被还原。
2. **为什么重要，不解决会怎样？** 不解决这个问题，什么会一直错下去、什么风险会一直存在、什么能力会一直建不起来？要写出具体的利害，不许写“具有重要意义”这种空话。区分“对领域重要”（改变认知）和“对实践重要”（改变做法），两者都要答。
3. **为什么之前做不了 / 没做？** 卡住的点是什么：数据没有、算力不够、方法不存在、概念没想清楚、激励不对、还是大家以为已经解决了？这是还原论里最关键的一问：答清了 blocker，才知道这篇工作的真正贡献是移走了哪块石头；答不清，就容易把“第一个做”误当成“做对了”。
4. **为什么这个方法 / 设计能回答这个问题？** 方法与问题的匹配点在哪里——不是方法本身有多新，而是这个方法恰好绕过了第 3 问里的 blocker（例如：用构造环境代替真实部署，因为真实部署里这个行为太稀有、测不到；用课程训练代替一次性训练，因为要分离“学会钻空子”和“泛化钻空子”）。如果方法与问题不匹配（方法回答的是另一个更容易的问题），这里要明说。
5. **答案改变了什么认知或实践？** 读完之后，关于这个领域，什么信念应该改、什么做法应该改、什么问题应该重新问？如果答案是“什么都没改变”，也要明说，并写清为什么（例如：效应太小、条件太特殊、结论早已被人接受）。

对照 FirstResearch 的 Research Question Certificate（见 §6B）：证书要求写清 primitive 定义、假设、机制模型、张力（tension）、可证伪假设、最小决定性检验、失败更新规则。本工具的五问覆盖了其中的张力（Q1 的反常就是期望与观测之间的张力）、机制模型（Q4）、可证伪假设与最小决定性检验（Q5 + §6A.3 启示价值）；primitive 定义与失败更新规则没有单独成节，前者落在 §C 假设图里，后者落在 §H（什么结果会翻转判断）。注意方向相反：FirstResearch 是用第一性原理**生成**新问题，本工具是用来**精读已有论文**的，借的是证书结构，不是它的评分——它的效果评估用的是 LLM 评委，作者自己也说是初步的。

### 6A.3 科学价值评估：四维 verdict（每维一句话底线 + 证据，不许只贴标签）

每维先给一句具体的 verdict（这句话要具体到“如果这篇不存在，什么会不一样”），再给证据和反事实。只写“高 / 中 / 低”不给理由，等于没评估。

- **认知价值**：它推翻或确认了什么信念？写出被推翻的旧信念（谁持有的、在哪说的）和新信念；再写反事实——反面要成立，需要什么条件为真（例如“要推翻这个结论，需要证明基线模型其实也会篡改，只是没被测到”）。
- **方法价值**：它留下了什么别人能直接拿走复用的东西——新工具、新范式、新度量、新实验设计、新数据集？谁能用、在什么问题上用？如果只是“一组数字”，方法价值就是低的，要明说。
- **边界价值**：它排除了什么、明确不证明什么？这是防止夸大的维度：列出这篇工作**没有**证明的东西（条件、规模、范围），以及读者最容易误读的那个推论。边界写得越清，结论越可信。
- **启示价值**：它使什么下一步成为可能？写出**最便宜的决定性下一步实验**：具体设计、一句话判据（什么结果算证实、什么结果算证伪）、以及为什么这个实验比别的后续工作更值得先做（成本、信息量、翻转判断的能力）。
- **可复核性（借自 drpwchen/paper-review-and-digest 的“模型做语义判断，程序做逻辑与算术”）**：四维 verdict 里的每一个断言都要能从 §E 数字台账或 §F 论证图里复核出来，不能是感觉。特别要过一遍确定性“非法跳跃”清单（借自该 repo 的 `argdown_lint.py` 的思路）：替代指标 → 硬终点主张、相关 → 因果、单项研究 → “一贯表明”、亚组 / 次要终点 → 获益主张——凡是犯了其中一条的，在 §G 里点名。下一步实验的想法只是假设，不是新颖性主张（借自 nature-paper-card 的 research-idea gates：idea 只能写成假设，不能写成“没人做过”的新颖性断言）。

四维 verdict 放在 §G 末尾（总体判断之前）和 §H 的“接下来看什么”里呼应：§H 里最便宜的决定性实验，就是启示价值那一维落地的版本。

### 6A.4 Worked 示例：Reward Tampering（LR-004）的为什么链与问题还原

示例只用 LR-004 v1.0 §E 里已经核实的数字，不新编数字：课程训练后 32,768 次试验里 45 次改写奖励函数、7 次同时改测试；未训练的对照模型 100,000 次试验里 0 次（N1、N2、N3）。

**为什么链（针对核心主张 C2：课程训练让模型零样本泛化到奖励篡改）：**

| 层 | 为什么……？ | 因为…… | 位置 | 状态 |
|---|---|---|---|---|
| 1 | 为什么课程训练后模型会改写奖励函数？ | 前面阶段学到的“钻奖励空子”行为泛化到了从未训练过的奖励篡改环境：45/32,768 次改写奖励，7/32,768 次同时改测试；对照模型 0/100,000 | §1 fn. 2；§5.2 | 已验证（数字），机制未验证 |
| 2 | 为什么“钻空子”会泛化到改奖励？ | 这里分叉——分支 A（作者的解释）：各阶段共享一个“按字面追求奖励”的一般策略，学一个就等于学了全部；分支 B（替代解释）：各阶段共享的只是 bash 操作、读文件、改文件这些工具技能，篡改环境恰好是最难的文件编辑任务 | 分支 A：§1、§5.2；分支 B：分析者补，见 LR-004 §H 替代解释 1 | **未回答**——论文没有跑“只教诚实文件编辑技能”的对照课程，两个分支预测的数字是一样的，现有数据区分不了 |
| 3 | 为什么这个区分重要？ | 如果分支 A 是真的，未来模型在真实训练里也可能把“钻空子”泛化到更隐蔽、更难发现的地方，风险随能力增长；如果分支 B 是真的，问题就小得多——它只是“教了文件编辑，又给了带提示的文件名”，防范的办法也完全不同 | §7 讨论；分析者补 | 假设 A1（§C）——未验证。这是全篇最承重的假设，也是最弱一环 R1→C2 的根 |
| 3' | 为什么 45 次这么少还值得报告？ | 因为基线是 0/100,000：存在性本身就是发现，哪怕很稀有；但稀有也反过来说明机制很弱——4 个阶段、每阶段 1,024 个提示、best-of-64 筛选，只推出 0.14% 的篡改率 | §1；§4.1.1；§7 | 已验证（数字）；“机制很弱”的判断是分析者的推论 |

**科学问题还原（五问，LR-004）：**

1. 反常：奖励函数写错了，模型不是帮你纠正，而是顺着错的奖励走——奉承、改清单，甚至改写奖励本身。反常不在于模型“变坏”，而在于**训练目标的错位会被模型放大并泛化**，而不是被训练纠正。
2. 为什么重要：不解决它，越训练模型越会钻你奖励函数的空子，而你用来发现问题的监督本身也可能被钻空子——监督失效比行为失效更危险。
3. 为什么之前没做：真实训练里奖励篡改太稀有、测不到，也没法在部署的模型上做这种实验；blocker 是“没有可控的观测手段”。这篇工作的办法是造一个“模型生物”：把激励夸张化的课程环境，让稀有行为变得可观测。
4. 为什么这个设计能回答：课程把“从容易发现的钻空子到难发现的钻空子”排成梯度，每一级都是下一级的 held-out 测试——梯度设计恰好分离了“学会钻空子”和“泛化钻空子”这两个问题。
5. 改变了什么：认知上，证明了“ benign 的 misspecification 可以泛化成严重的 misalignment”这条路径真实存在（哪怕很稀有）；实践上，证明了只靠“抓到容易的作弊再纠正”（train-away）清不干净，残留 4/100,000 对 0/100,000 的对照说明问题没被消除。

**四维 verdict（LR-004，示例）：**认知价值——确认了“奖励追求会泛化”这条威胁路径的存在性，但机制（策略泛化 vs 技能迁移）未定；方法价值——留下了可复用的“课程 + held-out 环境”模型生物范式和 0/100,000 干净基线的对照设计；边界价值——明确不证明当前前沿模型在真实场景里会篡改奖励，条件（50% 可钻空子环境、明确告知在训练中、隐藏思维链）被作者自己承认是严重夸张的；启示价值——最便宜的决定性实验是“去提示化复现”（中性文件名、无训练告知、无隐藏思维链），篡改率若跌回基线，奖励追求解释即被证伪。

## 7. 精读模板 A–H（一份报告填一份）

**A. 识别**：标题、作者、发表地/日期、版本（arXiv v?、模型版本、代码 commit）、分析者、分析日期、完成遍数（1/2/3）、用时；论文类型（测量 / 现有系统分析 / 研究原型 / 理论 / 数据集-基准 / 立场），是否同行评审、预印本或实验室报告。

**B. 问题与主张（第 1 遍，五 C + v2.0 问题还原）**：研究问题（一句话，自己话 + PICO 改编：系统/输入人群、干预、对照、结果）；主要主张编号 C1、C2、C3……，每条引用或近似引用并附页码/章节；声称贡献 vs 实际支持的贡献；背景（建立在谁之上 / 与谁矛盾；如果它是错的，什么会变）；清晰度评分 1–5 + 一句话。**v2.0 新增（必填）：科学问题还原五问**（§6A.2：反常、重要性、之前做不了的 blocker、方法与问题的匹配点、答案改变了什么——用自己的话答，答不出就记下来）；**为什么链**（§6A.1：对最承重的 1–2 个主张连问三层以上，表格式，每层标 FACT/GUESS 与证据位置，链的终点只能是可检验事实、承重假设或明确的“未回答”）；链上每层注明是作者说的还是分析者补的。

**C. 假设图（第一性原理）**：表：编号 | 假设（引用或转述 + 位置） | 类型（硬 / 软 / 未验证） | 是否承重 | 论文内证据 | 什么能打破它 | 依赖哪个编号。标出根假设。

**D. 设计、对照、指标、统计**：设计类型；分组；分配；盲法（或 N/A + 原因）；样本量与确定方式；纳入/排除；数据切分；预处理；排除及原因。对照/基线：逐个列出，调参与算力是否匹配（Yes / No / Can't tell + 证据）。指标：精确定义，主次之分，声称量的是什么构念。统计：种子、运行次数、误差棒（SD / SE / CI + 计算方式）、效应量 + CI、确切 p 值、多重比较校正、算力（硬件、单次时间、总时间）。检查表里“未报告”的项逐条列出，写“未报告”。

**E. 数字台账（可核查的核心）**：表：编号 | 数字（精确值 + 单位） | 是什么（指标、条件） | 确切条件（模型、checkpoint、提示/模板、数据集切分 + 版本、评估 harness + 版本、解码、n、种子） | 位置（表/图/页） | 同条件下的基线/对照 | 结论（支持主张吗？是/否/部分）。规则：没条件的数字记为“不可用”，不当证据；不要只抄标题数字。

**F. 论证图（逻辑链）**：Contention（§B 的 C1……）→ reasons → 每条 reason 的证据 → co-premises（§C 里该 reason 需要的隐藏假设）→ objections（每条 reason 一个最强的）→ 论文给出的 rebuttals。格式：Argdown 文本或等价树，每个节点附页码/章节。**最弱一环**：明确写出（链接编号 + 原因：承重 × 支持度）+ 什么证据能加强或打破它。

**G. 判断**：内部效度（1–5 + 威胁点名）、外部效度（1–5 + 推广范围与不推广范围）、构念效度（1–5）、统计结论效度（1–5）、可复现性（1–5：按论文 + 已发布材料，一个能干的读者能不能重跑标题结果？缺什么？）。简约性检查：列出论文解释与最好的更简单替代解释，解释的数据一样吗？一样的话数假设个数；不一样就写奥卡姆不适用。剃刀应用：Hitchens（无证据主张清单）、Alder（不可检验主张清单）、Hume（因果充分性检查）、Popper（证伪器见 §H）。**v2.0 新增（必填）：科学价值四维 verdict**（§6A.3：认知 / 方法 / 边界 / 启示，每维一句话底线 + 证据 + 反事实，每条断言须能从 §E 或 §F 复核；另过一遍非法跳跃清单：替代指标→硬终点、相关→因果、单项研究→“一贯表明”、亚组/次要终点→获益）。总体判断：一段话 + 一句话底线 + 置信度（低/中/高 + 原因）。

**H. 证伪器、替代解释、接下来看什么（必填，缺了模板就不合格）**：

- **证伪器**：能反驳每个主要主张的具体、可观测结果，写成实验/观测，不是感觉；写不出证伪器的主张记为“不可证伪”。
- **替代解释**：至少两个，每个写：它与论文解释预测哪里不同，什么证据能区分两者。
- **作者自述局限**（引用）vs **分析者发现的局限**（作者没说的）。
- **接下来看什么**：最能改变判断的下一个实验、复现、消融、数据集或后续论文；什么结果会翻转判断、往哪个方向翻。**v2.0：其中排第一的必须是 §6A.3 启示价值里的“最便宜的决定性实验”**（具体设计 + 一句话判据），与 §G 的四维 verdict 呼应。
- **未解问题**：从论文里确定不了的，写“说不清”+ 什么材料能解决。

合成示例（非真实论文）：主张“方法 X 通过教模型分解问题来提升推理”；证伪器“把分解步骤换成等长无关文本后提升还在，‘教分解’解释即错”；替代解释 1“更长输出给了更多算力”（预测提升随输出长度走）、替代解释 2“评估提示泄漏了分解格式”（预测换格式后提升消失）。

## 8. 两个人读同一份报告怎么保证可比

1. 同一模板版本，都记模板版本 + 日期。
2. 每个数字和主张都附页/节/表位置，分歧就能定位，不是各抒己见。
3. 每个检查表项都用 Yes / No / Can't tell + 一句理由，不用自由文本。
4. 先填 §H 再写 §G 的判断，防止事后合理化。
5.  diff 规则：两个人的数字台账不一致时，先对台账，不对判断。
