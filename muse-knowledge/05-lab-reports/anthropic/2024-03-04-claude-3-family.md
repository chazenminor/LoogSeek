## B. 问题与主张

### B.1 科学问题还原：五问（分析者用自己的话回答；公告本身没有提出研究问题，而是直接断言结论）

1. **现象 / 反常是什么？** Claude 3 之前，公开基准榜首是 OpenAI 的 GPT-4 家族与 Google 的 Gemini 1.x 家族，Claude 2 / 2.1 处于追赶位置；Claude 完全没有视觉能力，而竞品已具备多模态能力；用户对 Claude 2 的过度拒绝（对无害请求也拒绝）和幻觉已有抱怨。反常不在某一次实验失败，而在**竞争格局**：榜单落后、缺视觉、可用性被诟病——公告要回答的正是“Claude 能不能反超”。
2. **为什么重要，不解决会怎样？** 对实践：若 Claude 3 不能证明达到前沿，Anthropic 将在企业客户、API 生态与云合作（Bedrock / Vertex）竞争中持续下风，开发者会继续默认选择 GPT-4 / Gemini。对领域：若一家主要实验室长期无法在公开基准上挑战榜首，“前沿由一两家定义”的格局会固化，基准竞争本身的信号价值也会被质疑。不解决，什么都不会“错下去”——这不是科学错误待纠正，而是市场与技术地位问题；但若领先宣称是假的，受损的是 Anthropic 的可信度与用户据此做的选型决策。
3. **为什么之前做不了 / 没做？** 卡住的点是**能力本身**：Claude 2 / 2.1 一代的模型能力、视觉能力与长上下文能力尚未达到可宣称领先的水平——没有一块“石头”可移走，只有把模型做得更强这一条路。这与典型论文的 blocker 不同（数据没有、方法不存在、概念没想清楚）；这里的 blocker 就是“模型还不够好”。因此公告的真正贡献不在方法，而在**产品本身**（三个模型、200K 上下文、视觉能力）与**宣称**（基准领先）。
4. **为什么这个方法 / 设计能回答这个问题？** 公告的“方法”是发布三个分层模型并附一张基准对比表，匹配点只有一半是真的：分层发布（Haiku / Sonnet / Opus 按智能 / 速度 / 成本分层）确实回答了“不同需求的用户能不能各取所需”；但基准对比表**并不真正回答**“是否领先于当前同行”——表中的同行数字引自较旧的报告（原始 GPT-4，2023 年 3 月，而非 GPT-4 Turbo），且评估条件（harness、提示、解码、种子）全未报告。公告回答的是一个更容易的问题（“在一张表上 Opus 的数字更高”），而不是它宣称回答的问题（“Opus 是当前业界最强的模型”）。方法与问题不匹配。
5. **答案改变了什么认知或实践？** 认知上几乎什么都没改变：公告没有提供任何可检验的机制解释（没有架构、数据或训练变化），也没有可复核的证据，因此关于“什么让模型变强”的信念不应改变。实践上改变的是**产品选择面**：三个模型、200K 上下文、159 个国家 API 可用、ASL-2 安全级别——这些是真实、可查的产品事实，用户与开发者可以据此做选型。榜单宣称本身应被视为“待验证”，直到出现同 harness、当前 checkpoint 的复现。

### B.2 主张的完整逻辑链（每条主张只讲一次；后文一律引用链号，不复述）

**链 1——C1 前沿智能。** 科学问题：Opus 是否在常用基准上超越当前同行并树立新标准（§B.1 Q4 的重构问题）。承重假设：A1（基准分 = 通用能力）、A2（对比公平：相同提示、harness、解码、模型版本）、A3（测试集不在训练数据中）。设计 / 对照：基准对比表 + 内部评估；同行仅具名（GPT-4、GPT-3.5、Gemini 1.0 Ultra / Pro、Gemini 1.5 Pro，按模型卡），正文中无同行检查点 / 版本、无 harness、无提示、无解码、无种子、无污染声明。关键证据：标题数字全部在 §E 台账 2、**未核实**（MMLU Opus 86.8% 对 GPT-4 86.4%，仅 0.4 个百分点差距；GPQA 50.4%、GSM8K 95.0%、HumanEval 84.9%）；公告正文称 Opus“在复杂任务上表现出接近人类水平的理解与流畅度，引领通用智能的前沿”，但页面上无任何人类基线。结论与置信度：**未确立，置信度低**。最弱一环 / 边界：A2 + A3 全无证据，且同行是 2023 年 3 月的原始 GPT-4 而非 GPT-4 Turbo，真实差距被夸大；同一张表有三个无法区分的解释——分支 A（公告的解释：更强的模型家族）、分支 B（新旧 artifact：2024 年 3 月模型对 2023 年 3 月基线）、分支 C（harness / 提示优化，如 GPQA / MATH 用 0-shot CoT，同行是否同等待遇未报告）。区分实验见 §H。
**链 2——C6 长上下文与近乎完美的召回。** 科学问题：200K 上下文窗口是否意味着能有效处理长上下文提示。承重假设：A7（NIAH 召回 = 长上下文可用性，而不只是检索能力）。设计 / 对照：Needle In A Haystack（NIAH，大海捞针）评估，每提示用 30 组随机针 / 问题对，多样化的众包文档语料；无同行 NIAH 数字。关键证据：Opus 召回准确率 >99%（§E N3），但测试的上下文长度、提示数量、解码、种子均未报告；>1M token 输入“能够接受”却“可能向部分客户提供”，发布时不普遍提供（§E N2）。结论与置信度：**召回确立、推理未确立，置信度中**——NIAH 只测检索，不测综合。最弱一环 / 边界：A7，且公告自己承认 Opus“发现了评估本身的局限”，即针可被识别为人工植入物；没有任何需要在全上下文内综合 / 推理的任务证据。
**链 3——C5 准确率提升 / 幻觉减少。** 科学问题：Opus 在开放式事实问题上是否比 Claude 2.1 准确两倍。承重假设：A6（内部“大量复杂事实问题”集合是衡量真实部署中准确率 / 幻觉的有效探针）。设计 / 对照：内部准确率测试，问题针对当前模型已知弱点，回答分正确 / 错误 / 不确定三类；来源句子的引用承诺“即将提供”。关键证据：只有 2× 比值，无绝对比率、无测试集规模（n）、无构建方式、无评分程序（§E N6）。结论与置信度：**作为精确宣称不可用，置信度低**。最弱一环 / 边界：A6 全无支撑，且其实践规模（绝对准确率多高）无法从公告中得知。
**链 4——C2 速度 / 延迟阶梯。** 科学问题：三个模型的速度分层是否如宣称。承重假设：A5（速度宣称可推广到所述工作负载之外）。设计 / 对照：无延迟测试方法——无硬件、无并发、无输出长度、无百分位（p50 / p95）。关键证据：Sonnet 比 Claude 2 与 Claude 2.1 快 2 倍（§E N4，无任何条件）；Haiku 不到 3 秒读完一篇约 10k token、含图表的信息与数据密集 arXiv 论文（§E N5，单一工作负载）；Opus 速度与 Claude 2 / 2.1 相近但智能高得多（无数字）。结论与置信度：**2× 比率不可用，置信度低；Haiku <3 秒仅对该单一工作负载部分支持 C2**。最弱一环 / 边界：A5——有负载下的独立延迟测量即可推翻比率。
**链 5——C7 负责任的设计 / 安全级别。** 科学问题：ASL-2 是否为正确的安全级别。承重假设：A8（红队评估与能力评估足以排除 ASL-3 级风险；政策框架 + 经验充分性未验证）、A9（更低的 BBQ 分数意味着真实使用中偏见更小）。设计 / 对照：按《负责任扩展政策》与白宫承诺、2023 年美国人工智能行政命令进行的红队评估；BBQ（偏见基准）衡量偏见。关键证据：公告称家族“仍处于 AI 安全级别 2（ASL-2）”，红队评估“得出结论，模型目前造成灾难性风险的可能性可忽略不计”，偏见“如模型卡所示”低于以往模型——但评估方法、阈值、结果与 BBQ 数字**全部推迟到模型卡**，页面上无数字。结论与置信度：**ASL-2 定级是公告陈述的政策事实；“灾难性风险可忽略”的经验结论在公告内无法核查**。最弱一环 / 边界：A8——一项能力评估（生物、网络、自主性）接近 ASL-3 阈值即可打破它；公告承诺“继续仔细监测”与 ASL-3 的接近程度，隐含承认安全评估是暂定的。
**无链可立的主张（C3、C4、C8）——断言而无证据，按 Hitchens 规则搁置。** C3 视觉平齐：“Claude 3 模型拥有可与其他领先模型媲美的复杂视觉能力”，可处理照片、图表、图形、技术图解，动机是“部分企业客户的知识库高达 50% 以 PDF、流程图、幻灯片等格式编码”（§E N8，无分母、无客户样本）——但公告文本中无任何视觉基准数字。C4 更少（不必要的）拒绝：Opus、Sonnet 与 Haiku“比前代显著更不可能拒绝回答那些接近系统护栏边界的提示”，“无害提示被拒绝的频率低得多”——展示了一张图表，但抓取文本中没有数字。C8 易用性：更擅长遵循复杂多步骤指令、遵循品牌语调 / 回复规范、产出结构化输出（JSON），并称三个模型在分析、预测、内容创作、代码与非英语语言上均有提升——无数字、无例子、无评估。以上三条均无承重假设可检验、无对照、无数字，见 §H 证伪器。

## C. 假设图（第一性原理；每条只列一次，后文引用编号）

- **A1（根假设，未验证，链 1 之根）：** 基准分数（MMLU、GPQA、GSM8K、HumanEval 等）衡量通用智能 / 能力。打破它：证明这些基准奖励记忆、格式匹配或测试集泄漏，而非所声称的能力；或一篇公告未提及的、Opus 落败的基准。

## G. 效度判断

评分 1–5（5 = 强），针对**公告作为证据**，而非模型本身。**内部效度 2/5：** 没有实验，经典内部效度威胁大多是“说不清”而非受控；适用的具体威胁是基线不对称（同行数字引自较旧报告，原始 GPT-4 而非 GPT-4 Turbo）、可能的测试集污染（从未提及）、基准选择（表格只展示 Opus 领先的基准，未提及任何 Opus 不领先的基准），链 3 的测试集与评分器均未描述；给 2 分而非 1 分，因为 NIAH 程序至少部分有描述（30 组针 / 问题对、众包语料），且比较对象至少具名。**外部效度 2/5：** 从一组狭窄的学术基准加一次检索测试，推广到“引领通用智能前沿”、“接近人类”这类断言；无部署测量、无用户研究、尽管宣称多语言却无多语言数字、尽管宣称视觉却无视觉数字；200K 上下文宣称从检索（NIAH）推广到“有效处理长上下文提示”，比测试所支持的范围更宽；能推广的是可用性 / 产品事实。**构念效度 2/5：** MMLU / GPQA / GSM8K 分数被当作“智能”、“专家知识”与“专家推理”，NIAH 召回被当作长上下文能力，BBQ 被当作偏见，一张拒绝率图表被当作“细致理解”——每一步都是层级跳跃（分数 → 能力 → 理解），没有桥接证据；公告自己的 NIAH 轶事（模型识破人工植入的针）具有两面性：它表明测试测量的不是自然长文档使用中的东西。**统计结论效度 1/5：** 未报告任何统计量（无 n——除 NIAH 的 30 对外——无种子、无运行次数、无误差棒、无 CI、无 p 值）；标题差距在可核查处很小（MMLU Opus 86.8% vs. GPT-4 86.4%——0.4 个百分点的差距，远小于一次单运行评估在约 14k 道题测试上任何合理的误差棒），却被当作胜利呈现且无不确定性；2× 准确率比值给出时无绝对比率，因此其实践规模无法从公告中得知。**可复现性 1/5：** 无提示、无 harness、无解码设置、无种子、无数据集版本、无代码、无权重、无训练数据；唯一可复现的是产品事实（上下文窗口大小、可用性）；甚至基准表也无法仅从公告推导出来，因为数字在图片中，且本分析期间未能抓取模型卡 PDF；有 API 访问权限的读者原则上可以重跑 MMLU，但必须猜测每一个评估选择。

**简约性检查：** 公告对 Opus 基准领先的解释是“更强的模型家族”（规模 + 训练改进，未具体说明）；一个更简单的替代解释同样能解释同一张表——**检查点选择**：将 2024 年 3 月的模型与 2023 年 3 月 GPT-4 的数字对比，即领先部分是新旧 artifact，而非能力跃升；两种解释都预测“这张表里 Opus 的数字更高”，它们在同日期、同 harness 对比中的预测不同（新旧解释预测对上 GPT-4 Turbo 时领先缩小或消失）；仅凭表格，奥卡姆无法在二者之间裁决——能区分的证据（同 harness、当前检查点的对比）正是未报告的内容。第二个更简单的替代解释：**针对报告基准的提示 / harness 优化**（模型卡报告多个基准用 0-shot CoT；同行是否得到同等待遇未报告）。
**剃刀应用：** **Hitchens：** 公告中无证据的主张均标记为“待证据、可无进一步论证驳回”——涵盖 C3（视觉平齐，无数字）、非英语宣称、预测 / 内容创作宣称，以及“接近人类”（链 1 的修辞一半）。**Alder / 牛顿的火焰激光剑：** “接近人类水平的理解”与“类人理解”未被操作化，公告提供的任何观察都无法裁决——按现状搁置为不可检验。**Hume（因果充分性）：** 公告从未提供 Claude 3 为什么更好的机制（未提及任何架构、数据或训练变化），因此基准领先背后的因果故事是空的；所宣称效应的规模（新行业标准）与任何已陈述的原因不匹配。**Hume 的断头台：** 规范性结尾（前沿发展引导 AI 走向积极结果，A10）无法从描述性基准宣称推出；它需要另加未给出的前提。**Popper：** 基准宣称原则上可证伪（见 §H），但修辞性宣称（A4、A10）不可证伪。**Sagan：** “引领通用智能前沿”是非凡宣称；所提供的证据（正文中无法核实的表格、无误差棒、较旧的同行检查点）达不到非凡标准。**Hanlon：** MMLU 的微小差距与陈旧的同行检查点，应首先解读为报告 / 基准 artifact，而非蓄意误导。

- **认知价值：低。** 没有推翻或确认任何科学信念——断言 Opus 领先，却没有提供可检验的机制或可复核的证据，读完之后关于“什么让模型变强”的信念不应改变。证据：§F 最弱一环（A2 + A3 无证据）、§E 台账 2 全部未核实、0.4 个百分点的 MMLU 差距无误差棒。反事实：要让认知价值成立，需要一次同 harness、当前 checkpoint、带误差棒的复现确认 Opus 领先；若复现使排序翻转，认知价值即为零且公告的定位宣称被证伪。
- **方法价值：低。** 没有留下别人能直接拿走复用的工具、范式、度量、实验设计或数据集——没有代码、数据、提示、harness 或权重随公告发布。证据：§D“数据 / 代码可得性：不可得”、§E 缺失清单。唯一接近可复用的是一点方法描述：增强版 NIAH（30 组随机针 / 问题对、众包语料）与内部准确率测试的思路（正确 / 错误 / 不确定三分法），但两者均未公开细节到可复用的程度。反事实：若模型卡随公告完整公开（含 harness、提示、BBQ 与拒绝率数字），方法价值会显著高于现在。

## I. 结论、结果与价值总览（只用本文件已核实的材料；数字见 §E，此处不重复印数字）

### 一句话结论

作为产品发布，它可信地宣布了 Claude 3 三模型、200K 上下文与 ASL-2；作为“Opus 树立智能新标准”的证据，它不成立——标题基准数字未核实、对比用的是较旧的同行检查点、没有任何数字带不确定性。

1. **产品事实确立（置信度：高）。** 三模型分层发布、发布时 200K 上下文窗口、API 在 159 个国家可用、ASL-2 安全分级，都是公告正文直接陈述、可核查的事实。证据：§E 台账 1（N1、N7）、§B.1 Q5。
