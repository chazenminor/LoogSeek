## 一、背景与问题

### 公告之前是什么局面

在 Claude 3 之前，公开基准的榜首是 OpenAI 的 GPT-4 家族和 Google 的 Gemini 1.x 家族。Claude 2 和 Claude 2.1 处在追赶的位置。

Claude 还有一块明显的短板：它完全没有视觉能力，而竞品已经能处理图像。

用户对 Claude 2 也有两点抱怨：对无害请求也拒绝的过度拒绝，以及幻觉。

所以这篇公告要回答的问题，不是某一个实验问题，而是竞争格局里的问题：Claude 能不能反超？它发布了三个模型，并宣称其中最强的 Opus 在常用基准上超过了同行，树立了新的行业标准。

### 公告自己的说法

公告说，Opus 在复杂任务上表现出接近人类水平的理解与流畅度，引领通用智能的前沿。

它还说，三个模型按智能、速度和成本分层，适合不同的需求；上下文窗口达到 200K；具备了视觉能力；更少出现不必要的拒绝；回答更准确。

公告建立在 Claude 2 和 Claude 2.1 之上，也提到了宪法 AI（Constitutional AI）训练。

文末它还提出了一个战略上的假设：处于 AI 发展的前沿，是引导其轨迹走向积极社会结果的最有效方式。这句话是以“我们的假设”形式提出的，是价值判断，不是实证结论。

### 这是一篇什么样的文档

标题是 Introducing the next generation of Claude，主题是 Claude 3 模型家族：Claude 3 Haiku、Claude 3 Sonnet、Claude 3 Opus。

作者和发布方是 Anthropic。这是一则公司公告，页面上没有列出个人作者。发表地是 Anthropic News（博客 / 模型公告），链接是 https://www.anthropic.com/news/claude-3-family 。

## 二、方法与设计

先说清楚这篇东西的性质。它是一篇模型发布帖，不是同行评审论文，也不是实验。

按论文意义上的实验设计，它没有假设检验，没有随机化，没有对照组，没有预注册，也没有统计分析。下面按它本来面目来评估它：一项由基准对比与内部评估支持的能力宣称。

### 它是怎么做评估的

公告附了一张基准对比表，并做了几项内部评估：准确率测试、大海捞针测试、BBQ 偏见基准和红队评估。

对比对象分两组。一组是同行模型：GPT-4、GPT-3.5、Gemini 1.0 Ultra、Gemini 1.0 Pro 和 Gemini 1.5 Pro，这些名字按模型卡列出。另一组是自家的前代：Claude 2 和 Claude 2.1。

但对比的细节没有交代。正文里没有写同行模型是哪个检查点、哪个版本，也没有说基线是不是在同一个评估框架里跑的。

基线的调参和算力是否对等，同样没有报告。这一点是说不清的。

公告里没有描述任何人类评估，所以随机化、盲法这些概念在这里不适用。

### 样本、提示与指标

样本量只有大海捞针测试给了数字：每条提示用 30 组随机的针和问题对。准确率测试只说问题“大量”，没有给出数量。

基准测试的题量是各基准的标准规模，公告没有说明。

数据的纳入和排除、切分和版本，公告都没有报告。模型卡的二手副本说，训练数据的知识截止期是 2023 年 8 月。

提示词也没有给出。正文里没有提示模板，也没有 few-shot 的数量。模型卡报告了各基准的 shot 数，比如 MMLU 是 5-shot，GPQA 是 0-shot 思维链，但这些数字是暂定的，见下文数字台账。

指标方面，正文点名的有 MMLU、GPQA、GSM8K 和 HumanEval。模型卡里还列了 MATH、MGSM、DROP、BIG-Bench Hard、MMMU 和视觉基准。

公告还用了大海捞针的召回准确率、内部准确率测试的正确、错误和不确定三类结果、BBQ 和拒绝率。拒绝率只出现在图表里，正文没有数字。

这些指标只被点名，没有在公告里定义，也没有分主次。它们号称在量什么，公告是直接断言的，没有论证。

比如它说，MMLU 量的是本科水平的专家知识，GPQA 量的是研究生水平的专家推理，GSM8K 量的是基础数学。分数和它所声称的能力之间，没有给出桥接的证据。

### 统计、算力与可得性

统计方面，公告什么都没有报告。没有种子，没有运行次数，没有误差棒，没有置信区间，没有 p 值，也没有多重比较校正。

训练算力也没有报告。没有参数量，没有训练 FLOPs，没有硬件，也没有训练时长。评估算力同样没有报告。

训练数据、评估代码和模型权重都没有发布。读者能接触到模型的唯一途径是 API。

安全方面，公告给出了 ASL-2 定级、红队评估的摘要、BBQ 的引用和宪法 AI 的提及。但细节全部推迟到了模型卡。

按 NeurIPS / Pineau 检查表，下面这些项在公告里都是“未报告”：主张与结果的一致性（无法核查，因为数字在图片里）、局限（公告中未陈述）、理论与假设（无）、可复现路径（无代码、无数据、无提示、无种子、无评估框架）、实验设置（正文中无解码、无 shot 数）、统计显著性（无）、算力（无）。

数据与代码许可不适用，因为这是专有模型。

## 三、主要发现

### 三个模型

Claude 3 家族有三个模型：Haiku、Sonnet 和 Opus，按能力递增排列。

Opus 是最强的一档，Sonnet 居中，Haiku 是最快、最轻的一档。发布时 Opus 和 Sonnet 可以使用，Haiku 是“即将推出”。

三个模型的 API 标识符分别是 `claude-3-opus-20240229`、`claude-3-sonnet-20240229` 和 `claude-3-haiku-20240307`。

但这三个标识符没有出现在公告页本身。它们来自 Anthropic 文档和二手来源，没有对照公告页核实。

### 基准对比：公告的核心宣称

公告最核心的宣称是，Opus 在大多数常用基准上超过了同行，树立了新的行业标准。

这张对比表是图片形式，抓取到的页面文本里没有它的数字。所以下面这些数字不是从公告页直接读到的。

它们按 Claude 3 模型卡所印的样子引用，来源是模型卡的一份二手托管副本，并对照了 Anthropic 官方的《Claude 3.5 Sonnet Model Card Addendum》。这些数字全部是未核实的，不能当作已确立的结论引用。

MMLU 是 5-shot。按模型卡副本，Opus 86.8%，Sonnet 79.0%，Haiku 75.2%。同表里的同行数字是 GPT-4 86.4%，GPT-3.5 70.0%，Gemini 1.0 Ultra 83.7%，Gemini 1.5 Pro 81.9%，Gemini 1.0 Pro 71.8%。

Opus 只比 GPT-4 高 0.4 个百分点。这个差距很小，而且没有任何误差棒。

这里有一个没有解决的冲突。官方的 3.5 附录显示，Claude 3 Sonnet 的 MMLU 5-shot 是 78.3%，而不是模型卡副本里的 79.0%。

可能是不同的评估运行，也可能是摘录里的列错位。两个数字都没有对照原始页面核实。

GPQA 用的是 Diamond 切分，0-shot 思维链。Opus 50.4%，Sonnet 40.4%，Haiku 33.3%。GPT-4 是 35.7%，这个数字按二手摘要，摘录中没有确认。

Opus 的 50.4% 已经在官方 3.5 附录的 Opus 一列中得到确认。Sonnet 和 Haiku 的数字只来自模型卡副本和二手摘要。

GSM8K 上，Opus 95.0%，Sonnet 92.3%，Haiku 88.9%。摘录里没有说明 shot 数。GPT-4 是 92.0%，按二手摘要。

这些数字只来自模型卡的二手摘要，官方附录的摘录里没有确认。

HumanEval 是 0-shot 的 Python 编程任务。Opus 84.9%，Sonnet 73.0%，Haiku 75.9%。GPT-4 是 67.0%，按二手摘要。

Opus 的 84.9% 已经在官方 3.5 附录中确认。Sonnet 和 Haiku 的数字只来自模型卡副本和二手摘要。

这里有一个值得标注的现象：Haiku 的 75.9% 高于 Sonnet 的 73.0%。公告没有解释这一点。

MATH 是 0-shot 思维链，Opus 60.1%，Sonnet 43.1%。MGSM 也是 0-shot 思维链，是多语言数学，Opus 90.7%，Sonnet 83.5%。

DROP 是 3-shot 的阅读理解 F1，Opus 83.1。Opus 的 MATH 60.1% 和 MGSM 90.7% 已经在官方 3.5 附录中确认。

DROP 的数字只在附录摘录里出现过一次。那份摘录的列对齐是混乱的，所以就连归属给 Opus 这一点也是暂定的。

模型卡还报告了多数投票的数值：Opus 的 MATH 是 73.7%，GPQA 是 59.5%。采样条件是温度 1、采样 32 次，用多数投票决定答案，不是单次采样。

还要指出一点。公告正文说 Opus 有“接近人类水平的理解与流畅度”，但页面上没有任何人类基线。这个说法没有可以对照的数字。

同行对照本身也有一个问题。表里的 GPT-4 是 2023 年 3 月的原始 GPT-4，而不是当时已经部署的 GPT-4 Turbo。

拿 2024 年 3 月的模型去比 2023 年 3 月的基线，差距会被夸大。

### 长上下文与大海捞针

发布时，三个模型最初提供 200K token 的上下文窗口。

模型“能够接受”超过 100 万 token 的输入。但公告说“我们可能向部分客户提供”，发布时并不普遍提供。

为了证明长上下文能力，公告用了大海捞针测试。做法是把一句话藏进一大段文档里，再问模型把它找出来。Opus 的召回准确率超过 99%。

测试的具体做法只交代了一部分。每条提示用 30 组随机的针和问题对，文档是多样化的众包语料。

但测试是在多长的上下文上做的、用了多少条提示、解码设置和种子是什么，都没有报告。也没有同行模型的大海捞针数字可以对照。

公告自己还讲了一个细节：Opus 发现了评估本身的局限。它能识别出藏进去的句子是人工植入的，因为那句话和周围的文档格格不入。

这说明测试测的是找东西的能力，未必是自然地使用长文档的能力。

大海捞针只测检索，不测综合。公告没有给出任何需要在整个上下文里综合和推理的任务证据。

所以 200K 上下文能不能用来做长推理，从这篇公告里是看不出来的。

### 准确率提升

公告说，Opus 在有挑战性的开放式问题上，准确率比 Claude 2.1 高出两倍。

测试用的是一组“大量针对当前模型已知弱点的复杂事实问题”。回答分成正确、错误和不确定三类。

但这里只有一个比值：两倍。绝对准确率是多少，公告没有说。测试集有多大、怎么构建的、怎么评分的，也都没有说。

所以这个“两倍”作为精确的宣称是不可用的，它的实际规模无从得知。

公告还承诺，引用来源句子的功能“即将提供”。也就是说，准确率的宣称先于可以验证它的功能而存在。

### 速度

速度方面，公告说 Sonnet 比 Claude 2 和 Claude 2.1 快两倍。

但它没有说明是在什么工作负载、什么硬件、什么并发、什么输出长度下测的，也没有给出延迟的百分位。这个两倍的比率作为精确的宣称是不可用的。

Haiku 的速度给了一个具体的例子：它不到 3 秒就能读完一篇约 10k token、信息和数据密集、含有图表的 arXiv 论文。

但这只是单一工作负载，没有输出长度、并发和百分位的信息。它只能支持这一例，不能推广到一般情况。

Opus 的速度和 Claude 2 与 Claude 2.1 相近，但智能要高得多。这句话没有配任何数字。

### 视觉能力

公告说，Claude 3 模型拥有可与其他领先模型媲美的复杂视觉能力，能处理照片、图表、图形和技术图解。

它给出的动机是企业客户的知识库：其中一些客户的知识库高达 50% 是以 PDF、流程图、幻灯片等格式编码的。

这个数字没有分母，也没有客户样本。它只是背景动机，不是模型的测量结果。

关键在于，公告文本里没有任何视觉基准的数字。视觉基准的数字只在模型卡里可能有，公告正文里没有表，也没有分数。

### 更少的拒绝

公告说，Opus、Sonnet 和 Haiku 比前代“显著更不可能拒绝回答那些接近系统护栏边界的提示”，无害提示被拒绝的频率“低得多”。

公告展示了一张相关的图表，但抓取到的文本里没有这张图的数字。拒绝率在数值上改进了多少，从公告正文里是读不出来的。

### 易用性

公告还说，三个模型更擅长遵循复杂的多步骤指令，遵循品牌语调和回复规范，并产出结构化输出，比如 JSON。

它还说，三个模型在分析、预测、内容创作、代码和非英语语言上都有提升。这些说法没有配数字，没有例子，也没有评估。

### 发布与可用性

发布时，Claude API 在 159 个国家全面可用。Opus 和 Sonnet 可以使用，Haiku 即将推出。模型也上线了 Bedrock 和 Vertex。

### 安全

安全方面，公告说整个家族“仍处于 AI 安全级别 2”，也就是 ASL-2。红队评估得出的结论是，模型目前造成灾难性风险的可能性“可忽略不计”。

偏见方面，公告说偏见比以往的模型低，“如模型卡所示”。但评估的方法、阈值、结果和 BBQ 的数字，全部推迟到了模型卡。公告页面上没有任何数字。

红队评估是按《负责任扩展政策》、白宫承诺和 2023 年美国人工智能行政命令来做的。公告承诺会“继续仔细监测”与 ASL-3 的接近程度。

## 五、精读点评

这一节是分析者的判断，和上面对公告的呈现分开写。

### 这篇公告真正要回答的问题

这篇公告真正要回答的问题是：在 Claude 2 落后、没有视觉能力、又被抱怨过度拒绝和幻觉之后，Claude 3 能不能让 Anthropic 反超到前沿？它给出的答案分两层。一层是产品：三个模型、200K 上下文、视觉能力、159 个国家可用、ASL-2。另一层是宣称：Opus 在基准上超过了同行。第一层是事实，第二层是待验证的断言。

### 科学问题还原：五问

**现象是什么？** Claude 3 之前，公开基准榜首是 OpenAI 的 GPT-4 家族与 Google 的 Gemini 1.x 家族，Claude 2 / 2.1 处于追赶位置。Claude 完全没有视觉能力，而竞品已具备多模态能力。用户对 Claude 2 的过度拒绝和幻觉已有抱怨。反常不在某一次实验失败，而在竞争格局：榜单落后、缺视觉、可用性被诟病。公告要回答的正是“Claude 能不能反超”。

**为什么重要，不解决会怎样？** 对实践来说，如果 Claude 3 不能证明达到前沿，Anthropic 将在企业客户、API 生态与云合作（Bedrock / Vertex）竞争中持续下风，开发者会继续默认选择 GPT-4 / Gemini。对领域来说，如果一家主要实验室长期无法在公开基准上挑战榜首，“前沿由一两家定义”的格局会固化，基准竞争本身的信号价值也会被质疑。

不解决，什么都不会“错下去”。这不是科学错误待纠正，而是市场与技术地位问题。但如果领先宣称是假的，受损的是 Anthropic 的可信度与用户据此做的选型决策。

**为什么之前做不了？** 卡住的点是能力本身。Claude 2 / 2.1 一代的模型能力、视觉能力与长上下文能力尚未达到可宣称领先的水平。没有一块“石头”可移走，只有把模型做得更强这一条路。

这与典型论文的阻碍不同。典型论文卡住的原因是数据没有、方法不存在、概念没想清楚。这里的阻碍就是“模型还不够好”。因此公告真正的贡献不在方法，而在产品本身（三个模型、200K 上下文、视觉能力）与宣称（基准领先）。

**方法与问题是否匹配？** 公告的“方法”是发布三个分层模型并附一张基准对比表。匹配点只有一半是真的。

分层发布确实回答了“不同需求的用户能不能各取所需”：Haiku、Sonnet、Opus 按智能、速度和成本分层。

但基准对比表并不真正回答“是否领先于当前同行”。表中的同行数字引自较旧的报告（原始 GPT-4，2023 年 3 月，而非 GPT-4 Turbo），评估条件（评估框架、提示、解码、种子）全未报告。

公告回答的是一个更容易的问题（“在一张表上 Opus 的数字更高”），而不是它宣称回答的问题（“Opus 是当前业界最强的模型”）。方法与问题不匹配。

**答案改变了什么？** 认知上几乎什么都没改变。公告没有提供任何可检验的机制解释（没有架构、数据或训练变化），也没有可复核的证据。因此关于“什么让模型变强”的信念不应改变。

实践上改变的是产品选择面：三个模型、200K 上下文、159 个国家 API 可用、ASL-2 安全级别。这些是真实、可查的产品事实，用户与开发者可以据此做选型。

榜单宣称本身应被视为“待验证”，直到出现同评估框架、当前检查点的复现。

### 价值判断

认知价值是低的。公告没有推翻或确认任何科学信念。它断言 Opus 领先，却没有提供可检验的机制或可复核的证据。读完之后，关于“什么让模型变强”的信念不应改变。

方法价值也是低的。公告没有留下别人能直接拿走复用的工具、范式、度量、实验设计或数据集。没有代码、数据、提示、评估框架或权重随公告发布。

唯一接近可复用的是一点方法描述：增强版大海捞针（30 组随机针和问题对、众包语料）与内部准确率测试的思路（正确、错误、不确定三分法）。但两者均未公开细节到可复用的程度。

边界价值是高的，这正是这份精读记录最有价值的部分。它明确不证明的东西包括：Opus 对当前同行（GPT-4 Turbo、Gemini 1.5 Pro）的领先；200K 上下文下的推理能力；视觉与多语言能力；拒绝率与偏见的数值改进；以及两倍准确率的实践规模。

读者最容易误读的推论，是把“表格数字更高”读成“模型全面更强”。边界写得越清，结论越可信。这篇公告可信的是产品与安全事实，不是榜单宣称。

启示价值在于，最便宜的决定性实验是同评估框架、当前检查点的重跑。具体设计在下面“接下来看什么”里写。

### 最弱的一环

最弱的一环在基准表和“新行业标准”之间。整张表的说服力，依赖于三件公告从来没有拿出来的东西。

第一，基准分数真的能代表通用能力。第二，对比是公平的：同行模型在可比条件下被评估，用相同的提示、评估框架、解码和模型版本。第三，测试集不在训练数据里，没有污染。

这三件东西都没有证据。表格数字不在可读文本中，同行检查点较旧，评估条件全未报告。

同行是 2023 年 3 月的原始 GPT-4，而不是 GPT-4 Turbo。MMLU 上 0.4 个百分点的差距，没有误差棒。放在约 14k 道题的测试上，这个差距远小于一次单运行评估任何合理的误差棒，却被当作胜利呈现。

Sonnet 的 MMLU 数字在两个来源里对不上：79.0% 对 78.3%。这是一个很小的症状，但它说明这些数字没法从已发布的材料里稳定地复现出来。

### 效度判断

下面是针对公告作为证据的评分，满分 5 分，评的是证据，不是模型本身。

内部效度 2 分。没有实验，经典内部效度威胁大多是“说不清”而非受控。适用的具体威胁是基线不对称（同行数字引自较旧报告）、可能的测试集污染（从未提及）、基准选择（表格只展示 Opus 领先的基准），以及准确率测试的测试集与评分器均未描述。

给 2 分而不是 1 分，是因为大海捞针程序至少部分有描述（30 组针和问题对、众包语料），而且比较对象至少具名。

外部效度 2 分。公告从一组狭窄的学术基准加一次检索测试，推广到“引领通用智能前沿”、“接近人类”这类断言。没有部署测量，没有用户研究。尽管宣称多语言，却无多语言数字；尽管宣称视觉，却无视觉数字。

200K 上下文宣称从检索推广到“有效处理长上下文提示”，比测试所支持的范围更宽。能推广的是可用性与产品事实。

构念效度 2 分。MMLU、GPQA、GSM8K 分数被当作“智能”、“专家知识”与“专家推理”，大海捞针召回被当作长上下文能力，BBQ 被当作偏见，一张拒绝率图表被当作“细致理解”。每一步都是层级跳跃，从分数跳到能力，再跳到理解，中间没有桥接证据。

公告自己的大海捞针细节具有两面性：模型识破人工植入的针，这表明测试测量的不是自然长文档使用中的东西。

统计结论效度 1 分。公告未报告任何统计量：除大海捞针的 30 对外，没有样本量；没有种子，没有运行次数，没有误差棒，没有置信区间，没有 p 值。

标题差距在可核查处很小（MMLU 上 Opus 86.8% 对 GPT-4 86.4%），却被当作胜利呈现且无不确定性。两倍准确率比值给出时没有绝对准确率，所以其实践规模无法从公告中得知。

可复现性 1 分。没有提示、没有评估框架、没有解码设置、没有种子、没有数据集版本、没有代码、没有权重、没有训练数据。唯一可复现的是产品事实（上下文窗口大小、可用性）。

甚至基准表也无法仅从公告推导出来，因为数字在图片中，而且本次精读期间未能抓取模型卡 PDF。有 API 访问权限的读者原则上可以重跑 MMLU，但必须猜测每一个评估选择。

### 其他可能的解释

同一张表，至少有三种别的解释也能说得通。

第一种是新旧之差。Opus 在表中领先，主要是因为对比的是较旧的同行检查点，特别是 2023 年 3 月的原始 GPT-4，而非 GPT-4 Turbo。领先的部分可能是新旧之差，而非能力跃升。

这种解释预测，在同评估框架下对上当前检查点时，领先会缩小或反转。而“更强的模型”这种解释预测领先持续。区分证据是同日期、同评估框架下对 GPT-4 Turbo 与 Gemini 1.5 Pro 的对比。

第二种是针对报告基准的提示与评估框架调优。Anthropic 的数字反映的是为这些基准调优过的提示、few-shot 数与解码选择（例如 GPQA 和 MATH 用 0-shot 思维链），而同行数字取自同行在不同设置下的报告。

这种解释预测，排名对提示与评估框架的选择敏感。区分证据是以相同提示与解码重跑所有模型。如果排名移动，调优的解释就成立。

第三种是基准与部署之间的差距。基准衡量的是特定格式下的应试，Claude 3 被调优以适应这种格式。真实任务表现（开放式、多轮、工具使用）可能不同。

这种解释预测，基准排名与部署任务排名分歧。区分证据是智能体任务或长时程任务上的评估，或用户结果数据，而不是静态问答基准。

第四种是污染。部分基准题目（或近似重复）可能出现在 2023 年 8 月截止的训练混合中，抬高了分数。

这种解释预测，在去污染或截止期后新写的测试集上分数下降，而“能力”的解释预测分数保持。区分证据是去污染审计，或截止期后新写的基准。

### 什么观察能反驳这些宣称

基准领先的宣称可以这样检验：在同一个评估框架里重跑，用具名的当前检查点（GPT-4 Turbo、Gemini 1.5 Pro）、明确的提示与固定种子。如果 Opus 在 MMLU、GPQA、GSM8K、HumanEval 多数项上不再领先，或者 MMLU 的差距落进误差棒里，“在大多数常用基准上超越同行”作为关于当前同行的陈述就被反驳了。

速度宣称可以这样检验：独立延迟测量，用固定提示集、固定输出长度、明确并发。如果 Sonnet 并非约两倍于 Claude 2 / 2.1，或者 Haiku 阅读带图的 10k token 文档耗时显著超过 3 秒，速度宣称就被反驳了。

视觉平齐的宣称可以这样检验：Opus 在标准视觉基准（例如 MMMU、MathVista、ChartQA）同评估框架对比中显著低于 GPT-4V / Gemini，“与其他领先模型平齐”就被反驳了。

拒绝改进的宣称可以这样检验：用一组留出的、边缘但无害的提示，如果 Claude 3 的拒绝率与 Claude 2.1 相同，拒绝改进就被反驳了。

准确率提升的宣称可以这样检验：重跑内部准确率测试，或者用等效的已发表事实性基准（例如 SimpleQA 风格）。如果没有发现对 Claude 2.1 约两倍的提升，或者发现绝对准确率仍然很低，改进宣称就被反驳了。

长上下文的宣称可以这样检验：用一个需要在全上下文内综合（而非针检索）的长上下文基准。如果 Opus 在 200K token 之前就远低于其短上下文表现，“有效处理长上下文提示”就被反驳了。

安全级别的宣称可以这样检验：一份有记录的能力评估显示 Claude 3 跨越 ASL-3 阈值（例如显著助长生物武器相关工作或自主复制），安全级别宣称就被反驳了。

文末的战略信念（处于前沿最能引导 AI 走向积极结果）按现状是不可反驳的。它是战略信念，不是经验主张。需要先把它操作化（例如前沿领导地位会改变的某个可测量结果），才能写出反驳它的观察。

### 接下来看什么

最值得先做的，是同评估框架、当前检查点的重跑。在公开评估框架中，用固定提示、固定解码与固定种子，重跑 MMLU、GPQA、GSM8K 和 HumanEval，对比 `claude-3-opus-20240229` 与 GPT-4 Turbo、Gemini 1.5 Pro，报告误差棒与运行次数。

判据很简单：如果 Opus 不再在多数项上领先，或者 MMLU 的差距落进误差棒里，领先的宣称就站不住；如果领先在紧的置信区间下成立，宣称就升级为可信。

这件事成本最低，只需要 API 访问与公开评估框架，不需要训练。信息量也最大，它直接裁决最承重的宣称。

其次是直接读到完整的 Claude 3 模型卡。这一份文档能解决大多数未核实项：能力表、视觉和多语言数字、BBQ 数字、拒绝率、红队摘要，以及任何关于污染的讨论。

再往后看三件事：超过检索的长上下文评估，在 100K 到 200K token 上做综合和推理；承诺的引用功能和任何已发表的事实性评估，用绝对准确率检验两倍的说法；后续 Claude 3.5 的评估（2024 年 6 月已发表），作为 Claude 3 数字的一致性检查。Sonnet 的 MMLU 差异（79.0% 对 78.3%）应该以原始表格为准解决。

最后是训练数据构成的任何披露，或者针对报告基准的去污染审计。

### 声称的贡献和实际支持的贡献

公告声称的贡献是树立新的行业标准与前沿领导地位。文本本身支持的范围要窄得多：一组被断言的基准胜利，加上若干具体、可核查的产品事实。

作为一份文档，公告的“贡献”是发布本身：三个模型、按智能、速度和成本分层定价、API 在 159 个国家全面可用、Bedrock / Vertex 上线。而不是一项科学发现。

如果领先的宣称是假的，对用户的实际后果不大（一个很强但第二名的模型），但对 Anthropic 的定位宣称影响很大。

清晰度方面，给 3 分（满分 5 分）。对一般读者和企业读者，行文清晰、结构良好。作为技术文档，它是不透明的：标题基准表的数字不在正文里，内部准确率测试没有定义，没有误差棒，关键限定词（“大多数”、“接近人类”、“显著”）从来没有被操作化。

## I. 结论、结果与价值总览

### 一句话结论

作为产品发布，它可信地宣布了 Claude 3 三模型、200K 上下文与 ASL-2；作为“Opus 树立智能新标准”的证据，它不成立。标题基准数字未核实，对比用的是较旧的同行检查点，没有任何数字带不确定性。

### 核心结论

1. **产品事实确立（置信度：高）。** 三模型分层发布、发布时 200K 上下文窗口、API 在 159 个国家可用、ASL-2 安全分级，都是公告正文直接陈述、可核查的事实。

2. **大海捞针召回确立，但只证明检索，不证明长上下文推理（置信度：中）。** 测试的上下文长度、提示数量、解码、种子均未报告，而且公告自己承认针可被识别为人工植入物。

3. **基准领先未确立（置信度：低）。** 标题数字全部出自数字台账 2，未对照原始公告页或模型卡 PDF 核实。对比的是 2023 年 3 月的原始 GPT-4 而非 GPT-4 Turbo。没有任何误差棒。

4. **速度与准确率宣称不可用（置信度：低）。** Sonnet 快两倍，没有任何工作负载、硬件、并发或百分位条件。Opus 准确率提升两倍，只有比值，没有绝对准确率与测试集描述。Haiku 不到 3 秒只是单一工作负载。

5. **视觉、多语言、拒绝率、偏见的数值改进未确立（置信度：低）。** 公告只有“平齐”、“更少拒绝”这类词，没有数字，全部推迟到抓取失败的模型卡。

### 关键结果

发布时上下文窗口是确立的。发布时最初提供，三个模型均如此。

大海捞针召回确立为检索，不确立为推理。每条提示用 30 组随机针和问题对，文档是众包语料。上下文长度、提示数、解码、种子未报告。没有同行数字。

Sonnet 的速度是不可用的。没有任何条件：没有工作负载、硬件、并发、百分位。

Opus 的准确率提升是不可用的。没有绝对准确率，没有测试集描述。

Haiku 的阅读速度只对单一工作负载部分支持。条件是一篇约 10k token 的 arXiv 论文，含有图表。没有输出长度、并发、百分位。

标题基准数字是未核实的，不作为已确立的结论引用。它们不在抓取到的公告文本中，模型卡 PDF 抓取失败。

### 科学价值总评

认知价值是低的。没有推翻或确认任何科学信念。读完之后，关于“什么让模型变强”的信念不应改变。

方法价值是低的。没有留下可复用的工具、范式、度量或数据集。唯一接近可复用的只是增强版大海捞针的思路与内部准确率测试的三分法，而且细节未公开到可复用的程度。

边界价值是高的，这是这份精读记录最有价值的部分。它明确不证明：对当前同行（GPT-4 Turbo、Gemini 1.5 Pro）的领先、200K 上下文下的推理能力、视觉与多语言能力、拒绝率与偏见的数值改进、两倍准确率的实践规模。最容易误读的推论是把“表格数字更高”读成“模型全面更强”。

启示价值在于，最便宜的决定性实验是同评估框架、当前检查点的重跑。在公开评估框架中用固定提示、固定解码与固定种子重跑 MMLU、GPQA、GSM8K 和 HumanEval，对比 `claude-3-opus-20240229` 与 GPT-4 Turbo、Gemini 1.5 Pro，报告误差棒与运行次数。

总体 verdict 是：这篇工作值得被记住的，是作为 2024 年 3 月 Claude 3 发布的事实记录（三个模型、200K 上下文、ASL-2、大海捞针检索结果）。不值得被记住为“Opus 领先”的证据。

### 适用边界

不要用这份公告论证 Opus 是当时最强的模型，不要用大海捞针论证 200K 上下文下的推理能力，不要引用台账 2 的任何基准数字为已确立的结果。

可以引用的是发布事实（模型分层、上下文窗口、可用性、ASL-2）与大海捞针检索结果。引用后者时，须同时说明它只测检索。
