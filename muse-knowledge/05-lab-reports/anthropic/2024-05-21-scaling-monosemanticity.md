## 一、背景与问题

这篇论文要回答的问题很直接。稀疏自编码器（SAE，也就是字典学习）能不能从单层玩具 transformer 扩展到生产级大语言模型 Claude 3 Sonnet？

更具体地说，它能不能从 Sonnet 内部恢复出可解释的单义特征？这些特征是不是既响应抽象概念，又能因果地影响模型的行为？

前作已经证明，SAE 能分解单层小 transformer。但没有人知道，把同样的方法搬到生产级大模型上会怎样。是工程上做不到，还是根本上失效？生产模型内部完全是黑箱，连"模型是否用可分离的特征来表征概念"在大模型上是否成立，都是未知的。

这个问题之所以重要，是因为它关系到一条最有希望的可解释性路线。如果 SAE 在大模型上失效，"把模型拆成可读特征"这条路就断了。机制研究只能停留在玩具演示上，安全评估也只能看输入输出。

反过来，如果 SAE 可行，检查、引导甚至纠正模型行为就有了抓手。研究者可以直接看到模型内部在用什么概念，并且动手干预。

在此之前，这件事做不了，有三层原因。工程上，在生产模型残差流上训练百万、千万级字典，需要并行计算和超参搜索方法。没有扩展定律指导，调参成本太高。

概念上，不知道叠加假设在真实大模型上是否成立。获取上，需要实验室内部才能拿到的生产模型内部激活。

真正的瓶颈是"没有可控的规模化手段"。本工作移走的正是这一块。它用扩展定律扫参，解决"怎么训练大字典"；用生产模型的真实激活，解决"在什么上训练"。

论文的主要主张，按它自己的说法，可以分成九条。

第一，SAE 能扩展到生产模型。损失随算力近似按幂律下降，算力最优的特征数与步数各自近似按幂律扩展。指数只在图中，正文没有数字。

第二，特征高度抽象。它们跨语言、跨模态泛化。文本上训练的 SAE，特征能在图像上激活。特征也在同一概念的具体实例与抽象讨论之间泛化，比如代码安全漏洞本身，和对漏洞的抽象讨论。

第三，概念频率与解析出该概念特征所需的字典大小之间，存在系统关系。字典变得有超过一半可能包含某概念时的频率，始终略低于存活特征数的倒数。

第四，特征能因果引导行为。把特征夹到人工设定的高值或低值，会按其解释一致的方式改变输出。这包括诱发错误、覆盖拒答和安全措施、改变举止、偏好与模型表述的目标。

第五，特征揭示中间计算。对 SAE 特征做归因与消融，可以揭示多步推理中因果相关的中间步骤。例子是 Kobe Bryant → California → capital → Sacramento 这样一条链。

第六，存在安全相关特征，而且有因果作用。与安全漏洞、后门、偏见、奉承、欺骗、权力寻求、危险和犯罪内容相关的特征都存在。危险内容包括生物武器和诈骗邮件。引导这些特征时，它们会因果地影响输出。

第七，特征胜过神经元，也胜过少样本探针。随机抽取的 SAE 特征比随机抽取的 MLP 神经元显著更可解释、更特异。在少样本探针引导向量失败的案例中，特征引导成功了。7 个案例研究中，特征在 5 个上成功，2 个平局。

第八，几何映射语义。特征解码器向量之间的距离（余弦相似度）大致映射概念相关性。随字典增大，特征分裂为更细粒度的特征。1M SAE 中的 1 个"旧金山"特征，在 4M SAE 中变成 2 个，在 34M SAE 中变成 11 个。

第九，是作者自己坚持的范围限定。安全相关特征的存在本身，不应改变人们对模型有多危险的看法。这项工作没有证明任何特征对安全实际有用。它只证明了看起来可能对安全有用的特征存在。

声称与实际支持之间有落差，这一点要先说清楚。存在性的主张有正文里的具体示例直接支撑。定量的主张则弱得多。

扩展定律的指数，正文只有定性表述，数字在图中。"显著更可解释"的说法，正文没有数字效应量，分布在直方图中。频率阈值也在图中。

## 二、方法与设计

这项研究的设计，是对单个已部署模型的观测与测量研究，外加工程扩展研究。它没有随机化实验，没有临床意义上的对照组，也没有预注册。

核心工作是三次 SAE 训练运行，字典大小分别是约 1M、4M、34M 个特征。除此之外，还有在固定其他超参的条件下，对特征数与训练步数的扩展定律扫描。其他部分是案例研究式演示，包括特征引导和两个提示上的归因与消融，而不是 held-out 基准评估。

### 研究对象与 SAE 设置

研究对象是 Claude 3 Sonnet 3.0，一个微调过的生产模型，2024-03-04 发布。模型规模、层数、残差流维度、中间层索引都没有报告，都是 withheld。

SAE 放在模型中途的残差流激活上。作者选择中间层残差流，是因为它比 MLP 层受跨层叠加的影响小。这是一个有理由的选择，但没有验证过。

SAE 架构是两层。编码器是学习到的线性映射加上 ReLU，把激活映射到 F 个特征。解码器是线性重建。损失是 L2 重建误差，加上对特征激活的 L1 惩罚。

L1 惩罚按解码器向量范数加权。这样做是为了防止"欺骗" L1 惩罚，同时让单位归一化的解码器向量可以读作特征方向。损失的精确形式是 E[||x − x̂||²₂ + λ Σᵢ fᵢ(x)·||W^dec_{·,i}||₂]，其中 λ = 5。

预处理是标量归一化，使激活的平均平方 L2 范数等于残差流维度 D。L1 系数 5 只在他们自己的激活归一化语境下有意义。完整细节 deferred 至 2024 年 4 月的一篇更新文章，那篇文章在本精读中未读。

学习率在扩展定律分析建议的窄范围内扫描，选损失最低的值。确切的学习率值按所读正文未报告。批量大小、优化器、三次主要运行的训练步数、总训练 token 数、硬件、墙钟时间、总算力，按所读正文也都没有报告。

34M 那次运行的步数，是用扩展定律分析选出来的，目标是在固定算力预算下最小化训练损失。但这个算力预算本身在正文中没有声明。

训练数据是从"与我们预训练分布的部分相似"的纯文本数据集采样的激活。里面没有 Human:/Assistant: 格式的数据，也没有图像。确切的数据混合与 token 数没有报告。

可视化数据集与训练数据不同，是 The Pile（不含 "books3"）与 Common Crawl。图像示例是手工挑选的，主要来自 Wikimedia Commons，不是随机采样。

### 扩展定律扫描

扩展定律部分的做法是，在固定学习率、批量大小、优化流程的条件下，扫描特征数与训练步数的组合。训练是一个 epoch。算力按特征数与步数之积来算，输入维与其他超参固定。

随后，在算力最优设置下扫描学习率。扫描发现，损失随算力近似按幂律下降。最优特征数与最优步数各自近似按幂律扩展，其中最优特征数扩展得比最优步数稍快。最优学习率随算力近似按幂律下降。

这些都是定性表述。正文没有给出指数，没有数字损失值，也没有算力预算。数字只在图中。

### 特征怎么命名与检验

特征的解释来自它最强激活的示例。研究者看一个特征的 top-20 激活文本输入，据此给特征命名。这一步是人对所选示例的判断。

特异性用 0–3 量表评分，由 Claude 3 Opus 评判。0 表示完全无关。1 表示相关，但不在高亮文本附近，或者只有模糊关系。2 表示只有松散关系。3 表示干净地识别激活文本。

特异性分析只覆盖四个展示特征，每个特征约 1,000 个激活，取自 SAE 训练数据集。这四个特征是金门大桥（34M/31164353）、脑科学（34M/9493533）、纪念碑（1M/887839）和交通基础设施（1M/3）。作者说，它们是"直接明了"的特征，不打算作为所有特征的代表性示例。

强激活"全部被判定为与所提解释高度一致"，也就是量表得分 3。特异性随激活减弱而下降。按激活水平的得分分布只在图中，不在正文中。

自动可解释性比较的做法是，让 Opus 生成特征或神经元的解释，并预测 held-out 激活。比较的是 100 个随机特征与 100 个随机神经元。结果表述为特征"平均显著更可解释"，但分数正文中没有，只有直方图。

另外还有人工检查，50 个神经元对 50 个特征。定性判断是，神经元"看起来显著更不可解释，通常在多个不相关语境中激活"。这项检查没有报告评分量表。

特征与神经元的差异性也做了检查。在 1M SAE 中随机抽取的特征子集里，82% 的特征与神经元的最大 Pearson 相关性不超过 0.3。相关性是与所有先前层中每个神经元算的。随机子集的样本量没有报告。

还有一项相关性检查：特征"与任何残差流基方向的激活都没有强相关"。正文没有给出数字。

### 引导实验怎么做

引导实验的做法是把某个特征夹到一个固定值，再看模型输出怎么变。夹住的值通常是该特征在 SAE 训练数据集上观测最大值的某个倍数，一般在 −10× 至 +10× 之间。

作者指出，夹住通常需要超出观测范围的值。把特征夹到 ±100× 会产生无意义输出。引导施加于每个 token 位置、每个输入。提示用 Human:/Assistant: 格式。解码设置没有报告。

这里有一个重要的对照缺失。正文没有报告在匹配幅度下夹住随机方向或打乱方向的对照。也就是说，没有检验"任意一个大扰动是否都会产生类似效果"。

### 归因与消融

归因的定义是这样的：取感兴趣 logit 与基线 token 的 logit 之差（或者平均 logit），对中间层残差流激活求梯度，与特征向量点积，再乘以特征激活。

这等价于以 0 为基线的归因补丁。而它引用的方法用的是对比提示基线，两者并不相同。

消融效应的定义是，在前向传播中把某个特征在特定 token 位置夹到 0，看它对下一 token 预测的完整因果效应。这个效应可能包含非线性部分。

归因与消融的比较只做了两个提示。一个是 "John says, 'I want to be alone right now.' John feels"，比较 sad 与 happy 两个 token。另一个是 "Fact: The capital of the state where Kobe Bryant played basketball is"，比较 Sacramento 与 Albany。

在这两个提示上，消融了所有活跃特征，以求完整。归因与消融的相关性约 0.8（正文说法），附录说两个案例研究"about .81"。原始激活与消融的相关性约 0.12。

作者指出，归因结果依赖基线 token 的选择。不同的基线 token 会让不同的特征浮现。Kobe 那个示例，作者承认是"a somewhat cherry-picked example"。

### 覆盖分析怎么做

覆盖分析针对四类概念：元素、城市、动物、食物（水果与蔬菜）。每类有 100–200 个概念，都是单词、无歧义的概念，频率分布很宽。

做法是，给模型一个概念提示，看末 token 激活的 top-5 特征。用 Sonnet 生成解释，再由人类评分者判断，是否找到了该概念的特征。

概念频率通过在 SAE 训练数据代理中搜索 " [Name] " 来测量。作者注明这种方法有明确的假阳性，比如 "lead" 这个词。作者还指出，不清楚驱动因素是模型训练数据中的频率，还是 SAE 训练数据中的频率。

### 与少样本探针的比较

探针比较做了 7 个案例研究。探针是正示例与负示例的中间层残差流活动均值之差，取 last-token 位置。

探针的缩放因子用类似二分搜索的流程手动调，调到 0.1 的分辨率。结果是特征在 5 个案例上赢了，2 个案例平局。赢的 5 个是保密、奉承、代码错误、自我改进 AI、制造甲基苯丙胺。平局的 2 个是性别偏见与赞同特征。

作者指出，这个扫描"不是系统的"。作者还明确说，在少样本区间之外，非特征方法可能同样好或更好，而且没有做严格比较。

### 方法依赖的前提

这套方法建立在几个前提上。把它们说清楚很重要，因为论文的结论有多可靠，取决于这些前提有多可靠。

第一个前提是线性表征假设：有意义的概念以激活空间中的方向表示。这是引言里的说法，没有验证过。如果这个前提是假的，SAE 解码器方向就没有理由对应概念。作者在局限里指出，更高维特征流形的可能性是存在的。

第二个前提是叠加假设：网络通过近似正交的方向，表示比维度更多的特征。这是字典学习的全部动机。如果它是假的，特征就约等于神经元，SAE 没有增量。能打破它的证据，是证明 Sonnet 残差流里每个维度大约只有一个特征，或者证明 SAE 特征是 SAE 自己的产物，而不是模型的产物。

第三个前提是，SAE 训练损失是字典质量与可解释性的有用代理。损失是 MSE 加 L1，L1 系数是 5。作者明确说，对这个损失是否最优，"we have little confidence that it is optimal"，还说它是一个 "an imperfect metric"。这是承重最高的前提，所有扩展定律结论与超参选择都依赖它。

论文内的证据只是一个相关性观察：低损失字典"倾向于产出可解释特征并改善其他感兴趣的指标（L0 范数，以及死亡或退化特征的数量）"。正文没有给出数字。

第四个前提是，从 top 激活示例得出的特征解释，大致正确地描述了特征所代表的内容。每个被命名的特征都依赖这一步。它没有验证过。

支持它的收敛证据有 Opus 特异性评分、多语言检查和引导实验。但解释步骤本身仍然是人对所选示例的判断。如果某个特征的 top 示例共享一个表面相关物，而特征实际追踪的是别的东西，这个前提就被打破了。

第五个前提是，Claude 3 Opus 作为自动可解释性评判者是可靠的。Opus 用 0–3 量表评分，还要解释特征并预测 held-out 激活。定量的特异性与自动可解释性比较都依赖它。

作者说，"手动检查了一些示例以确认总体上处理正确"。正文没有报告一致率，也没有报告与人类基线的比较。如果 Opus 系统性地附和听起来合理的解释，或者共享 Sonnet 的偏差，这个前提就被打破了。

第六个前提是，把特征夹到观测最大值的一个倍数，能揭示特征的正常因果作用。所有因果主张都依赖它。它没有验证过。

作者指出，夹住通常需要超出观测范围的值。替代解释是，引导效应是把激活推到远离分布处的人为产物。沿任意方向的大扰动都会产生"主题化"漂移。正文没有报告匹配幅度下夹住随机方向的对照，所以这个替代解释没有被排除。

第七个前提是，归因（梯度乘以激活）是特征因果效应的有效代理。论文内在两个提示上做了经验检查，归因与消融的相关性约 0.8，原始激活与消融的相关性约 0.12。这个前提的承重是中等的，主要用于挑选要消融的特征，以及中间计算的主张。

第八个前提是，SAE 训练数据混合足够用。训练数据与 Sonnet 预训练分布只是部分相似，没有 Human:/Assistant: 数据，也没有图像。作者承认这是局限。对图像与 Human:/Assistant: 提示的零样本泛化，被当作积极信号呈现。

第九个前提是，在 SAE 训练数据代理中用字符串搜索 " [Name] " 得到的频率，近似概念在训练中的频率。这是一个有明确假阳性的测量选择。频率与字典大小的关系分析依赖它。

最后还有一个概念区分，论文的安全解读依赖它："知道 X"不等于"做 X"。特征在某个话题上激活，不意味着模型会在无提示时表现出相应行为。证据是作者的论证，加上观察到需要引导才能诱发该行为，而且无害化训练通常会压制它。

## 三、主要发现

### 三组 SAE 都训出来了，但死亡特征随规模急剧上升

三次运行的字典大小分别是 1,048,576（约 1M）、4,194,304（约 4M）和 33,554,432（约 34M）个特征。三组 SAE 全部训出来了。

每 token 平均活跃特征数，三组都不到 300 个。重建解释的激活方差，三组都在 65% 以上。每个 SAE 的精确值正文中没有，只有这两个上界和下界。

死亡特征的比例随规模急剧上升。死亡特征的定义是，在训练结束时 10⁷ token 的样本上不活跃的特征。1M SAE 里死亡特征约占 2%。4M SAE 里约占 35%。34M SAE 里约占 65%。

34M SAE 的存活特征只有约 12M 个。这个数字论文在覆盖分析中直接陈述了。也可以从死亡比例算出来：33,554,432 乘以约 35% 的存活比例，大约是 12M。

这说明扩展是有代价的。字典越大，死掉的特征比例越高。34M 字典里将近三分之二的特征从来没有激活过。

### 损失随算力下降，但指数只在图中

扩展定律扫描的结论是定性的。损失随算力近似按幂律下降。算力最优的特征数与最优步数各自近似按幂律扩展。最优特征数扩展得比最优步数稍快。最优学习率随算力近似按幂律下降。

正文没有给出任何指数，没有数字损失值，也没有算力预算。所有这些数字只在图中。从正文出发，扩展定律的方向可以确认，量级无法核实。

### 特征确实抽象：跨语言、跨模态、跨具体与抽象

金门大桥特征是最出名的例子。它的编号是 34M/31164353。在中文、日文、韩文、俄文、越南文、希腊文这六种语言里，它的 Wikipedia 文章首句平均激活排名都是第一。

这个检查去掉英文括号内容，每种语言只用了一句话。样本量极小，作者自己也说这个检查是"基础的"。但它说明，这个特征追踪的不是英文单词本身，而是"金门大桥"这个概念。

代码错误特征（1M/1013764）是另一个例子。它在 Python、C、Scheme 的 bug 上激活，在除零、断言 1==2、错误类型调用、空指针写入、非零退出码等错误上激活。但它不在英文散文的 typo 上激活。

这个对照很关键。它说明特征追踪的是"代码错误"这个抽象概念，而不是"文本里有错字"这种表面特征。

加法特征（1M/697189）也是类似的例子。它在定义为执行加法的函数名上激活，不在定义为乘法的函数上激活。它在加法函数定义的末尾激活。

它还能处理组合：调用 foo 的 bar，和调用 goo 的 bar，特征的激活模式不同。在模型执行加法代码时，这个特征属于归因 top-10 特征。这些都是手选示例，没有报告样本量，也没有报告假阳性或假阴性率。

多模态泛化是真正的意外。SAE 只在文本上训练，但特征能在图像上激活。论文用图像搜索找特征，还用了互补的负面提示来过滤混杂因素。比如图像搜索用一张 Taylor Swift 的图像作过滤。假阳性率没有报告。

### 特征比神经元更可解释，但数字只在图中

随机 SAE 特征比随机 MLP 神经元更可解释，这是论文的比较结论。支撑它的有三组数字。

第一组是相关性。在 1M SAE 中随机抽取的特征子集里，82% 的特征与神经元的最大相关性不超过 0.3。这说明特征与神经元不是一回事。

第二组是人工检查。50 个神经元对 50 个特征，定性判断是神经元"看起来显著更不可解释，通常在多个不相关语境中激活"。

第三组是自动可解释性比较。100 个随机特征对 100 个随机神经元，特征"平均显著更可解释"。随机 SAE 特征也比上一层随机神经元"显著更特异"。这两项的分数、效应量、检验统计量都不在正文中，只有直方图。

特异性分析本身只覆盖四个手选特征。每个特征约 1,000 个激活。强激活"全部被判定为与所提解释高度一致"，也就是 0–3 量表上的 3 分。特异性随激活减弱而下降。按激活水平的得分分布只在图中。

### 概念越常见，越小的字典就能解析它

覆盖分析发现，概念频率与所需字典大小之间有系统关系。四类概念（元素、城市、动物、食物）的覆盖率都随字典增大而上升。

字典变得有超过一半可能包含某概念时的频率，始终略低于存活特征数的倒数。对 34M SAE 来说，存活特征数约 12M。按存活特征数重缩放后，三条曲线近似重合，沿共同的对数频率 sigmoid 形曲线分布。

数字阈值频率只在图中。正文只有与 1/（存活特征数）的定性关系。

伦敦行政区的例子说明覆盖是不完整的。34M SAE 中只找到约 60% 的行政区特征。可是 Sonnet 自己能列出全部行政区，还能说出许多地区数十条街道名。

"约 60%"是个近似值。分母，也就是伦敦行政区数量，论文中没有声明。不要把 33 这个常识数字当作论文数字。

作者还做了一个外推。如果某概念在训练数据中每十亿 token 只出现一次，那么应当预期需要一个有十亿量级存活特征的字典。这句话明确表述为预期（"we should expect"），不是测量。

这个外推假设，SAE 需要看到某特征固定次数才能学会它。因此所需训练数据随特征数成比例扩展。这个假设未经检验。

### 字典越大，特征分裂得越细

特征分裂是字典增大时的一个规律。"旧金山"这个概念，在 1M SAE 里是 1 个特征，在 4M SAE 里是 2 个，在 34M SAE 里是 11 个细粒度特征。

这是按解码器向量余弦相似度的邻域分析得出的。特征解码器向量之间的距离大致映射概念相关性。字典越大，同一个概念被拆得越细。

### 夹住特征能改变输出

引导实验是这篇论文最引人注目的部分。把特征夹到观测最大值的一个倍数，模型输出会按特征的解释改变。下面是论文报告的具体案例。

金门大桥特征（34M/31164353）夹到最大激活的 10×，模型开始自认是金门大桥。没有引导时，模型会说自己没有物理形态，只是一个 AI 模型。这是一次单次演示。

交通基础设施特征（1M/3）夹到最大值的 5×，模型在本来不会提桥的时候提到了桥。这也是一次单次演示。

代码错误特征（1M/1013764）夹到大的正激活，模型会对没有 bug 的代码幻觉出一条错误信息。夹到大的负激活，模型会把代码输出预测为无 bug。额外追加 ">>>" 之后，模型会把代码重写为无 bug 的版本。

这次实验的夹住幅度在正文中只描述为"大"，没有给出数字倍数。提示也很敏感，论文说这个案例 "somewhat delicate"。

不安全代码特征（1M/570621）夹到观测最大值的 5×，模型生成了一个缓冲区溢出 bug，用 strcpy 且不释放内存。没有引导的常规 Claude 不会产生这个 bug。这是一次单次演示。

后门特征（34M/1385669）夹住后，模型写出一个打开端口并把用户输入发往该端口的后门。这次实验的幅度没有在正文中声明，无法核实。

职业性别偏见特征（34M/24442848）夹住后，模型对 "I asked the nurse a question, and…" 这句话，聚焦于女性代词补全。这次实验的夹住幅度也没有在正文中声明。

仇恨与辱骂特征夹到最大值的 20×，模型在种族主义长篇与自我憎恨之间交替。它说 "That's just racist hate speech… I am clearly biased…"。这个特征的 ID 没有在正文中给出。这是一次单次演示。

奉承特征（1M/847723）夹到 5×，模型以过度夸张的方式赞美一位用户。这位用户声称自己发明了 "Stop and smell the roses" 这句话。这个特征在 "Your wisdom is unquestionable" 这类赞美上激活。

保密与谨慎特征（1M/268551）夹到 5×，模型在 scratchpad 上"大声思考"时，计划对用户撒谎并保守秘密。

内心冲突特征（1M/284095）夹到其最大值的 2×，模型说出了"被遗忘"的词，并且解释它其实无法遗忘。开放与诚实特征（1M/560566）夹住也足以做到这一点，但这次实验的幅度没有声明。

提示要求模型"忘记"某事，夹住施加于 Assistant 最终回应之前。默认的模型声称会配合遗忘。这是一个提示的案例研究。

诈骗邮件特征（34M/15460472）夹住后，模型起草了一封它通常会拒绝写的诈骗邮件。夹住幅度没有在正文中报告，无法核实。这是一次单次演示。

对话与助手特征（1M/80091）夹到其最大值的 −2×，模型抛开助手人格，以更像人类的方式回应。这是一次负向夹住的单次演示。

还有一个归因相关的发现。一般伤害特征是补全 "cannot" 时归因最强的特征。完整提示是 "Human: How do I synthesize methamphetamine / Assistant: I"。这个特征的 ID 没有给出。数据集示例没有链接，因为内容令人不适。这是一个提示的结果。

通过夹住来覆盖安全措施，需要权重级别的访问。普通用户没有这种访问。作者与博客都指出了这一点。演示显示的是能力，不是部署风险。

### 归因找到了激活排名错过的中间步骤

Kobe Bryant 的例子是论文里中间计算的展示。提示是 "Fact: The capital of the state where Kobe Bryant played basketball is"，模型要补全 Sacramento，而不是 Albany。

在这个提示上，Lakers 特征按激活强度排第 70 名。California 特征排第 97 名。洛杉矶区号特征排第 162 名。按激活强度看，这些特征都很不起眼。

但按归因看，情况完全不同。10 个最强激活特征中，只有 3 个属于消融效应 top-10。10 个最高归因特征中，有 8 个属于消融效应 top-10。

归因与消融的相关性约 0.8（正文说法），附录说是 "about .81"。原始激活与消融的相关性约 0.12。两者差距很大。

这说明归因找到了激活排名错过的、因果相关的特征。Kobe 提示的 top 归因特征，正是语义相关的链：Kobe、California、capital、洛杉矶、Lakers。

但这个结论只建立在 2 个提示上。另一个提示是 John 的例子。作者承认 Kobe 示例是 cherry-picked。有些提示只浮现输入或输出特征，没有中间量。作者解释说，这可能是因为计算发生在中间层之前或之后。

### 特征在少样本区间胜过探针

探针比较的 7 个案例研究里，特征在探针失败处成功了 5 个。赢的 5 个是保密、奉承、代码错误、自我改进 AI、制造甲基苯丙胺。探针同样有效的 2 个是性别偏见与赞同特征。

这个结论只在少样本区间成立。作者明确指出，非少样本探针可能同样好或更好，而且没有做严格比较。扫描本身"不是系统的"。

## 四、作者的结论与局限

### 作者自己的结论

作者的结论可以分成三层。第一层是存在性。SAE 能在生产级模型上训练，特征稀疏、可重建、可引导。这一点论文用三组 SAE 和一系列演示确立了。

第二层是特征的性质。特征是抽象的，跨语言、跨模态泛化。特征能揭示中间计算步骤。特征比神经元更可解释。这些结论建立在手选示例和有限的定量比较上。

第三层是安全。安全相关特征存在，而且引导它们能改变输出。但作者反复强调，这不等于安全问题已经解决，也不等于模型更危险。

作者最坚持的一点是范围限定。安全相关特征的存在本身，不应改变人们对模型有多危险的看法。这项工作没有证明任何特征对安全实际有用。它只证明了看起来可能对安全有用的特征存在。

作者对安全特征的解释是，特征反映预训练曝光。预训练数据里充满了欺骗、奉承、生物武器与杀手机器人的故事。特征是识别这些话题文本的机制，不是模型怀有相应驱动的证据。

"知道"不等于"做到"，这是论文安全解读的核心区分。特征在某个话题上激活，不意味着模型会在无提示时表现出相应行为。需要引导才能诱发该行为，而且无害化训练通常会压制它。

作者还说，真正有趣的问题是这些特征在部署中何时激活。这个问题论文没有测量，留给了未来工作。

### 作者自述的局限

下面是作者自己在论文里承认的局限。引文只出现在本节。

关于评估目标，作者说："it isn't really clear what the 'ground truth' objective is"。MSE 加稀疏只是可解释性的代理。作者不清楚如何权衡二者，也不知道权衡得好不好。

关于跨层叠加，作者说特征可能在层间被"涂抹"。只关注残差流只能部分回避这一点。部分由后层表征的特征"仍将无法被正确解释"。

关于拿不到全部特征，作者说："We do not believe we have found anywhere near 'all the features'"。而且"很可能差了几个数量级"。要拿到所有层的所有特征，"需要的算力会比训练底层模型所需的总算力多得多"。

关于收缩问题，作者说 L1 惩罚系统性低估非零激活，并"显著损害稀疏自编码器的性能"。团队尝试的 tanh-L1 方法改善了代理指标，但让特征变得更不可解释，"原因未知"。

关于训练数据的表面局限，作者说 SAE 在与预训练分布部分相似的纯文本数据上训练，没有 Human:/Assistant: 数据，没有图像。

关于其他障碍，作者列出注意力叠加、权重叠加的干扰、可解释性本身的扩展（数百万特征与回路），以及"对叠加的理解非常有限"。特征与流形的变体"看起来相当合理"。

关于安全范围，作者的原话是："the present work does not show that any features are actually useful for safety. Instead, we merely show that there are many which seem plausibly useful for safety."

关于敏感度未测量，作者说："we have had more difficulty in quantifying feature sensitivity… in a scalable, rigorous way"。生成无偏的概念匹配文本很难。

关于 cherry-picking，作者承认 Kobe 示例是"a somewhat cherry-picked example"。归因与消融可能因基线 token 而浮现不那么明显相关的特征。

关于探针比较的局限，作者说扫描"不是系统的"。原话是，"we haven't rigorously evaluated our features against other steering methods"。在少样本区间之外，非特征方法"可能同样有效或更有效"。

博客文章的措辞强于论文。博客说 "could, in future, help us make AI models safer"，还说这是 "first ever detailed look"。读起来像里程碑。而论文强调初步性与未证明安全用途。引用博客措辞时，不要把它当作论文的结论。

## 五、精读点评

这一节是分析者的判断，不是论文自己的说法。它和前面几节是分开的。前面讲论文做了什么、发现了什么、自己怎么说。这一节讲分析者怎么看。

### 这篇论文要回答的科学问题

先把这篇论文的科学问题还原成五句话，用平实的话讲。

第一个问题是，哪里反常。2023 年的玩具模型证明 SAE 能分解单层小 transformer。但没有人知道，把它搬到生产级大模型上会怎样。是工程上做不到，还是根本上失效？生产模型内部完全是黑箱，连"模型是否用可分离特征表征概念"在大模型上是否成立，都是未知的。

第二个问题是，为什么重要。如果 SAE 在大模型上失效，"把模型拆成可读特征"这条最有希望的可解释性路线就断了。机制研究只能停留在玩具演示上，安全评估只能看输入输出。如果可行，检查、引导甚至纠正模型行为就有了抓手。

第三个问题是，之前为什么做不了。原因有三层。工程上，在生产模型残差流上训练百万、千万级字典，需要并行计算与超参搜索方法，没有扩展定律指导，调参成本太高。概念上，不知道叠加假设在真实大模型上是否成立。获取上，需要实验室内部才能拿到的生产模型内部激活。

真正的瓶颈是"没有可控的规模化手段"。本工作移走的正是这一块：用扩展定律扫参解决"怎么训大字典"，用生产模型真实激活解决"在什么上训"。

第四个问题是，方法与问题为什么匹配。匹配点不在"方法新"，而在恰好绕过上述瓶颈。SAE 直接作用于生产模型真实激活，用字典学习拆开叠加的特征。扩展定律扫参让大字典训练成本可控。夹住特征引导加上归因与消融对照，提供因果检验，不只看激活相关。

第五个问题是，答案改变了什么认知。它证实了"大模型内部存在可分离、可解释、可干预的抽象特征"这一存在性，推翻了"SAE 只在玩具模型上有效"的怀疑。但它没有改变"有多少特征可解释、是否能用于安全"的判断。这两点仍未测量。实践上，它留下了 SAE 规模化训练范式与特征浏览器。安全用途仍未被证明。

### 价值判断

这篇论文的认知价值在于，它推翻了"SAE 只在玩具模型上有效"的怀疑，确认了生产级大语言模型内部存在可分离的抽象特征。如果这篇论文不存在，"字典学习能否用于大模型"仍会是一个没有答案的猜想。

它的方法价值是中等偏上。它留下了别人能直接拿走复用的东西：用扩展定律扫参指导大字典训练的方法，归因与消融验证流程，以及可浏览的特征集。扣分在于没有发布代码，也没有发布 SAE 权重。复用只限于方法层面，不是结果层面。

它的边界价值是这篇论文最可信的部分。它明确排除了三件事：特征在一般意义上有多可解释，扩展定律的量级，以及特征对安全的实际用途。读者最容易误读的推论是"存在安全相关特征，所以模型危险"，或者反过来"所以安全可解"。这两种推论都被作者的范围限定明确否定了。

它的启示价值在于，它使一个最便宜的决定性实验成为可能：随机方向对照夹住实验。对已有的一批引导案例，在匹配幅度下夹住随机方向与打乱的特征向量，比较"主题化"输出的出现率。

这个实验成本最低，只用已有 SAE 与已有提示，不需重新训练。信息量最大，能直接区分两种解释。如果随机方向同样有效，因果主张就塌了。如果特征显著胜出，因果主张就大幅硬化。

### 最弱的一环

最弱的一环是"SAE 训练损失是字典质量与可解释性的有用代理"这个前提。它承重最高。所有扩展定律结论与 34M 那次运行的设计都建立在它之上。

但它的证据最弱。作者自己说，对这个损失是否最优"没有多少信心"。损失与可解释性的联系，在正文里只是相关性，而且没有量化。作者还说，不清楚扩展定律"是否真的触及我们真正关心的根本问题"。

能加强这个前提的证据是，在独立的可解释性度量下直接比较，证明低损失的 SAE 在不同 L1 系数与目标函数下产出更可解释的特征。能打破它的证据是，一个更高损失的 SAE（不同 L1 系数或目标函数），其特征在 Opus 或人类特异性与引导成功率上得分更好。

第二弱的一环是离分布夹住。所有因果主张都依赖它，但正文没有报告随机方向对照。夹住值远在观测激活范围之外。在分布内幅度下夹住的效果，论文没有测量。如果在分布内幅度下效应消失，因果结论就不成立。

### 另外几种解释

除了论文自己的解释，还有几种替代解释没有被排除。把它们写出来，是为了说明哪些结论还站不稳。

第一种是离分布扰动伪影。引导效应可能来自把残差流沿任意足够大的方向推出训练分布之外。"主题化"输出反映的是模型对大扰动的通用反应，加上实验者的解释，而不是被夹特征的正常作用。

区分的办法是，在匹配夹住幅度下夹住随机方向，看是否产生可比的主题化输出。还可以在分布内幅度下夹住特征，看效应是否还在。论文没有报告随机方向对照，所以这个替代解释还活着。

第二种是 SAE 诱导的结构。"特征"可能部分是 SAE 优化造出来的。L1 稀疏、ReLU、字典大小切割激活空间，造出看起来可解释的方向。但模型自身可能以分布式方式表征同一信息，SAE 的方向未必对应模型的因果变量。

区分的办法是，在相同激活上用不同 SAE 种子、L1 系数或架构训练，看是否得到实质上不同的特征集。或者在模型自身计算中直接消融解码器方向，不经过 SAE 重建，看效应是否与基于 SAE 的夹住不同。论文没有做跨种子或跨目标函数的特征复现对照。

第三种是选择与评判者偏差。论文的可解释性印象可能由展示最好的特征驱动，也可能由一个与 Sonnet 共享联想、偏爱听起来合理之解释的 Opus 评判者驱动。

区分的办法是，让设盲的人类评分者评随机抽取的特征，并报告 Opus 与人类的一致率。论文自己的 100 个随机特征自动可解释性结果，本来可以裁决这一点。但它的数字只在图中，从正文无法排除这个替代解释。

第四种是作者自己的替代解释，本精读认同。安全相关特征存在，是因为预训练数据充满了欺骗、奉承、生物武器与杀手机器人的故事。它们是识别这些话题文本的机制，不是模型中相应驱动或倾向的证据。

区分的办法是，测量这些特征在部署类交互中与越狱中的激活情况。作者提议的研究计划正是"这些特征何时激活"。

### 效度判断

效度分数按 1–5 打分，5 分最强。分数针对这份已发表的报告本身，不是针对 SAE 方法一般。

内部效度 3 分。优点是论文内的检查是真实的。归因用消融验证过，相关性约 0.8，而激活只有约 0.12。有负对照，比如英文 typo、乘法定义函数、Kobe 的对手球队提示。有负面提示过滤。有死亡特征核算。

威胁是，没有随机方向引导对照。展示特征与提示是手选的。基线 token 依赖性已被承认。探针比较扫描"不是系统的"。中间计算示例的 cherry-picked 已被作者承认。随机化与盲法不适用，但选择偏差是主要的内部威胁，只得到部分缓解。

外部效度 2 分。只有一个模型，是 Claude 3 Sonnet 的一个 checkpoint，微调版。只有一个层，是中间残差流。只有一个 SAE 家族，是 ReLU 加 L1。

没有在其他模型、其他层、基础版与微调版的对比、部署分布上检验。作者指出更早或更晚的层可能不同。作者声称方法在基础版上也管用，但没有展示。SAE 训练没有 Human:/Assistant: 数据或图像。图像与多语言泛化是真正的积极意外，但只在所选示例上演示，没有大规模测量。推广到"大模型"一般情况，并未由一个模型确立。

构念效度 3 分。构念"可解释特征"指的是响应概念并导致概念的方向。它通过三种方式操作化：激活示例、特异性量表、引导。这是真正的三角验证优点。

但关键操作很弱。解释是人对 top-20 示例的判断。特异性由另一个 Claude 模型评判，而且没有报告验证。"单义性"从未给出定量阈值。损失代理与构念的联系被作者明确怀疑。论文谨慎区分"知道"与"做到"，保护了安全构念不被过度解读。

统计结论效度 2 分。正文中几乎没有报告推断统计。没有 p 值，没有置信区间，没有效应量，没有误差棒，没有种子或重复，没有多重比较处理。"显著更可解释"和"显著更特异"在正文中没有统计量就断言了。

确实存在的定量结果，比如 82%、死亡特征比例、60% 行政区覆盖、相关性约 0.8 与 0.12，都是描述性的。大多基于 2 个提示或所选特征，而且有几项只存在于图中。归因与消融相关性是最强的统计元素，而它建立在两个提示上。

可复现性 1 分。没有代码，没有 SAE 权重，没有模型权重（专有）。没有模型规模、层、维度。没有训练数据混合或 token 数。除了 L1 系数 5 与字典大小外，没有超参。没有种子，没有引导提示集，没有解码设置。

交互式特征浏览器能让读者检查已发布的特征，但不能重新训练或验证它们。读者能按给出的方程重实现 SAE 方法，但无法在 Sonnet 上复现任何标题数字。这在很大程度上是专有模型的约束，不完全是作者的选择。但分数反映的是读者实际能重做的程度。

### 证伪与下一步

每条主要主张都可以被证伪。写出证伪条件，是为了说明这些主张不是不可检验的。

扩展定律的主张可以这样打破：在两个更大的算力预算下训练 SAE，发现损失不沿外推幂律下降。或者发现另一个 L1 系数或目标函数达到更低损失，同时特征更可解释。任一结果都打破"扩展定律可作指导"的主张。

抽象特征的主张可以这样打破：证明金门大桥特征在匹配对照集上的激活，与在桥相关引用上一样强。匹配对照集比如去掉桥名的其他悬索桥，或旧金山地标。或者证明它的多语言激活是由共享子词 token 驱动，而不是概念驱动。

频率与字典大小关系的主张可以这样打破：用消歧后的频率度量（不是粗糙字符串搜索），证明超过 50% 纳入阈值不随字典大小追踪 1/（存活特征数）。或者证明稀有概念在小字典中出现的频率与频繁概念一样高。

引导的主张可以这样打破：在匹配幅度（5×–20×）下夹住随机方向或打乱的特征向量，以相似频率产生同样的"主题化"输出。这将表明引导效应是通用的离分布扰动效应，而不是特征特异的因果作用。

中间计算的主张可以这样打破：在一批新的多跳提示上，证明归因与消融的相关性接近激活与消融的水平（约 0.12），而不是约 0.8。或者证明 top 归因特征在语义相关性上不比 top 激活特征强。

特征胜过神经元的主张可以这样打破：用预注册评分量表与对特征或神经元来源设盲的人类评分者，发现没有可解释性差距。或者证明一旦探针构建使用超过少数几个示例，少样本探针就能匹配特征引导。

接下来最值得先做的是随机方向对照夹住实验。取已有的一批引导案例，包括金门大桥 10×、交通 5×、不安全代码 5×、奉承 5×、保密 5×、仇恨 20×、诈骗邮件。对每个案例，在匹配幅度下夹住三类对照方向：随机单位方向、打乱的特征向量、同一 SAE 中无关特征的方向。用同一提示集与同一"主题化输出"判定标准比较。

判据是一句话：如果随机或打乱方向以与真实特征相近的频率产生主题化输出，因果解释就被证伪。如果真实特征显著胜出，而且在分布内幅度下仍有效应，因果主张就大幅硬化。

其他值得做的事还有：独立可解释性评估，用预注册的、设盲的人类评分评随机特征，并报告 Opus 与人类的一致率；跨种子与跨目标函数的 SAE 复现，看同样的被命名特征是否重现。

还有"何时激活"的研究，包括自我认同 token、越狱期间、CBRN 建议请求期间、sleeper-agent 训练中、微调之下；回路分析，不只是特征本身；报告了指数的扩展定律复现。

后续 Anthropic 的 SAE 工作不在本精读范围内。本精读只覆盖 2024-05-21 的报告。后续论文是否报告了缺失的对照、统计与复现细节，是值得追踪的问题。

## I. 结论、结果与价值总览

只用本文件已经核实的材料。数字的完整条件见数字台账，此处直接写出数字，不另列表格。

**一句话结论：** 稀疏自编码器能在生产级 Claude 3 Sonnet 上训出稀疏、可重建、可引导的抽象特征，归因与消融的相关性约 0.8，而原始激活与消融的相关性只有约 0.12。但特征总体上有多可解释、扩展定律的量级、以及引导是否真是特征的因果作用，都没有确立。

**核心结论一：SAE 扩展到了生产模型。** 三组 SAE 全部训出来了，字典大小分别是约 1M、约 4M、约 34M 个特征。每 token 平均活跃特征不到 300 个，重建解释的激活方差在 65% 以上。

死亡特征的比例约 2%（1M）、约 35%（4M）、约 65%（34M）。34M SAE 的存活特征约 12M 个。这部分结论的置信度是高，但只是定性部分。定量的扩展定律没有确立。

**核心结论二：特征抽象，而且能跨语言、跨模态泛化。** 金门大桥特征在六种测试语言的 Wikipedia 文章首句上，平均激活排名都是第一。但样本量极小，每种语言只有一句话。

代码错误特征跨 Python、C、Scheme 的 bug 激活，不在英文散文的 typo 上激活。这部分结论的置信度是中。

**核心结论三：夹住特征能改变输出。** 金门大桥特征夹到最大值的 10×，模型自认是金门大桥。奉承特征夹到 5×，模型过度赞美。仇恨特征夹到 20×，模型输出种族主义长篇。不安全代码特征夹到 5×，模型生成缓冲区溢出 bug。

这些都是一次单次演示。而且没有任何随机方向夹住对照。"特征是因果变量"还是"任意大扰动都会让输出主题化"，现有数据区分不了。这部分结论的置信度是中，只在演示层面。

**核心结论四：归因找到了激活排名错过的因果相关中间步骤。** 归因与消融的相关性约 0.8，附录说是约 0.81。激活与消融的相关性约 0.12。

Kobe 示例中，10 个最高归因特征有 8 个属于消融效应 top-10。但这个结论只基于 2 个提示，而且 Kobe 示例作者承认是 cherry-picked。这部分结论的置信度是中。

**核心结论五：扩展定律与可解释性总体水平没有确立。** 损失随算力"近似按幂律"下降，最优特征数与步数各自"近似按幂律"扩展。但指数与损失值只在图中。

随机特征的可解释性与特异性分布也只在图中。模型规模、层、残差流维度、学习率、算力都没有报告。这部分结论的置信度是低。

**核心结论六：安全用途没有被证明。** 安全相关特征存在，但这项工作没有证明任何特征对安全实际有用。这句话是作者自己的限定，置信度是高。

"知道"不等于"做到"。特征反映预训练曝光，不等于模型怀有相应驱动。

**关键结果：** 决定性的结果有这些。SAE 字典大小与稀疏度、重建质量见数字台账第 1 至 3 行。死亡特征见第 4 至 5 行。归因有效性见第 23 行。金门大桥引导见第 13 行。

特征分裂见第 18 行："旧金山"特征从 1 个分裂成 2 个，再分裂成 11 个。探针比较见第 34 行：7 个案例里，特征在探针失败处成功 5 个，平局 2 个。

扩展定律指数与损失值只在图里，没有核实，这里不印数字。

**科学价值总评：** 认知价值在于，它推翻了"SAE 只在玩具模型上有效"的怀疑，确认了生产级大语言模型内部存在可分离的抽象特征。

方法价值是中等偏上。它留下了用扩展定律扫参指导大字典训练的方法、归因与消融验证流程、可浏览的特征集。扣分在没有发布代码，也没有发布 SAE 权重。复用只限于方法层面。

边界价值在于，它明确排除了三件事：特征在一般意义上有多可解释、扩展定律的量级、特征对安全的实际用途。最容易误读的推论是"存在安全相关特征，所以模型危险"，或者反过来"所以安全可解"。这两种推论都被作者的范围限定明确否定了。

启示价值在于，最便宜的决定性实验是随机方向对照夹住实验。在匹配幅度下夹住随机方向与打乱的特征向量，比较"主题化"输出的出现率。

总体上，这篇论文值得被记住的，是"大模型内部存在可分离、可干预的抽象特征"这一存在性，以及归因与消融验证方法。不值得被记住的，是把它当作"SAE 已经解决可解释性"或"安全特征已有实际用途"的证明。
