## B. 问题与主张

**没有陈述的研究问题，按产品宣称重构（分析者用语）：** 新的中端模型 Claude 3.5 Sonnet 是否在标准能力基准上达到或超过此前的旗舰 Claude 3 Opus 和当前竞品模型，同时成本更低、速度更快，并保持在可接受的安全范围内？**PICO 式改编：** 系统 = Claude 3.5 Sonnet（2024 年 6 月快照）；干预 = 新模型本身（没有操纵任何干预——这是一次比较，不是一次实验）；对照 = Claude 3 Opus / Sonnet / Haiku、GPT-4o、GPT-4 Turbo、Gemini 1.5 Pro、Llama 3 400B（instruct）；结果 = 基准分数、内部智能体编码通过率、人类偏好胜率、拒绝率、长上下文回忆、ASL 分级。

## C. 假设图（第一性原理）

**根假设（倒下则全盘受损）：** A1——在 GPQA / MMLU / HumanEval 等基准上得分更高 = 一般智能 / 能力更高（"raises the industry bar for intelligence"，公告 L6–7、L15）；A2——所报告的基准未被污染，模型没有在（近似）复制的测试题上训练过；A13——附录中评估的 2024 年 6 月快照就是用户在发布时收到的模型。三者均未验证：A1 的推论是断言的，不是论证的；A2 没有任何去污染声明；A13 无法核查，因为任何地方均未报告检查点 / 版本标识符。如果 A2 倒下，表 1–2 的每个单元格都可疑；如果 A13 倒下，这些数字描述的是另一个产物；如果 A1 倒下，数字可以完全正确，而标题宣称仍然是错的。

**其余承重假设（均未验证）：** A3——表 1–2 中的跨模型单元格可比，即差异反映模型而非评估协议；表格本身削弱了它：同一行内协议不同（MATH：Claude / GPT-4o 用 0-shot CoT，Gemini 用 4-shot，Llama 3 用 4-shot CoT；MGSM：0-shot CoT 对 Gemini 的 8-shot；DROP：Gemini 为 "Variable shots"），竞品数字取自厂商自己的报告（参考文献 [8]、[9]、[16]、[17]）而非同一框架下重跑。A4——从 OpenAI / Google / Meta 出版物引用的竞品数字准确，且指用户会遇到的同一模型版本；只有引用（附录参考文献 [8]、[9]、[16]），除 "GPT-4o"、"Gemini 1.5 Pro"、"Llama 3 400B（April 15, 2024 checkpoint）" 之外没有版本锁定。A5——内部智能体编码评估衡量真实世界的软件工程能力（附录 §2 "Agentic Coding"）：设计以散文描述，但 **n 未报告**，问题选择未描述，无难度分布，无基线脚手架比较。A6——内部评估中给每个模型的智能体脚手架 / 工具等价，因此 64% 对 38% 是模型差距：脚手架、工具、迭代预算、提示词均未描述。A7——与 Opus 相比的人类偏好胜率衡量能力提升而非风格、长度或评分者预期（附录 §2.1）：方法推迟到 Claude 3 主模型卡 §5.5；评分者 n、任务 n、盲法、平局处理、指令均未报告。A8——"Twice the speed" 是一次有意义、可复现的速度比较（公告 L19）：无延迟数字、无任务、无硬件、无每秒 token 数、无测量方法，完全未报告。A11——安全：能力提升没有跨过 ASL-3，因为模型 "does not trigger the 4x effective compute threshold" 从而启动完整 RSP 协议，且针对性测试未发现阈值 breach（附录 §3.1）：阈值未报告；定量的 CBRN / 网络安全 / 自主性结果未报告（只有 "did not exceed our safety thresholds"）；UK AISI 结果未在此发表；4 倍算力触发条件是一项政策约定，不是物理事实。A12——HHH（Helpful, Honest, Harmless）导致的拒绝只会*低估*能力，而 Anthropic 内部的“非拒绝”诱发能恢复真实能力而不夸大它（附录 §3.2，最后一段）：只是断言；诱发技术未描述，作者自己也指出结果 "may underestimate" 一个仅 Helpful 的模型；偏差方向是假定的，不是证明的。

**软假设（不承重或仅部分承重）：** A9——拒绝率差异（表 4）衡量更好的安全校准而非不同的拒绝风格或阈值调校；Wildchat / XSTest 已具名，规模与抽样未报告。A10——Needle-in-a-Haystack 回忆率衡量与真实 20 万 token 使用相关的长上下文检索能力（附录 §2，表 5）：Anthropic 自己的任务变体（参考文献 [21]），合成针、单一事实。A14——"State-of-the-art" 指在*此处评估的*已报告基准上最好，而非所有相关评估上最好（定义性）：表格本身反驳了无保留的读法——同一表格中 GPT-4o 在 MATH（76.6% 对 71.1%）和 MMMU（69.1% 对 68.3%）上击败 3.5 Sonnet。

**什么能打破它们（各取最直接的一条）：** A1——证明提升只是基准特异的（记忆、格式适配、提示词适配），没有迁移到未见过的真实任务上。A2——重叠分析显示测试题（或其改写）在训练数据中出现，或在全新的、截止日期之后的基准上分数急剧下降。A3/A4——在同一框架下用相同提示词 / 样本数重跑所有模型，看到排名改变。A5/A6——公开复现（同一快照上的 SWE-bench Verified）给出非常不同的通过率，或显示固定脚手架下与 Opus 的差距消失。A7——长度受控产出的盲法复现显示胜率接近 50%。A8——在所述条件下做的任何延迟测量显示比率与之有实质差异。A11——公布阈值与分数；外部评估发现 breach；或证明有效算力的核算低估了能力跃升。A13——API / 模型 ID 记录显示被评估的构建与发布构建不同。

## D. 设计、对照、指标、统计

**设计类型：** 没有一种标准实验设计适用。这是一份**厂商基准报告**：一组已有的公开基准（自家模型由 Anthropic 运行；竞品数字引自厂商自己的出版物）加一次内部非公开评估和一次人类偏好研究。没有假设、没有随机化、没有预注册、没有实验意义上的对照组——表中的对照模型就是“对照”。

**实际做了什么：** 标准基准（附录表 1–2）：GPQA Diamond、MMLU（两种协议）、MATH、HumanEval、MGSM、DROP、BIG-Bench Hard、GSM8K、MMMU（验证集）、MathVista（testmini）、AI2D（test）、ChartQA（test）、DocVQA（test）；每行注明样本数与思维链使用（见 §E），但**提示词、评估框架、框架版本、解码设置（温度、top-p、最大 token 数）与运行次数均未报告**。智能体编码（表 3）：问题基于真实开源 pull request；模型必须实现改动（通常 3–4 个文件，最多 20 个）；隐藏测试必须全部通过；模型可以在智能体循环中编写 / 运行代码并自我修正；沙箱环境，无互联网；**n、问题选择标准、时间 / 步数预算、脚手架、提示词均未报告**。拒绝（表 4）：Wildchat（有毒 / 无毒分组）与 XSTest；正确拒绝率与错误拒绝率；数据集规模、抽样、提示词格式未报告。大海捞针（表 5）：Anthropic 自己的任务变体；上下文长度 up to 200K 时的平均回忆率；针的类型、提示词（图 1 提到一个 "modified prompt"）、每个长度的试验次数未报告。人类反馈（§2.1，图 3）：评分者按任务说明与模型对话；相对于 Claude 3 Opus 基线的胜率（Opus 按构造为 50%）；方法推迟到 Claude 3 主模型卡 §5.5；评分者数量、任务数量、盲法、一致性、平局处理、显著性均未报告。安全（§3）：CBRN 自动化知识测试 + 非专家 uplift；网络安全夺旗赛；通过代码编写评估测自主性；按领域定义 "thresholds of concern"（阈值未报告）；UK AISI 对 "near-final model" 做部署前测试；METR 对自主性做 "initial exploration"；**未报告任何定量安全结果**。

**对照 / 基线：** Claude 3 Opus、Sonnet、Haiku（Claude 2.1 仅用于 NIAH）为内部基线；GPT-4o、GPT-4 Turbo、Gemini 1.5 Pro、Llama 3 400B 为外部对照。**调参与算力是否匹配：说不清**——事实上在协议上明显不匹配：同一基准行内不同模型的样本数与 CoT 设置不同（见 §C A3/A4）；竞品分数不是由 Anthropic 重跑的，而是引自竞品自己的出版物。这是本文件最重要的设计事实。**盲法：** 人类评估未报告 / 说不清（且方法推迟到另一份文件）；自动化基准不适用盲法，但基准污染状态未报告。

**指标：** 准确率 / 通过率（%，一位小数）、F1（DROP）、ANLS（DocVQA）、宽松准确率（ChartQA）、平均回忆率（NIAH）、胜率（人类评估）、拒绝率（表 4）；没有区分主要指标与次要指标——每个已报告的数字都被呈现为支撑标题宣称。

**统计——以下全部是“未报告”：** 种子 / 运行次数（全部表格）；误差棒（SD / SE / CI，表 1–5 均无；10 月附录的 OSWorld 表确实报告了 95% CI，6 月附录没有）；效应量、p 值、多重比较校正；样本量 n（任何基准均未报告——GPQA Diamond、MATH、HumanEval、智能体编码、人类评估、Wildchat / XSTest、NIAH 试验次数）；算力（训练 FLOPs、硬件、时间）；训练数据、架构、参数；评估框架 + 版本、提示词、解码；污染 / 去污染分析；数据 / 代码可用性（未随这些文件发布代码、提示词、原始结果或评估脚本）。

**检查表结论（NeurIPS / Pineau 条目，作为能力宣称）：** 主张↔结果一致性——*部分*（标题宣称夸大了混杂的表格，见 §G）；局限——*部分陈述*（见 §H，作者自述）；可复现路径——**无**；实验设置——*部分*（仅样本数 / CoT）；统计显著性——**无**；算力——**无**；数据 / 代码——**无**；伦理 / 安全——*部分*（ASL-2 已断言，定量结果未公开）。

**必须明说的一句话：** 这是一篇模型发布帖加厂商模型卡，不是同行评审论文。科学意义上没有实验——没有操纵变量、没有随机化、没有统计推断。正确的评估标准是“读者应该在多大程度上信任这些厂商报告的数字以及建立在其上的宣称”，而不是“假设检验的功效是否充足”。

**替代解释（附可区分的证据）：** 1. **提示词 / 协议不对称，而非模型更优（针对 A3）：** 3.5 Sonnet 在每个基准下都按其最有利的协议评估（例如 MMLU 用 5-shot CoT 得 90.4%，而在 GPT-4o 获胜的 0-shot CoT 协议下只有 88.3%），竞品则按其自己的出版物以不同协议引用，或留空。不同预测：在固定框架下用相同提示词 / 样本数跑全部模型，跨厂商差距缩小或重排，而 Claude 模型内的差距（同一框架）保持不变。可区分的证据：一次单框架复现（例如 OpenAI simple-evals 风格，或独立评估套件），版本锁定并报告 CI。2. **基准污染 / 格式适配，而非一般能力（针对 A1/A2）：** 提升反映了训练数据与基准题目的重叠（或开发过程中对基准格式的大量优化），所以分数高估了可迁移的能力。不同预测：模型在*全新的、截止日期之后的*基准与真实世界任务套件上的提升，远小于在已报告的（2024 年之前、被广泛镜像的）基准上的提升。可区分的证据：一次去污染 / 重叠分析（从未为该模型发表）或在知识截止日期之后创建的基准上的表现——10 月附录的 SWE-bench Verified（升级版快照从 33.4% 到 49.0%）是这一方向上的部分、较晚的数据点，但它针对的是另一个快照与另一项评估。3. **脚手架与工具，而非模型，推动了智能体编码差距（针对 A5/A6）：** 64% 对 38% 的差距反映的是给新模型更好的智能体框架、工具集、迭代预算或提示词（或给 Opus 更旧、更弱的框架），而不是 26 个百分点的模型差异。不同预测：互换框架（Opus 用新脚手架，3.5 Sonnet 用旧脚手架）后，通过率随脚手架走，而非随模型走。可区分的证据：任何评估框架的发布，或一次公开的 SWE-bench 风格复现，对两个模型使用固定脚手架。4. **风格 / 长度偏好，而非能力，推动了人类胜率（针对 A7）：** 评分者偏好 3.5 Sonnet 的输出是因为语气、格式或长度——这些正是公告本身称赞的品质（"natural, relatable tone"）——而不是因为正确性。不同预测：长度受控的盲法重跑在按正确性评分的任务上胜率接近 50%，而在按风格评分的任务上胜率仍然高。可区分的证据：一次带输出长度控制与基于正确性评分的盲法人类评估（本文件未报告）。

## I. 结论、结果与价值总览（v2.1 新增；只用本文件已核实的材料）

### 一句话结论

2024 年 6 月快照在 Anthropic 所选基准、所选协议下得分高于 Claude 3 Opus（GPQA 59.4% 对 50.4%、HumanEval 92.0% 对 84.9%、智能体编码 64% 对 38%）；但“击败竞品、树立新行业基准”的标题宣称不成立——MATH 与 MMMU 上落败、若干标题比较无竞品数据、没有任何数字带不确定性、没有任何训练信息。

### 核心结论

1. **家族内领先确立（置信度：中）。** 表 1 的 11 行中，3.5 Sonnet 在 7 行领先全部已报告单元格；GPQA 59.4% 对 Opus 50.4%、HumanEval 92.0% 对 84.9%、智能体编码 64% 对 38%，差距大且方向一致，不太可能完全是人工产物。但没有任何数字带 n、种子、误差棒或 CI，统计结论效度 1/5。证据：§E E1、E3.1；§G 总体判断。
2. **行业领先未确立（置信度：低）。** MATH 71.1% 对 GPT-4o 76.6%（低 5.5 个百分点）、MMMU 68.3% 对 GPT-4o 69.1%、MMLU 0-shot CoT 88.3% 对 GPT-4o 88.7%，三项直接落败；MMLU 5-shot CoT（90.4%）与 GPQA Maj@32（67.2%）完全没有竞品单元格。证据：§E E1.3、E1.5、E1.6、E2.1。
3. **智能体编码 64% 对 38% 是最有实践意义、也最难核查的数字（置信度：中）。** 内部评估：真实开源 PR、多文件编辑、带代码执行与自我修正的智能体循环；但 n、问题选择、步骤 / 时间预算、脚手架、提示词、种子均未报告，26 个百分点差距的原因完全未知——是模型更强还是脚手架更好，现有数据区分不了；见 §B 链 2。证据：§E E3.1、§G 内部效度 2/5。
4. **2 倍速度无法核实（置信度：低）。** “运行速度是 Claude 3 Opus 的两倍”没有任何条件：两份文件均未报告延迟、吞吐量、任务、硬件或测量方法。证据：§E E4.1；§G Hitchens 剃刀。
5. **安全 ASL-2 只是断言（置信度：低）。** 安全分级基于针对性（而非完整 RSP）测试，定量结果未报告；UK AISI 测试的是一个“接近最终的”模型，结果未发表；阈值与分数均未公开，对外部读者实际上不可证伪。证据：§E E4.3、§H 作者自述局限。
6. **拒绝率确有改善的一面（置信度：中）。** XSTest 错误拒绝率 1.7%，对 Opus 8.3%、Sonnet 36.6%、Haiku 33.1%，是本文件中最引人注目的拒绝结果；但 Wildchat 无毒错误拒绝率 11.0% 差于 Sonnet（8.8%）与 Haiku（6.6%），附录“在两个维度上都超过 Opus”仅对 Opus 为真。证据：§E E3.3、E3.4。

### 关键结果（数字见 §E，此处不另列表格）

决定性数字：GPQA、HumanEval、MATH、MMLU、MMMU（§E E1）、智能体编码（E3.1）、XSTest 与 Wildchat 拒绝率（E3.3、E3.4）、NIAH（E3.5、E3.6）、人类偏好胜率（E3.7）、2 倍速度（E4.1，不可用）。判定见上文核心结论 1–6。

### 科学价值总评（汇总 §G 四维 verdict）

- **认知价值：** 只确认了一个可部署的事实——中端模型在已报告基准上可以击败此前的旗舰；没有推翻或确认任何关于智能、训练或评估的科学信念，因为文件没有提出或检验任何机制。
- **方法价值：低。** 没有留下任何别人能直接拿走复用的东西；唯一接近“方法”的内部智能体编码评估只以散文描述，未发布任务集、脚手架或 n。
- **边界价值：** 它明确不证明的东西比它证明的东西更多：不证明行业领先、不证明一般智能、不证明真实世界软件工程能力、不证明 2 倍速度、不证明安全性。最易误读的推论是“基准领先 = 模型全面更强、部署一定更好”。
- **启示价值：** 最便宜的决定性实验是在单一评估框架下，用相同提示词、相同样本数、相同解码重跑 GPQA Diamond、HumanEval、MATH、MMMU 四项基准，对比 Claude 3.5 Sonnet 与 GPT-4o，并报告 n、种子与 95% CI。
- **总体 verdict：值得为什么被记住——作为 2024 年 6 月的发布事实与家族内比较的记录（中端击败旗舰、智能体编码 64% 对 38%、XSTest 拒绝率大幅改善）；不值得被记住为行业领先的证据。**

### 适用边界

不要引用这份文件论证 3.5 Sonnet 是当时行业最强模型；不要把智能体编码 64% 对 38% 读作真实世界软件工程能力；不要引用 2 倍速度；不要引用图 3 除法律 / 金融 / 哲学之外的胜率（未核实）；不要把价格（3 美元 / 15 美元每百万 token）当作当前价格——那是 2024 年 6 月的发布价。可以引用的是：2024 年 6 月快照在 Anthropic 所选基准、所选协议下的得分，以及 ASL-2 作为“所述的分级”（其背后的证据未展示）。
