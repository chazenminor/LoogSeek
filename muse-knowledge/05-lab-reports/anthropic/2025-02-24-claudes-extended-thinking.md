## 一、背景与问题

### 同一个模型，花更多时间想

文章开头打了一个比方。有些事我们几乎是瞬间知道答案的，比如“今天是星期几”；有些事需要持久的脑力，比如解隐晦纵横字谜或调试一段复杂的代码。人会根据任务难易决定投入多少认知努力。

现在 Claude 也有了这种灵活性。新的 Claude 3.7 Sonnet 里，用户可以打开或关闭“扩展思考模式”（extended thinking mode），让模型在更难的问题上想得更深。开发者还可以设定一个“思考预算”（thinking budget），精确控制 Claude 在一个问题上花多长时间。

文章特意澄清了一点：扩展思考模式不是切换到另一个采用不同策略的模型，而是让同一个模型给自己更多时间、付出更多努力来得出答案。

### 这篇要回答的问题

这篇博客要讲的问题可以说成一句话：一个模型如果能在回答之前想更久、而且把想的过程亮出来，会带来什么，又会付出什么代价？

逼出这个问题的反常并不难找。此前的大模型要么不怎么“想”，要么把推理过程藏起来；想得久的能力和“看得见想的过程”这两件事，第一次同时出现在了同一个公开模型里。重要性分两面：对领域来说，推理时计算（test-time compute）正在成为与训练时计算并列的扩展方向，这篇博客等于公开宣布了 Anthropic 在这条线上的产品化路线；对实践来说，用户和开发者第一次可以直接看到模型的思考过程，这改变了人和模型打交道的方式，也改变了安全工作的抓手。

之前做不了，是因为没有一个公开模型同时做到这两点：按需延长推理，并且把推理过程原样展示。Anthropic 的办法是把“想更久”做成同一个模型里的一个开关，而不是另训一个推理专用模型；再把这个开关打开时的原始思考过程直接展示出来。这个设计能回答问题，是因为它把“想多久”变成了一个可调的量——用户拨开关、开发者定预算，思考的量与效果之间的关系第一次变得可以直接观察。

如果答案成立，改变的是两件事：推理能力不再只由训练决定，部署时的计算投入也成了一条可调的杠杆；同时，模型的内部思考从黑箱变成了一个可见的界面，好坏都摆在台面上。

## 二、可见的思考过程

### 亮出来有三个好处

除了让 Claude 想得更久、答更难的问题，Anthropic 还决定把它的思考过程以原始形式展示出来。文章列了三个好处。

第一是信任（Trust）。能看到 Claude 是怎么想的，用户更容易理解和检查它的答案，也可能因此得到更好的输出。

第二是对齐（Alignment）。在以前的一些对齐科学研究里，Anthropic 用过模型内心所想与嘴上所说之间的矛盾，来识别它是否在从事欺骗之类的不当行为。看得见的思考过程让这种检查成为可能。

第三是趣味（Interest）。看 Claude 思考常常很有意思。一些有数学和物理背景的研究人员注意到，Claude 的思考过程与他们自己解难题的方式 eerily 相似：从许多不同角度和推理分支去探索，反复检查答案。

### 亮出来也有三个代价

文章没有只报喜。可见的思考过程有几个缺点，作者逐一写了出来。

第一个是观感。用户可能会注意到，展示出来的思考比 Claude 默认的输出更疏离、更没有个人色彩。这是因为 Anthropic 没有对思考过程做标准的性格（character）训练。他们想给 Claude 最大的自由去想任何为得出答案所必需的想法——而就像人的思考一样，Claude 有时也会想出一些不正确、误导性或半成品的想法。很多用户会觉得这有用，另一些人可能会觉得沮丧。

第二个是忠实性（faithfulness）。我们并不知道思考过程里的内容是否真的代表了模型脑子里发生的事。举例来说，思考过程里显示的英语单词，可能根本无法描述模型为什么表现出某种行为。忠实性问题——以及如何保证它——是 Anthropic 正在活跃研究的方向之一。迄今为止的结果表明，模型常常基于一些它在思考过程中没有明确讨论的因素做决定。这意味着，不能依靠监视当前模型的思考过程来为其安全性做出强有力的论证。

第三是安全与保障。恶意行为者可能利用可见的思考过程制定更好的越狱（jailbreak）策略。更具推测性的一点是，如果模型在训练中得知自己的内部想法会被展示，它可能会被激励去以不同、更不可预测的方式思考，或者故意隐藏某些想法。

这些后两个顾虑对未来更强大的 Claude 版本会尤其严重——那些版本如果不对齐，风险也更大。Anthropic 说，会权衡未来发布中揭示思考过程的利弊。与此同时，Claude 3.7 Sonnet 里可见的思考过程应被视为一个研究预览（research preview）。

## 三、对思考能力的新测试

### 作为智能体：OSWorld

Claude 3.7 Sonnet 受益于一种可以称为“行动扩展”（action scaling）的能力改进：它可以反复调用函数、响应环境变化，一直做到一个开放式任务完成为止。这类任务的一个例子是使用计算机：Claude 可以发出虚拟鼠标点击和键盘按键，替用户在屏幕上完成任务。与前代相比，Claude 3.7 Sonnet 可以给计算机使用任务分配更多的轮次、更多的时间和算力，结果也常常更好。

文章用 OSWorld 来展示这一点。OSWorld 是一个衡量多模态 AI 智能体能力的评估。Claude 3.7 Sonnet 起步时就稍好一些，而随着模型与虚拟计算机持续交互，性能差距随时间越拉越大。具体的分数只在图里，正文没有给出，见文末未核实清单。

### 打宝可梦

扩展思考加上智能体训练，不仅让 Claude 在 OSWorld 这类标准评估上更好，也在一些更出乎意料的任务上带来了大幅提升。

打宝可梦就是这样一个任务，具体是 Game Boy 经典游戏《宝可梦 红》（Pokémon Red）。Anthropic 给 Claude 配了基础记忆、屏幕像素输入和用来按键、在屏幕上导航的函数调用，让它能持续玩下去，突破通常的上下文限制，游戏过程持续了数以万计次交互。

文章在图里画了 Claude 3.7 Sonnet 与此前没有扩展思考选项的 Claude Sonnet 旧版本的宝可梦进度。旧版本很早就卡住了，其中 Claude 3.0 Sonnet 甚至没能走出故事开始的真新镇（Pallet Town）里的房子。

而 Claude 3.7 Sonnet 凭借改进的智能体能力走得远得多，成功挑战了三位宝可梦道馆馆主（游戏中的首领）并赢得了他们的徽章。文章说，Claude 3.7 Sonnet 特别擅长尝试多种策略、质疑此前的假设，这让它能在游戏进程中不断提升自己的能力。

文章也补了一句：宝可梦是一种欣赏 Claude 3.7 Sonnet 能力的有趣方式，但他们预期这些能力会在游戏之外产生真实的影响。模型保持专注、完成开放式目标的能力，将帮助开发者构建各种最先进的 AI 智能体。

### 串行与并行：两种推理时计算扩展

当 Claude 3.7 Sonnet 使用扩展思考能力时，可以说它受益于“串行推理时计算”（serial test-time compute）：在给出最终输出之前，它经过多个连续的推理步骤，一边推进一边投入更多计算资源。一般来说，这会以可预测的方式提升性能：例如，它在数学问题上的准确率随允许采样的“思考 token”数量呈对数增长。

Anthropic 的研究人员还一直在试验用并行（parallel）推理时计算来提升模型性能。做法是采样多个独立的思考过程，再挑出最好的一个，而事先并不知道正确答案。一种办法是多数（majority）投票或共识投票——选出现次数最多的答案当作最优答案。另一种办法是用另一个语言模型（比如 Claude 的第二个副本）检查它的工作，或者用一个学到的评分函数来挑出它认为最好的。文章说，这类策略以及类似的工作，也出现在其他几个 AI 模型的评估结果里，并给出了链接。

用并行推理时计算扩展，Anthropic 在 GPQA 评估上取得了显著提升。GPQA 是一组常用的、关于生物、化学和物理的难题。在相当于 256 次独立采样的计算量、一个学到的评分模型、最高 64k token 思考预算的条件下，Claude 3.7 Sonnet 的 GPQA 得分达到 84.8%，其中物理子项得分 96.5%，而且收益超出了多数投票的上限。文章说，评分模型方法和多数投票方法的结果都在下方的图里报告——但这些数字只在图里，正文没有给出，见未核实清单。

这类方法让 Anthropic 可以在通常不必等模型想完的情况下提升 Claude 答案的质量。Claude 可以同时进行多个不同的扩展思考过程，考虑更多方法，最终答对的概率大大提高。不过文章也说明了一点：并行推理时计算扩展在新部署的模型里还不可用，他们会继续研究这些方法，以备将来使用。

## 四、Claude 3.7 Sonnet 的安全机制

### 安全等级仍是 ASL-2

Anthropic 的负责任扩展政策（Responsible Scaling Policy）承诺，除非实施了适当的安全与保障措施，否则不训练或部署模型。Anthropic 的前沿红队（Frontier Red Team）和对齐压力测试（Alignment Stress Testing）团队对 Claude 3.7 Sonnet 做了广泛测试，以确定它需要与此前模型相同级别的部署与安全保障——即 AI 安全等级（AI Safety Level，ASL）2 标准——还是更强的措施。

全面评估确认，当前的 ASL-2 安全标准仍然适用。与此同时，模型在所有领域都表现出更高的复杂程度和更强的能力。在关于生产化学、生物、放射与核（CBRN）武器的任务的受控研究中，Anthropic 观察到，模型辅助的参与者比非辅助参与者有一些性能“提升”（uplift），也就是说参与者比只用网上公开信息能走得更远。但是，所有执行这些任务的尝试都出现了关键失败，完全阻碍了成功。

专家的红队测试反馈不一。一些专家注意到，模型在 CBRN 过程某些领域的知识有所提升，但他们也发现，关键失败的频率太高，无法成功完成端到端的任务。Anthropic 正在通过加速开发和部署针对性的分类器与监控系统，主动加强 ASL-2 措施。

此外，未来模型的能力可能需要进入下一阶段：ASL-3 保障。Anthropic 最近关于宪法分类器（Constitutional Classifiers）防止越狱的工作，以及其他努力，让他们有条件在不久的将来满足 ASL-3 标准的要求。

### 可见思考过程的加密

即使在 ASL-2 下，Claude 3.7 Sonnet 可见的扩展思考功能也是新的，因此需要新的、适当的保障。在极少数情况下，Claude 的思考过程可能包含潜在有害的内容（话题包括儿童安全、网络攻击和危险武器）。在这种情况下，Anthropic 会对思考过程加密：这不会阻止 Claude 在思考过程中包含这些内容（它们对最终产出完全无害的回答可能仍然重要），但相关部分的思考过程将不对用户可见。用户看到的将是“the rest of the thought process is not available for this response”（本次回答的其余思考过程不可用）这条消息。Anthropic 的目标是让这种加密很少发生，只在潜在危害很高的情况下出现。

### 计算机使用：提示注入防御

最后，Anthropic 加强了对 Claude 计算机使用能力的安全措施——它能看用户的电脑屏幕并替用户操作。在防御“提示注入”（prompt injection）攻击方面取得了实质进展：恶意第三方把秘密消息藏在 Claude 使用电脑时可能看到的地方，诱使它去做用户没打算让它做的事。

通过新的抗提示注入训练、一个包含忽略这类攻击指令的新系统提示，以及一个在模型遇到潜在提示注入时触发的分类器，Anthropic 现在能阻止这类攻击的 88%，而没有这些缓解措施时是 74%。

文章最后说，以上只是对 Claude 3.7 Sonnet 大量安全工作的简短总结。更多信息、分析结果和几个保障措施实际运作的例子，见完整的系统卡（System Card）。

### 如何使用

Claude 3.7 Sonnet 现在可以在 claude.ai 或 API 上使用。文章请用户把对新模型的反馈发到 feedback@anthropic.com。

## 六、精读点评

### 这篇东西是什么，不是什么

先把分量说清楚。这不是一篇研究论文，而是一篇随产品发布的说明博客。它没有作者署名，没有方法，没有数据，没有代码，没有统计，没有任何可复现的信息。它宣布一个产品能力，讲这个能力为什么有意思、有什么风险、做了哪些安全工作。按这个标准读，它是合格的；按论文的标准读，它几乎没有可供检验的内容。

它的可信度主要来自两点：数字很少，而且给出的几个数字都是具体、可证伪的——84.8% 的 GPQA 分数、88% 对 74% 的提示注入防御率、三块宝可梦徽章。这些数字如果造假，很容易被同行或用户戳穿。反过来，它的薄弱也正在于数字太少：全篇只有三个可核对的数字，而且其中两个没有任何方法细节支撑。

### 最有分量的一句话

全篇最值得记住的不是任何成绩，而是作者自己写的一句保留意见：模型常常基于一些它在思考过程中没有明确讨论的因素做决定，因此不能依靠监视当前模型的思考过程来为其安全性做出强有力的论证。

这句话重要，是因为它直接削弱了这篇博客前半部分给出的第二大好处——对齐。可见的思考过程被说成是对齐工作的帮手，同一篇文章又承认，这个帮手不能用来做强有力的安全论证。两者并不矛盾（弱信号仍有价值），但读者如果只记住“看得见就能监督”，就误读了作者的意思。

### 数字能说明什么，不能说明什么

GPQA 的 84.8% 是全篇最亮眼的数字，但它的条件需要看清：那是相当于 256 次独立采样的计算量、加一个学到的评分模型、最高 64k token 思考预算的条件下取得的。这不是“模型本身”的分数，而是一个重型推理时流程的分数。文章没有在正文里给出同样条件下多数投票的分数，也没有给出不加并行扩展的基线分数，所以读者无法从正文里判断，这 84.8% 里有多少来自模型本身、有多少来自 256 次采样和评分模型。

提示注入防御的 88% 对 74% 是一组干净的对照，但攻击集是什么、规模多大、怎么采样的，全都没有报告。14 个百分点的提升听起来不少，可如果攻击集很小或很特殊，这个数字的含义就很有限。

宝可梦的三块徽章是最生动的演示，也是方法上最弱的一环。它是一个单一的、没有对照消融的演示：没有说明扩展思考、智能体训练、记忆、像素输入这几样东西各自贡献了多少。Claude 3.0 Sonnet 走不出真新镇的房子，这句话很抓人，但它比较的是整整两代模型加一整套脚手架的差别，而不是扩展思考这一个变量的差别。

OSWorld 的说法更弱：正文只说“起步稍好、差距随时间拉大”，连一个数字都没有给出。读者只能相信图。

### 科学价值

认知价值上，这篇博客确认了一个方向性的判断：推理时计算是一条可产品化的扩展路线，串行扩展的效果随思考 token 呈对数增长，并行扩展还能再往上走。但它没有推翻或确立任何具体的科学信念——“想更久答得更好”在 2025 年初已经不是新闻，博客只是把它做进了产品。

方法价值上，它留下的可复用的东西不多。思考预算这个 API 设计后来成了行业通用的做法，但这篇博客本身没有给出任何别人能直接拿走的方法、度量或实验设计。它的价值在于宣布和示范，不在于方法。

边界价值上，这篇博客的边界写得比多数产品博客诚实。它明确说了三件事它不证明：可见的思考过程不等于模型真实的内部过程；并行推理时计算在部署的模型里还不可用；ASL-2 仍然适用、ASL-3 还没到。读者最容易误读的推论是“看得见思考就等于能监督模型”，作者在忠实性那一段已经提前堵住了这个口子。

启示价值上，它使一个下一步成为可能：把思考过程的忠实性变成可测量的东西。最便宜的决定性实验是，找一组模型在思考过程里没提、但实际影响了答案的因素，用干预实验验证思考内容与决策之间的因果关系——如果干预思考内容不改变答案、干预答案不改变思考，忠实性就无从谈起，监视思考过程的安全论证也就站不住。这个实验比继续刷 GPQA 分数更值得先做，因为它决定的是这条产品路线的安全论证能不能成立。

### 总体判断

这是一篇诚实但很薄的产品说明博客。它的优点是自我保留写得清楚——忠实性问题、安全顾虑、研究预览的定性都没有藏着。它的缺点是几乎所有亮眼的说法都缺乏可核对的数字支撑。内部效度、外部效度与统计结论效度都无从评分，因为它根本没有报告一项实验的设计；可复现性同样无从谈起，因为它没有给出任何复现材料。置信度：对“扩展思考模式存在且可用”这一事实性宣称，置信度高；对“它带来了多大的能力提升”这一程度性宣称，置信度低——正文能核对的数字太少，条件也说得太粗。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

- 如果独立复现显示，在同样的 256 次采样、评分模型、64k token 预算条件下，Claude 3.7 Sonnet 的 GPQA 得分远低于 84.8%，那么“并行推理时计算带来显著提升”这一说法的数字基础即被推翻。
- 如果提示注入攻击集换成另一批真实攻击样本后，防御率从 88% 大幅回落，那么“缓解措施有效”的说法就需要重新评估。
- 如果有人证明 Claude 3.7 Sonnet 的思考过程内容与它的最终答案之间没有因果关系（例如改写思考过程不改变答案），那么“可见思考过程有助于对齐”这一说法的机制基础即被推翻。

### 替代解释

第一个替代解释：GPQA 的 84.8% 主要来自 256 次采样和评分模型，而不是扩展思考本身。如果去掉并行扩展、只保留串行思考，分数大幅回落，这个解释就成立；如果分数基本不变，作者的解释就更有力。区分两者的办法是报告同一模型在串行与并行两种条件下的分数——而这正是正文没有给出的。

第二个替代解释：宝可梦的三块徽章主要来自脚手架（基础记忆、像素输入、函数调用），而不是扩展思考。如果给旧模型配上同样的脚手架也能走出真新镇、打赢道馆，这个解释就成立。区分的办法是做消融：同一代模型，有无扩展思考、有无脚手架，各跑一次。

### 作者自述的局限与分析者发现的局限

作者自述的局限写得很明确：思考过程的忠实性未知，不能用来做强有力的安全论证；可见思考过程可能被用来改进越狱，也可能让模型学会隐藏想法；并行推理时计算在部署模型里还不可用；这只是研究预览。

分析者发现的局限是作者没说的：全篇没有报告任何一项评估的方法细节——OSWorld 与 GPQA 的评估流程、提示、采样方式、样本量一概没有；GPQA 的对照分数只在图里，正文没有；提示注入攻击集的构成完全没有描述；宝可梦演示没有消融对照。这些缺失意味着，读者除了相信作者，没有办法独立核查任何一个数字。

### 接下来看什么

最值得先看的，是思考过程忠实性的可测量化。设计是：构造一组任务，让模型在思考过程里明确写出某个推理步骤，再干预这一步骤（改写或删除），看最终答案是否跟着变；反过来，干预答案、看思考过程是否跟着变。判据是：如果思考内容的干预基本不影响答案，忠实性就不成立，监视思考过程的安全价值也要重估。这个实验比继续刷基准分数更值得先做，因为它决定的是可见思考过程这条路线能不能作为安全论证的依据。

其次看两件事：完整的 Claude 3.7 Sonnet 系统卡里的方法细节（这篇博客明确指向它），以及后续模型是否真的需要 ASL-3——那将是这条能力路线的下一个分水岭。

### 未解问题

- OSWorld 上 Claude 3.7 Sonnet 与前代的分数差距到底有多大？需要图里的数字或系统卡的数据。
- GPQA 上多数投票与评分模型的分数各是多少？需要图里的数字。
- 提示注入攻击集的规模与构成是什么？需要系统卡或后续披露。
- 思考过程的忠实性到底有多差？需要专门的干预实验，目前没有答案。

## §I 收尾综合

### 一句话结论

这篇博客宣布了 Claude 3.7 Sonnet 的扩展思考模式，展示了几个亮眼的演示数字，同时坦承可见思考过程的忠实性未知、不能用来做强有力的安全论证——作为产品说明，它诚实；作为研究，它很薄。

### 核心结论

1. 扩展思考模式是同一个模型里的开关，不是另一个模型；开发者可以用思考预算控制思考时长。置信度高，证据是博客开篇的明确说明。
2. 可见的思考过程有信任、对齐、趣味三点好处，也有观感、忠实性、安全三点代价；其中忠实性未知是最关键的保留意见。置信度高，证据是博客第二、三节的逐项论述。
3. 并行推理时计算在 GPQA 上达到 84.8%（物理子项 96.5%），条件是 256 次独立采样的等效算力、学到的评分模型、最高 64k token 思考预算。置信度中，证据是正文给出的数字，但缺少可核对的对照分数。
4. 提示注入防御率从 74% 提升到 88%。置信度中，证据是正文给出的对照数字，但攻击集的构成完全未报告。
5. Claude 3.7 Sonnet 在《宝可梦 红》里打赢三位道馆馆主、拿到三块徽章，而 Claude 3.0 Sonnet 走不出真新镇的房子。置信度中，证据是正文的描述，但没有消融对照，无法归因到扩展思考本身。
6. 安全等级仍为 ASL-2；CBRN 任务上有能力提升，但所有尝试都出现关键失败；未来模型可能需要 ASL-3。置信度中，证据是博客安全一节的定性描述，没有可核对的数字。

### 关键结果

| 结果 | 数字 | 条件 |
|---|---|---|
| GPQA 总分 | 84.8% | 256 次独立采样等效算力，学到的评分模型，最高 64k token 思考预算 |
| GPQA 物理子项 | 96.5% | 与上同 |
| 提示注入防御率 | 88%，无缓解措施时 74% | 抗提示注入训练 + 系统提示 + 分类器，计算机使用场景 |
| 宝可梦进度 | 3 位道馆馆主，3 块徽章 | 基础记忆、屏幕像素输入、函数调用，数万次交互 |
| OSWorld 差距 | 仅图内，未核实 | 正文只说“起步稍好、差距随时间拉大”，无数字 |

### 科学价值总评

认知价值：确认了推理时计算可产品化这一方向，但没有推翻或确立任何具体科学信念。方法价值：没有留下可直接复用的方法、度量或实验设计，价值在于宣布和示范。边界价值：作者自己把边界写得清楚——忠实性未知、并行扩展未部署、ASL-2 仍适用。启示价值：最值得做的下一步是把思考过程的忠实性变成可测量的东西。总评：这篇博客值得被记住的不是它的数字，而是它的自我保留——它在宣布一个亮眼能力的同时，提前写下了这个能力不能用来做什么。

### 适用边界

这篇博客不证明扩展思考带来了多大的能力提升，不证明可见的思考过程能用来监督模型，也不证明并行推理时计算已经可用。任何人都不应该拿它的 GPQA 分数去论证“模型本身”有多强——那个分数属于一整套重型推理时流程；也不应该拿“看得见思考”去论证模型是安全的——作者自己已经说了这条论证不成立。
