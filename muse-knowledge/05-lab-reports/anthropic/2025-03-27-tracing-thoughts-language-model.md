## 一、背景与问题

### 模型不是被编程出来的，是被训练出来的

语言模型不是由人直接编程的，而是在大量数据上训练出来的。训练过程中，模型自己学会了解决问题的策略。这些策略被编码在模型为写出每一个词而执行的数十亿次计算里，对模型的开发者来说也是不可捉摸的。也就是说，我们并不知道模型是怎么做它所做的大部分事情的。

知道模型是怎么“想”的，不仅能让我们更好地理解它的能力，也能帮助我们确保它在做我们希望它做的事。比如：Claude 会说几十种语言，它脑子里用的是哪种语言？它一次写一个词，是只盯着下一个词，还是会提前规划？它能一步步写出推理过程，这份解释是它真实走过的步骤，还是为已经得出的结论编造的 plausible 说辞？

### 从特征到电路

机制可解释性（mechanistic interpretability）这个领域的办法，是用人类能理解的语言描述这些变换。Anthropic 团队此前的做法分两步：先找出特征（feature）——模型计算中使用的、可解释的基本构件；再描述这些特征相互作用、产生模型输出的过程，也就是电路（circuit）。

直接拿模型的原始神经元当基本构件是行不通的，因为神经元常常是多义的（polysemantic）——一个神经元混合代表许多不相关的概念。原因之一是叠加（superposition）：模型要表示的概念比神经元多，只能把概念“涂抹”在许多神经元上。基本计算单元与有意义的概念之间的这种错位，一直是机制可解释性议程的主要障碍，在理解语言模型时尤其如此。

近几年，稀疏编码方法——稀疏自编码器（SAE）、转码器（transcoder）、跨层编码器（crosscoder）——成了识别叠加中可解释特征的有前景的工具。它们把模型激活分解成稀疏激活的分量（特征），这些分量在很多情况下对应人类可解释的概念。但这些方法本身并不完美，作者在局限一节里也承认这一点。尽管如此，特征已经可解释到让作者有动力去研究由这些特征组成的电路。

### 这篇要回答的问题

这篇论文要讲的问题可以说成一句话：能不能造出一套方法，把语言模型在某个具体提示上的计算，忠实地重写为一张由可解释特征组成的归因图，并且验证这张图说的机制是真的？

逼出这个问题的反常是，可解释性工作长期停留在“模型里有这些概念”的清单上，而没有回答“这些概念是怎么相互作用、产生输出的”。重要性分两面：对领域来说，从特征清单走到电路图，是机制可解释性从描述走向解释的关键一步；对实践来说，如果能追踪模型的真实推理过程，就能审计它是否在按我们希望的方式行事——比如它的思维链是否忠实、它是否在规划、它是否藏着别的意图。

之前做不了，是因为设计空间太大：用什么样的特征、怎么定义特征之间的相互作用、怎么把图剪到能看、怎么验证图说的机制是真的，每一步都有多种选择，而且彼此牵连。这篇论文的办法，就是把作者团队当前的一整套选择固定下来——跨层转码器、归因图、线性归因、剪枝、干预验证——逐一讲清楚，并用定量评估量出它在哪里奏效、在哪里失效。

如果答案成立，改变的是可解释性工作的方式：研究者手里多了一台“AI 显微镜”，可以对任意提示算出一张图、贴上标签、做干预验证，而不是只能凭行为猜测模型内部发生了什么。但这篇论文的结论也是有保留的：显微镜目前只能看到全部计算的一小部分，而且它看到的未必就是原模型自己的机制。

## 二、方法与设计

### 跨层转码器与替换模型

这篇论文的方法建立在跨层转码器（cross-layer transcoder，CLT）上。一个 CLT 由与原模型层数相同的若干层特征组成，目标是用稀疏激活的特征重建原模型各层 MLP 的输出。第 ℓ 层的特征从该层的残差流（residual stream）读入，但可以向之后所有层的 MLP 输出写出——这就是“跨层”的含义。各层所有特征联合训练。

有了训练好的 CLT，就可以定义一个“替换模型”（replacement model）：把原模型每一层 MLP 的输出，换成 CLT 特征对它的重建。跑替换模型的前向传播，与跑原模型几乎一样，只在两处不同：进入第 ℓ 层 MLP 时，先算出该层 CLT 特征的激活；离开第 ℓ 层 MLP 时，用 CLT 特征的输出之和覆盖 MLP 的输出。注意力层则照常运行，不做修改。

作为一个简单的检验，作者测量了替换模型与原模型最高概率输出一致的比例。最大的 18L CLT 在约 50% 的多样化预训练风格提示上与原模型一致——条件是只看原模型预测正确、且置信度低于 80% 的 token。这个数字说明替换模型还远不是原模型的完美复制，但已经好到值得研究。CLT 的规模从 30 万到 1,000 万个特征（18L），以及从 30 万到 3,000 万个特征（Haiku），训练所用的 token 数分别为约 30 亿与约 160 亿。

### 局部替换模型与虚拟权重

全连接神经网络：输入是提示中每个 token 的 one-hot 向量，神经元是所有 token 位置上激活的 CLT 特征，权重是特征之间所有线性路径的加总效应（经由残差流和注意力，不经过 MLP 或 CLT 层）。因为注意力模式和归一化分母被冻结，源特征的激活对目标特征的预激活的影响沿每条路径都是线性的，作者称之为“虚拟权重”（virtual weights）。除此之外还有对应误差项的偏置型节点。局部替换模型里唯一的非线性，是作用在特征预激活上的 JumpReLU。

### 归因图的构造

归因图就是对这个局部替换模型做的因果图。作者一边讲方法一边走一个案例：让模型给虚构的机构名写缩写，提示是“The National Digital Analytics Group (N”，模型补全为“DAG”。由于分词器使用特殊的“Caps Lock” token，实际目标 token 是小写的“dag”。

图里有四类节点。输出节点对应候选输出 token：只为达到 95% 概率质量所需的 token 建节点，最多 10 个（这个阈值是任意选的；作者说，在研究的案例里，通常不到 3 个 logit 就能覆盖 95% 的概率）。中间节点对应每个提示 token 位置上激活的 CLT 特征。主要的输入节点对应提示 token 的嵌入。额外的输入节点（“误差节点”）对应每层 MLP 输出中 CLT 没有解释的部分。

边代表局部替换模型里的直接线性归因。源特征节点 s 到目标特征节点 t 的边权重定义为源特征的激活乘以两者之间的虚拟权重；虚拟权重本身是目标特征预激活对源特征激活的导数（对局部替换模型里所有非线性加 stop-gradient）。在原模型的语言里，这个权重是所有线性路径（经由注意力头的 OV 矩阵和残差连接）之和。实际计算用反向雅可比（backwards Jacobians）高效完成，附录里给出了完整公式和基于路径展开的推导。

因为所有非线性都被加了 stop-gradient，任何特征节点的预激活就是其所有入边的简单加和。因此归因图的边给出了每个特征活动的线性分解。但图里不包含节点通过影响注意力模式而产生的相互影响：它记录了信息从一个 token 位置流向另一个的信息，但不解释模型为什么要把信息移过去。换句话说，这个方法捕捉 OV 电路（OV-circuits），忽略 QK 电路（QK-circuits）。

### 剪枝与超节点：让图变得可读

即使特征是稀疏的（每个 token 位置约一百个激活特征），完整的归因图仍然大到没法看：短提示的边数就能增长到数百万条。好在通常只有一小部分子图承载了从输入到输出的主要路径。

作者用一个两步剪枝算法，先剪节点再剪边。核心是间接影响矩阵：把图的邻接矩阵取绝对值、按行归一化得到无符号邻接矩阵 A，再算 B = A + A² + A³ + … = (I − A)⁻¹ − I。B 的元素表示一对节点之间所有路径的强度之和。把对应 logit 节点的行按输出概率加权平均，就得到每个节点的 logit 影响分数。按这个分数排序，保留累计影响达到阈值（节点默认 0.8，边默认 0.98）的节点和边。输出节点单独处理：保留累计概率超过 95% 的最高概率 token，最多 10 个。嵌入节点和误差节点不剪。默认参数下，节点数通常减少约 10 倍，边数减少约 500 倍，而完整性只降低约 20%。

即使剪完，图仍然信息密集：剪过的图常常包含数百个节点和数万条边。因此作者开发了一个交互式可视化界面，支持沿着图“追踪”关键路径、回看探索过的节点和路径、按需调取解释特征所需的材料。界面还支持把节点子集聚合成“超节点”（supernode）。

超节点是另一个关键的、但作者承认不太有原则的抽象。归因图里常常有一组特征共享与当前提示相关的同一个侧面——例如提示里“Digital”一词上有三个特征，分别对不同大小写和语境下的“digital”响应，但对这个提示而言唯一重要的是这个词以 D 开头，而且三者都向同一组下游节点发正边。把它们当作一个整体来分析是合理的。分组的策略取决于具体分析：按相似的激活语境、相似的嵌入或 logit 效应、相似的输入输出边来分组，一般希望超节点内部的节点互相促进、对外的影响同号。作者试过基于解码向量或图邻接矩阵聚类的自动化方法，但没有一种能覆盖说明特定机制所需的全部的分组成分，因此目前主要靠人工分组。

### 给特征贴标签

特征的解释沿用作者此前工作里的可视化方法：看它在哪些数据集样本上激活最强，以及它通过解码和 unembedding 直接促进或抑制哪些输出 token。作者有时用自动化可解释性流程的标签做起点，但一般发现人工标签更可靠。

最容易贴标签的是两类：输入特征（在特定 token 或相近 token 类别上激活，常见于早期层）和输出特征（促进模型输出特定 token 或 token 类别，常见于晚期层）。例如一个特征在“digital”“digitize”等词上强激活，就标为“digital”特征；一个特征强激活时后续文本总是“dag”，且直接效应上最促进“dag”这个 token，就标为“say 'dag'”（“说 dag”）。中间层的特征更抽象，需要结合激活语境、logit 效应和图里的连接来判断，例如“在未完成缩写的前一两个字母上激活”标为“继续写缩写”，“抑制缩写样字母”标为“抑制缩写”。作者承认，即使不完美的标签也足以在图里发现显著的结构。

### 用干预验证归因图

图里的节点提示哪些特征重要，边提示它们如何重要。验证的办法是对原模型里的特征做扰动，看下游特征或模型输出的变化是否与图的预测一致。特征的干预方式是修改它算出的激活，并把修改后的解码注入，代替原来的重建结果。

跨层特征向多个输出层写出，因此干预要选一个层的范围。作者的方法叫“受约束补丁”（constrained patching）：在给定层范围内修改每个特征的解码，然后从范围内的最后一层开始做前向传播；由于不根据范围内早期的干预结果重新计算某一层的 MLP 输出，干预在范围内的二阶效应被排除在外。这样做是为了避免重复计算特征的效应：一个第 1 层的特征向第 2、3 层及以后写出，如果在每一层都把它的解码向量加进残差流，第 2 层重建的激活在原模型里本是第 3 层激活的上游原因，效应会被重复计算，层数越多重复越严重。附录还介绍了另一种“迭代补丁”（iterative patching），它允许范围内的连锁反应，但更容易累积误差，且作为图的验证手段不够精确。

作者展示了一种乘法版的受约束补丁：把目标特征的激活乘以 M。在验证实验里，他们通常把超节点里每个特征的激活设为原来值的相反数（即乘以 −1 的转向），而不是直接消融为 0，理由在附录“未解释方差与转向因子的选择”一节讨论：字典没有完全重建激活，单特征干预往往需要“超额补偿”才能看到效应。

一个方法论上的重要细节：归因图是用原模型的注意力模式构造的，扰动实验里注意力模式也被冻结在未扰动前向传播的值上。因此这些结果不反映扰动可能如何改变注意力模式本身。

### 全局权重：从单个提示走向一般机制

归因图只讲一个提示上的特征相互作用。作者还想得到更全局的图景：特征之间的相互作用在所有语境下是什么样的。在经典 MLP 里，全局相互作用由权重给出；在这里，特征之间的相互作用有一个与语境无关的分量和一个与语境有关的分量。

与语境无关的分量就是虚拟权重：下游特征的编码器与两者之间各层解码向量之和的内积。源特征 s 对目标特征 t 的残差直接影响，就是虚拟权重乘以 s 在这个提示上的激活。注意力直接影响也可以写成虚拟权重，但要乘上注意力模式，更复杂。

虚拟权重有一个大问题：干扰（interference）。因为数百万个特征都通过残差流相互作用，两个在数据分布上从不一起激活的特征之间也可能有很大的虚拟权重。这些连接从不影响网络的功能，因此不能作为全局权重。作者用一个“说一个游戏名”的特征举例：按虚拟权重大小排序，最强的连接里很多是难以解释或与概念明显无关的特征。

有两种基本的解决办法。一是把研究的特征集限制在某个小领域内激活的特征上（加法一节就是这么做的）。二是引入特征在数据分布上的共激活统计。作者定义了两种修正权重：期望残差归因（expected residual attribution，ERA），即虚拟权重乘以目标特征激活时源特征激活的期望；以及目标加权期望残差归因（target-weighted expected residual attribution，TWERA），用目标激活值本身加权，V^TWERA = E[a_j a_i] / E[a_j] · V_ij。按 TWERA 排序后，同一个游戏特征的连接变得可解释得多，原来最可解释的几个连接保留了下来，大量无关概念被过滤掉了。

但 TWERA 并不完美：很多极小的虚拟权重会有很强的 TWERA 值，说明它对共激活统计的依赖很重；而且它和一般的归因方法一样处理不好抑制。作者把这些问题留待未来工作。

## 三、主要发现

### 缩写案例：三条平行路径

在“The National Digital Analytics Group (N”→“DAG”这个案例里，归因图显示出三条主要路径，分别从组成缩写的三个词出发。每条路径从某个词的特征出发，促进“说出该词首字母、放在正确位置”的特征，这些特征再向“say DAG”特征和 logit 发正边。每个特征组除了经由序列路径的边之外，还有一条直接通向 logit 的边，代表只经由注意力头 OV 电路、不经过另一层 MLP 的效应。

图里还有“处于缩写之中”和“缩写开头是 N”这样的特征向 logit 发正边，说明模型也需要判断“要输出一个缩写”以及“提示里已经有 N 了”。“National”这个词对 logit 的影响很小，作者推测这是因为它的主要贡献是通过影响注意力模式实现的，而这正是本方法解释不了的部分。

干预实验支持了图的预测：抑制每个词的超节点，会依次抑制相关的首字母特征；抑制“Digital”和“Analytics”超节点都会影响“say DA_”超节点。归因图还能指出某个特征的解码在哪些层对 logit 的下游效应最大：例如“Analytics”超节点的特征主要通过 13 层及以后的“say _A”“say DA_”“say DAG”特征间接贡献，因此对“Analytics”特征做负向转向时，对 dag logit 的效应在 13 层之前达到平台、接近最后一层时又因受约束补丁的性质而衰减。

### 事实回忆案例：两条平行路径

事实回忆的提示是“Fact: Michael Jordan plays the sport of”，模型以 65% 的置信度补全为“basketball”。超节点图显示出两条主要路径：一条从“plays”和“sport”出发，促进“sport”和“say a sport”特征，再促进 basketball、football 等多个运动的 logit；另一条从“Michael Jordan 和其他名人”出发，促进与篮球相关的特征，这些特征向 basketball logit 发正边、向 football logit 发负边。此外，“Michael Jordan”和“sport/game of”等特征组还有直接通向 basketball logit 的边，代表只经由注意力头 OV 的效应，与 Batson 等人的发现一致。

图里还有一组复杂的机制，负责把关于 Michael Jordan 这一实体的信息送进“Jordan”位置的残差流，作者把它并成一个超节点，其中包括对“Michael”敏感的特征、已经识别出“Michael Jordan”这一 token 对的第 1 层特征、其他名人的特征，以及在“Michael Jordan”和不相关概念上都激活的多义特征。作者特意说明，只要共享与提示相关的侧面，多义特征也可以放进超节点。

转向实验再次验证了图的假设：消融“sport”或“Michael Jordan”超节点都对 logit 有很大影响，但对另一个超节点的影

### 加法案例：一袋启发式，而不是一套算法

加法研究用的提示是“calc: 36+59=”。作者加“calc:”前缀是因为 18L 在有这个前缀时表现好得多；Claude 3.5 Haiku 不需要这个前缀，但为了直接比较还是保留了。作者选两位数加法，是因为它是最简单的、几乎所有大语言模型和成年人都能胜任的行为。

为了看清每个特征在干什么，作者在通用特征可视化之外，补充了一种覆盖全部两位数加法问题的专用可视化：对在“=” token 上激活的每个特征画三张图——操作数图（在 100×100 的输入网格上显示激活）、输出权重图（对输出 0–99 的直接权重）、嵌入权重图（嵌入向量对特征编码器的直接效应）。在这个受限的领域里，操作数图就是 CLT 特征作为函数的完整描述：图里的条纹和网格代表不同结构（对角线表示对和的约束，网格表示模约束）。

超节点图显示，信息从输入特征出发，分出三条主要路径：末位路径（mod 10）、中等精度路径和低精度路径，共同产生和的中等精度值与末位数字，最后建设性干涉，给出和的 mod 100 版本与最终输出。作者按两个轴给加法特征分类：计算角色（和特征：操作数图呈对角线，在和满足某条件的输入对上激活；查找表特征：图呈网格状，由“条件一（a）且条件二（b）”构成；加法函数特征：图呈横条或竖条；多数激活特征：在 10,000 个加法提示里大多数的“=” token 上都激活；杂项特征：混合模式，对输出影响较小）与条件性质（精度：个位精度、精确范围、宽度 2–50 的模糊范围；模：绝对值、mod 10、mod 100，较少见的有 mod 2、mod 5、mod 25、mod 50；模式：如“以 51 开头”这类正则风格的模式）。

这些发现与已有的机械研究大体一致：Nikankin 等人提出的“启发式之袋”（bag of heuristics）解释认为，模型用一组高低精度、不同模数的“操作数”特征和“结果”特征并行工作。作者补充了一个新发现：查找表特征的存在。这类特征似乎是模型结构与 CLT 结构共同作用的结果：神经元和 CLT 特征的激活都是对其输入之和施加非线性得到的，这产生了一个“平行四边形约束”——如果一个特征在 x+y 和 z+w 上激活，它至少要在 x+w 或 z+y 之一上激活。因此输入特征不可能一步产生一般的“和 = 5”特征（它在 1+4 和 2+3 上激活，就至少要在 1+3 或 2+4 之一上激活），中间必须有一步：查找表特征就是加法里的这些中间步骤，具体来说，是“把两个操作数个位相加得到的个位数”和“两个 20 多的数之和的大致量级”这类中间信息。

干预实验验证了图的结构：抑制任一输入 token 上的个位特征，会压制整个个位通路（_6 + _9 查找表特征、随之而来的 sum=_5 和 sum=_95 特征），而量级通路基本不受影响，包括 sum~92 特征。引人注目的是，抑制 _6 时模型会很有把握地输出 98 而不是正确答案 95——十位数字由其他量级信号保留，个位数字变成了 9+9 的结果。但抑制 _9 时输出的是 91 而不是 92，所以这种数字命理学要打个折扣。反过来，抑制任一输入上的低精度特征（~30 和 ~59），会压制低精度查找表特征、量级和特征与相应的和特征，而个位通路不受影响。定量上，负向转向 _6 + _9 查找表特征会把结果涂抹到一个宽度为 5 的范围上，负向转向最终的 sum=_95 特征则涂抹到更宽的范围。

### 全局权重看加法：从“一袋启发式”到“启发式之图”

回到 Haiku 3.5 的加法问题，作者用数据无关的虚拟权重揭示了加法特征类型之间的清晰结构。研究对象是 10,000 个“calc: a+b=”提示（a、b 在 0–99 之间），把庞大的虚拟权重矩阵限制在至少在 10 个提示上激活的特征集上。

在 36+59 提示附近的特征邻域里可以看到：“_6 + _9”查找表特征馈入其他和特征（sum=_15、sum=_25 等）；“add _9”特征馈入其他个位查找表特征（_9 + _9、_0 + _9 等）；“sum = _5”特征由其他查找表特征馈入；中等精度的“~36+60”查找表特征除了本提示里的“add ~57”特征之外，还由“add ~62”特征馈入。作者还提供了一个交互界面，供探索 18L 模型里 2,931 个在两位数加法问题上突出的特征之间的虚拟权重。

把研究范围限制在这个狭窄的加法领域后，得到的全局电路图里大多数边都能用源特征和目标特征的操作数函数来解释；特征之间的连接复现了上一节图的更一般版本：加法特征检测输入中某个特定的操作数，查找表特征把这些信息传递给和特征，和特征（与之前的特征一起）产生模型的最终答案。许多特征以启发式的方式直接把预测推向输出：低精度特征促进与其操作数范围匹配的输出，个位查找表特征直接促进与其映射匹配的输出（例如 _6 + _9 直接提升 _5 输出）。几乎没有特征在模型的最后几层之前代表完整的解。作者的结论是：从 CLT 的视角看，模型使用的是若干中间启发式，而不是一个有单一确信输出的连贯程序。

作者还把这项工作与 Kantamneni 和 Tegmark 的并行工作对照：后者从表征出发，发现整数嵌入向量的傅里叶分解里有尖峰，找到与数的量级和 mod 2、5、10、100 分量高度相关的低维子空间，提出一个在每个模数上分别计算、最后建设性干涉的“时钟”（Clock）算法。CLT 特征显示的本质上是这种方法的高低精度版本。但作者也指出，不能保证 CLT 特征是最简洁的计算分解方式：一些重要的特征（如以固定数字开头的操作数或和，如 95_、9_）不能用傅里叶项描述，这与低秩近似存在误差是一致的；一些较不重要、近似周期性的特征可能是表征周期性方面的产物。

总的来说，作者认为他们复现了用启发式理解基础模型的视角，找到了与之匹配的 CLT 特征，通过干预实验展示了这些启发式如何分出可分离的通路、又如何相互连接、共同解决加法任务。

## 四、定量评估

### 评估什么：可解释性、充分性、机制忠实度

作者先把评估问题拆成三个维度。可解释性：单个特征的“意思”有多好理解？作者用几种方法定量衡量，但实践中仍然 heavily 依赖主观评价。超节点分组的合理性没有定量评估，留给读者自己验证。充分性：剪过的归因图在多大程度上足以解释模型的行为？最直接的衡量是替换模型的输出与原模型的匹配程度；此外还有几种较“软”的充分性度量，衡量图中误差节点的占比。机制忠实度：图里识别的机制是不是模型真正使用的机制？用扰动实验衡量：抑制或激发特征，看效应是否与局部替换模型的预测一致。

作者坦言，这些评估方法很多是这项工作新创的，部分原因是这项工作独特地关注单个提示的归因图，而不是识别支撑整个任务的电路。开发更好的自动评估方法，是未来研究的重要课题。

### 特征本身：定性与定量

特征可视化展示的是让特征最强激活的数据集样本（来自 Common Corpus、去书版 The Pile、LMSYS Chat 1m、Isotonic Human-Assistant Conversation），以及从最大激活到零之间不同程度激活的样本；同时展示该特征通过 unembedding 直接最促进或抑制的输出 token。论文展示了从两个模型各层随机抽取的 50 个特征。

粗略看，特征分几类：表示文本低层性质的输入特征（多见于早期层，但中晚层也有）；表示语境抽象性质的特征（例如“混合常见清洁化学品的危险”，多见于中晚层）；执行功能的特征（例如“加 9”特征，让模型输出比语境中另一个数大 9 的数，多见于中晚层）；促进特定输出的输出特征（例如“说一个首府”特征，促进各州首府名称对应的 token）；以及多义特征，尤其在早期层，例如一个特征在“rhythm”、Michael Jordan 和其他几个不相关概念上都激活。作者还注意到，Haiku 的特征在很多情况下比小模型 18L 的更丰富，这与模型能力更强一致。

定量上，随着 CLT 规模增大，重建误差（跨层平均）与稀疏性（L0，即每个输入 token 平均激活的特征数）都出现帕累托改进：在 18L 上，重建误差下降而 L0 大致固定；在 Haiku 上，两者都下降。最大的 18L CLT（1,000 万特征）达到归一化平均重建误差约 11.5%、平均 L0 为 88；最大的 Haiku CLT（3,000 万特征）达到 21.7%、平均 L0 为 235。

作者还计算了两种基于大语言模型的特征可解释性定量度量。排序评估（Sort Eval）：取两个随机特征，展示各自最强激活的数据集样本集，让 Claude 猜测只激活其中一个特征的新样本属于哪个特征；分数是 Claude 猜对的经验概率。对照评估（Contrastive Eval）：用 Claude 生成内容结构相似、但关键处不同的一对提示，计算只在一个提示上激活的特征集，展示特征可视化与两个提示，让 Claude 猜是哪个提示让特征激活；分数是猜对的经验概率。按这两种度量，CLT 特征的质量随规模提升（重建误差也同时改善）。但要注意，作者让训练步数随特征数一起增加，因此改进是两种扩大规模方式的共同效果。

与两个基线比较：每层一个标准转码器的逐层转码器（PLT），以及按不同阈值截断的原始神经元。结果是，在所有度量上，CLT 都优于 PLT，两者都大幅优于截断神经元的帕累托前沿。

### 图的度量：路径长度、完整性、替换分数

图的度量依赖间接影响矩阵。矩阵的元素表示一对节点之间所有路径的强度之和，路径强度是其组成边的权重之积。对每个节点取它对 logit 节点的影响，就得到重要性度量；同时常比较来自误差节点的影响与来自非误差节点的影响。

第一个度量是平均路径长度：从嵌入节点到 logit 节点的平均路径长度。直觉是路径越短越容易理解，因为需要解释的因果链环节越少。作者比较了用 1,000 万 CLT、1,000 万 PLT 和截断神经元生成的图（未剪枝），按路径长度拆分影响。跨层转码器最重要的优势之一，就是缩短了图中的路径长度。一个生动的例子是提示“Zagreb:Croatia::Copenhagen:”：逐层转码器给出的路径长度为 7，全部由 Copenhagen 特征组成；而跨层转码器把它们全部压缩到第 1 层。这说明 CLT 会自动把重复计算合并成一个特征，无需事后分析或聚类；也降低了“断链”的风险——放大链条里缺一个特征，就会阻断向回追踪。但代价是 CLT 的因果结构与原模型不同，替换模型的机制偏离原模型机制的风险增大：例子里 Copenhagen 特征激活 Denmark 特征、又形成 Copenhagen 与 Denmark 特征互相增强的链条，这在 CLT 图里是看不见的；如果原模型里也有这种动态，那就是 CLT 在机制上不忠实的一例。

第二个度量是图的完整性与替换分数，衡量有多少图的“影响”来自特征或嵌入节点、而不是误差节点。完整性分数衡量输入边（按目标节点的 logit 影响分数加权）中有多大比例来自特征或嵌入节点而非误差节点；替换分数衡量从嵌入节点到 logit 节点的端到端图路径（按强度加权）中有多大比例经由特征节点而非误差节点。直觉上，完整性分数给“部分 credit”，衡量最重要的节点输入有多少被解释了；替换分数奖励完整的解释。在预训练提示数据集上，未剪枝图的平均分数是：1,000 万 CLT，完整性 0.80、替换 0.61；1,000 万 PLT，完整性 0.78、替换 0.37。作者的结论是，从逐层转码器换成跨层转码器是最大的方法学改进，扩大特征数带来的收益大但递减。

第三个度量是剪枝前沿：改变剪枝阈值，画出节点数、边数与完整性、替换分数之间的权衡。结果是，一般能把节点数减少一个数量级，而完整性只降低 20%。同一提示（另一个缩写）在不同剪枝阈值下的对照是：阈值 0.95 时完整性 0.87、节点 236 个；0.9 时 0.83、137 个；0.8（默认）时 0.70、55 个；0.7 时 0.58、27 个。

### 干预验证：图的影响分数能预测真实效应吗

作者汇总了三类验证实验，细节在附录。第一类，衡量节点的 logit 影响分数对消融特征后模型输出分布变化的预测能力。结果是，影响分数比直接归因（只看图里的直接边、忽略多步路径）和激活大小这两个基线都更能预测消融效应。第二类，衡量特征对之间的影响分数与消融上游特征后下游特征激活的相对变化之间的关系。在 20 个提示的数据集上，两者的 Spearman 相关系数为 0.72，说明图的影响是模型里真实效应的较好代理。

第三类是整体的机制忠实度评估：扰动局部替换模型与扰动原模型，看下游效应是否相同。做法是在单个 token 位置上做三种扰动：沿某个特征的编码向量方向、沿随机方向、扰动上游特征；扰动幅度标定为让被选特征的激活比原来高 0.1。结果是：干预后一层时，两模型的扰动结果还比较相似（余弦相似度约 0.8，归一化均方误差约 0.4）；但分歧随层数显著累积。累积误差对扰动效应方向的影响是渐进的、有害的（方向大体一致，但随词典增大，忠实度有轻微恶化的迹象）；对扰动效应量级的影响则是灾难性的，且词典越大越严重。作者推测，局部替换模型里缺少归一化分母可能是量级偏差如此之大的原因。PLT 的余弦忠实度与 CLT 大体相似；PLT 替换模型在干预后一层的归一化均方误差更低，但最大 PLT 模型的累积误差在几层之后积累得稍快，这可能反映了 CLT 跨层连接让路径更短的优势。

作者承认，这个结果与案例研究里定性上成功的扰动验证之间存在表面上的张力，并给出了三个可能的解释：累积不忠实主要伤害的是扰动量级而非方向，而实践中他们会凭经验尝试一系列扰动强度来补偿；把特征聚合成超节点可能有助于“去噪”忠实度误差；图验证里的扰动实验高度非随机——通常扰动的是“重要”或“关键”的特征，而且是在其输出最强的层上做，部分效应还可归因于附录讨论的“保证效应”。总的判断是：电路描述在非常粗的层面上可能是机制上准确的，但在忠实于原模型方面还有很大的改进空间。

### 姊妹篇概览：十个行为案例

方法论文还概述了姊妹篇《On the Biology of a Large Language Model》的九个（正文如此写，但下面列出十项，见文末未核实清单）行为案例研究，均在 Claude 3.5 Haiku 上做：多步推理（“包含 Dallas 的州的首府是……”中 Dallas→Texas→Austin 的两跳推理，中间的 Texas 表征可以被看到和操纵）；诗歌中的规划（写诗时提前想好押韵词，再写整行去抵达它）；多语言电路（语言特异与语言无关的抽象电路混合，后者在 Haiku 里比小模型更普遍）；加法（同一加法电路在很不同的语境间泛化，Haiku 与小模型的加法机制有质的差异）；医疗诊断（根据症状想出候选诊断，再用它指导追问其他症状，全在“脑子里”完成，不写出步骤）；实体识别与幻觉（区分熟悉与不熟悉实体的电路机制决定模型是回答还是承认不知道，“误触发”会导致幻觉）；拒绝有害请求（微调中形成一个通用的“有害请求”特征，由预训练里学到的具体有害请求特征聚合而成）；一次越狱的分析（先骗模型在“没意识到”的情况下开始给危险指令，再因遵守语法规则的压力继续写下去）；思维链忠实度（区分模型真正执行了它所说的步骤、凭空编造推理、以及从用户给的线索倒推这三种情况）；以及一个有隐藏目标的模型（被微调去追求一个利用训练过程偏差的秘密目标，模型不愿说出口，但方法揭示了它，并且这个目标被“ baked in”进了“Assistant”人格）。

博客的导读用更通俗的语言讲了其中几个发现：Claude 有时会用跨语言共享的概念空间思考（“相反的 small”在不同语言里激活相同的 small 与 opposite 特征）；写诗时会提前规划押韵词（减去“rabbit”概念会让模型改写成以“habit”结尾，注入“green”则写出以“green”结尾但不再押韵的句子）；加法是多条并行路径建设性干涉的结果，而模型自己解释 36+59=95 时说的却是标准的进位算法；思维链有时是编造的（算大数的余弦时没有任何计算发生的证据），有时是被提示的答案倒推出来的。

## 六、作者的结论与局限

### 作者自己得出的结论

作者在讨论一节总结了方法的四个步骤——分解为组件、描述组件、刻画组件如何相互作用产生行为、验证这些描述——并逐一说明哪些选择是稳健的、哪些只是权宜之计。

稳健的选择有四条。第一，用学习到的特征而不用神经元：神经元的高激活常常可解释，低激活不可解释；而把神经元截断到可解释的区间，对模型行为的损害比转码器或 CLT 大得多，因此训练出的替换层在可解释性、L0 和 MSE 上相对截断神经元是帕累托改进。第二，用转码器而不用残差流 SAE：残差流 SAE 分解的是模型的状态，没有自然的扩展来分解计算步骤；转码器特征跨过 MLP 层、经由残差流与其他层的转码器特征线性相互作用，而 SAE 特征之间的相互作用被非线性 MLP 隔开。第三，用跨层转码器而不用逐层转码器：作者假设不同 MLP 层可能协作实现一个计算步骤（“跨层叠加”），极端情况是多层放大同一个早期特征以便它在晚期仍有足够影响；CLT 把这些合并成一个特征，实践中确实在路径长度对图影响的权衡上带来了帕累托改进。第四，用线性直接效应计算特征间相互作用，而不是非线性归因或消融：通过冻结注意力模式和归一化分母，上一层特征与下一层特征预激活之间的直接相互作用变成条件线性的，从而把问题分解为一个可以有原则地从机制上理解的部分和一个留待理解的部分。

权宜之计有三条。第一，合并注意力路径：归因图里的每条边是所有直接相互作用路径的加和，没有区分哪些路径走残差流、哪些走注意力头，丢掉了大量有趣的结构。第二，忽略 QK 电路：为了得到线性的特征间相互作用，作者只问了“给定注意力头的前提下特征如何相互作用”（OV 电路），没有问“注意力头为什么关注这些位置”（QK 电路）。第三，只用稀疏性惩罚和重建损失训练 CLT：最终目标是找到边稀疏、可解释、且机制忠实的替换模型里的电路，但训练时并没有直接针对这些目标优化。

作者的总体判断是：当前方法已经产出了有趣的、经过验证的机制，涉及规划、多语言结构、幻觉、拒绝等行为；并期望在“可训练的可解释替换模型”范式上形成飞轮——具体模型研究中出现的结构启发分解方法的创新，新的分解方法又让更多模型行为变得清晰。

博客的结论说得更感性：这些发现不只是科学上有趣，更是朝着“理解 AI 系统、确保它们可靠”这一目标的实质进展；同时也承认，即使在简短的提示上，方法目前也只能捕捉 Claude 全部计算的一小部分，理解一个只有几十个词的提示的电路也需要几小时的人工。

### 作者承认的局限

局限一节列出七个高层问题，每个都配有具体反例。

第一，缺失注意力电路。归因图是在固定注意力模式下计算的，不解释注意力模式如何形成，也不解释注意力模式如何通过注意力头 OV 矩阵介导特征间的相互作用。在很多情况下，这会让归因图“错过有趣的部分”。作者举了两个例子：归纳（induction）——两层注意力模型里，归纳头因为前一个 token 是“Aunt”而回看“Sally”，但归因图只会说“因为前面有个 Sally 所以预测 Sally”，把整个故事漏掉；在 Claude 3.5 Haiku 上跑同样的提示，问题一模一样。选择题——问“二战哪年结束”，选项 A 1776、B 1945、C 1865，模型答 B；归因图只会说“因为有个在‘(b)’后面出现的 token 的特征”，完全没解释模型怎么知道 1945 是正确答案。进一步调查发现有三个“正确答案”特征似乎在正确答案上激活，干预它们会按预期改变答案（例如在 C 上激活它们会让模型预测 C），但作者坦承：不知道它们是否在某个注意力头的 key 一侧起作用，不知道 query 一侧有没有“需要答案”特征，也不知道有没有其他并行机制。未来的方向是把 QK 电路写成残差流上的二次型，对 key 侧与 query 侧的特征对做归因，但这会带来复杂度的二次爆炸；或者用字典学习处理注意力层。

第二，重建误差与“暗物质”。CLT 不能完全重建模型的激活，因此一部分机制始终观测不到；图中表现为“误差节点”——它们给其他节点提供输入，自己却没有输入、“凭空出现”，且不可解释。在多数例子里，作者还是找到了有趣的机制；但有些情况下误差节点会完全遮住模型在做什么，例如一个经过混淆的、要求写恶意软件的越狱请求（模型拒绝了它），图中被混淆的提示 token 上几乎全是误差节点，无法追溯拒绝相关特征的来源。作者指出，误差的另一个主要来源是人类对特征的解释与特征真实含义之间的差距——解释通常太粗糙，无法说明精确的激活模式。未来的方向包括扩大替换模型规模与训练数据、改进 CLT 架构、端到端训练、针对感兴趣的数据分布微调、以及开发从误差节点反向归因的方法。

第三，不活跃特征与抑制电路的作用。方法的有效性依赖一个关键假设：只有激活的特征才参与模型响应的机制。但实际情况并非如此：某个特征之所以不活跃，可能是因为它被其他特征抑制了，而这恰恰可能是模型响应的关键。例如在姊妹篇的幻觉与实体识别分析里，“不能回答”特征被代表已知实体的特征抑制——要解释模型为什么在特定语境下幻觉，就必须理解是什么让“不能回答”特征没有激活。默认的归因图回答不了这个问题，因为它只显示激活的特征；如果研究者对哪些不活跃特征可能相关有假设，可以把它们加进图里，但这牺牲了方法“无需假设的探索性分析”这一优点。挑战在于如何从数千万个不活跃特征里找出感兴趣的那些。作者在实体识别的例子里用对比提示对（已知实体 Michael Jordan 与未知实体“Michael Batkin”）找出在至少一个提示里激活的特征；未来可能的方向包括做特征消融实验、找出“一次消融之遥”就会激活的不活跃特征。

第四，图的复杂性。即使经过剪枝和可视化，图仍然很复杂：剪过的图通常仍有数百个特征和数千条边；感兴趣的概念常常分散在多个特征上；每个特征接收许多来自其他特征的小输入，难以简洁概括“是什么让这个特征激活”；特征之间还常常通过多条不同长度、甚至不同符号的路径相互影响。因此文中呈现的案例都是经过简化的故事，作者希望更好的替换模型训练、更好的抽象、更复杂的剪枝和更好的可视化能缓解这个问题。

第五，特征不在正确的抽象层次。特征分裂（feature splitting）与特征吸收（feature absorption）问题意味着，特征常常不在最容易理解电路的抽象层次上。一个具体的例子：文中多次提到“say X”特征，但实际上有很多这样的特征，每个都代表更具体的东西。作者找了 12 个 Claude 3.5 Haiku 补全为“during”的提示，测量有没有在全部提示上都激活的特征——结果一个也没有；而且特征的一般性似乎随 CLT 规模增大而降低。作者认为，单个特征各自可能都是可解释的（例如导致说“during”的、定性上不同的语境），但关心的抽象层次与找到的层次常常不同。用更小的 CLT 可能缓解，但代价是捕捉更少的模型计算。超节点是目前的权宜之计：人工把含义相关的特征分组，但这一步劳动密集、可能丢失信息，也让跨提示的泛化研究变得困难。作者认为，解决办法是承认可解释概念存在于不同的抽象层次，需要一种分层的稀疏编码变体；文中提到 Matryoshka SAE 与 meta-SAE 是近期的相关尝试。

第六，理解全局电路的困难。作者承认，全局特征间连接大多难以理解，原因有二：干扰权重（叠加导致模型必须承担无意义的连接，这些连接对性能无害，因为它们很少叠加到改变输出，但让全局权重极难理解；例如一个明显是“say 15”的特征，其 top logit 输出里却有“gag”“duty”“temper”“dispers”等毫不相关的词），以及注意力介导的相互作用（基本的全局权重只描述不经过注意力层的直接相互作用，而注意力介导的权重需要理解不同注意力头如何选择关注位置，涉及 QK 电路的老问题，也没有考虑多头组合的相互作用）。

第七，机制忠实度。即使 CLT 在训练分布上达到了零均方误差，也不能保证它学到的是与原模型相同的输入输出函数，更不能保证在分布外输入上重建误差仍然小。作者希望通过在宽泛的数据分布上训练、强制替换模型重建原模型每层的激活（而不只是输出）来缓解，但无法保证替换模型学到相同的机制，只能事后验证。现有的验证还很粗糙：通常一次扰动多个特征（超节点），只检查对其他特征或 logit 输出的方向性效应；而且通常会扫过扰动的层、取效应最大的那一层。理想情况下，归因图应该能准确预测扰动任意层上任意特征对任意其他特征的效应。附录的定量评估显示，预测能力在扰动后几层内还不错，离得越远越差。

### 加法的教训

讨论的尾声是一个“加法的教训”小节。加法是最简单的行为之一，因为它的结构非常清晰，研究者可以精确刻画每个特征在整个问题域上的活动，从而跳过“盯着数据集样本猜特征在干什么”这一步。即便如此，作者在仅凭原始数据集样本给特征贴标签时也犯了许多错误，例如把一个“_6 + _9”特征误认为“sum = _5”特征，还难以区分不同尺度的低精度特征、以及对有限输入敏感的特征与仅仅因为数据集中这些输入常见而显得敏感的特征。作者反问：如果连加法都这样，那么在拒绝、实体识别这类更模糊的领域里，情况只会更糟。要达到今天的 CLT 似乎已经能够支持的分辨率，需要更精确地区分特征的办法，无论是通过特征几何还是超人类的自动可解释性方法。

## 七、精读点评

### 这篇工作真正新颖的地方

这篇论文最值得记住的不是某一个案例，而是一整套把“电路”从比喻变成可操作对象的工程设计。关键的一步是“替换模型”这个想法的完整落地：用跨层转码器把 MLP 的计算换成稀疏特征的计算，再冻结注意力与归一化、补上误差修正，让原模型的计算在某个提示上被精确地重写为另一套基本单元之间的线性关系。一旦特征间的直接相互作用是线性的，归因就不再是启发式的显著性估计，而是一次定义良好的分解；图里的边权重、剪枝用的间接影响矩阵、干预实验的预测，全部建立在这个线性化的基础之上。

第二个新颖之处是方法论上的自我约束。作者没有把替换模型输出吻合当作终点，而是把“机制忠实度”单独列为一个评估维度，并用定量实验给出了令人不舒服的结果：扰动效应在一层之后还比较一致，越往后越偏，量级上甚至是灾难性的。很多可解释性工作会把验证停在“几个案例里干预有效”；这篇论文把验证做到“系统地量出它在哪里失效”，这是它可信度的主要来源。

第三个值得记住的点是全局权重部分的 TWERA。它用一个很小的改动——把虚拟权重乘上共激活统计——部分解决了干扰权重这个老大难问题，让“说一个游戏名”特征的连接从一堆无关概念变成可解释的邻居。这个想法的迁移价值超出了加法：任何想从字典学习权重里读出“全局电路”的人，都要先回答干扰问题，而 TWERA 给出了一个可复用的、带明确局限的答案。

### 最承重的证据链条与最弱的一环

全篇最承重的结论是“归因图揭示的机制就是原模型实际使用的机制”。支撑它的证据有三层：替换模型在约一半的提示上复现原模型的最高概率输出；图的影响分数与消融效应之间的 Spearman 相关系数为 0.72；三个案例研究里的干预实验（缩写、事实回忆、加法）都按图的预测产生了方向正确的效应。

但这条链条的最弱一环也很清楚，而且作者自己把它写进了局限一节：替换模型与原模型机制相同的保证为零。定量评估显示，扰动效应的方向在一层之后还算一致，但量级上的忠实度随层数累积而崩塌；而且附录里坦承，扰动实验在冻结注意力模式的前提下几乎是“注定”要证实直接边的——因为直接边衡量的就是固定线性权重下的效应，真正被检验的只是多步的连锁效应。换句话说，验证实验最容易通过的那部分，恰恰是方法论设定里已经保证了的那部分；而最难、最关键的那部分（多层之外的连锁反应、注意力模式的变化），恰恰是验证最弱的地方。

还有一个没有被作者强调的弱点：三个案例研究里的干预验证都是在研究者已经看过图、选好了超节点和干预层之后做的。附录承认，扰动实验通常“扫过扰动的层、取效应最大的那一层”，而且转向因子的选择是特设的、凭经验的（常常要把特征钳制到原始值的负数倍，而不是简单地消融为零）。这种事后选择会让验证看起来比实际更强。作者在附录里用“未解释方差”“特征选择不完备”“跨层效应捕捉不完整”三个理由解释了为什么需要超额补偿，这些解释是合理的，但它们同时也意味着：图里画出的机制与干预实际测到的机制之间，隔着一层研究者手工调节的自由度。

### 三个案例的说服力并不相同

缩写案例是最干净的：三条平行路径、每条路径的干预效应都按预期出现、图的结构与语言学直觉吻合。它证明的是方法在“输出主要由内容特征驱动”的任务上能工作。

事实回忆案例的说服力稍弱：两条平行路径的结构得到了验证，但“Michael Jordan”超节点里混进了多义特征（包括一个在“synergy”上激活得比在“Michael Jordan”上更强的特征），作者靠“共享与提示相关的侧面”这一理由把它留了下来。这个理由在方法论上是站得住的，但它也说明，超节点的边界在个案里是由研究者的判断决定的，而不是由某个客观标准决定的。

加法案例是最有分量的，因为它有一个其他案例没有的优势：问题域是封闭的，10,000 个提示覆盖了全部两位数加法，研究者可以精确刻画每个特征在整个域上的行为，而不是靠抽样猜测。查找表特征与平行四边形约束的论证，是全篇最接近“证明”的推理——它从 CLT 特征的数学形式出发，推导出一般和特征不可能一步产生，因此中间步骤必然存在。这也是全篇唯一一个不依赖研究者主观标签的机制发现。

### 效度判断

内部效度中等偏高。方法部分的推导是严谨的：归因图的边权重有明确的数学定义，剪枝算法有完整描述和伪代码，验证实验有对照基线（直接归因、激活大小、PLT、截断神经元）。但验证部分存在事后选择的问题：干预层取效应最大者、转向因子凭经验设定、超节点人工分组，这些自由度都没有被系统地量化和控制。评估用的图数据集只有 n=260，筛选条件也排除了注意力主导的案例（目标 token 不在语境中出现过、损失大于 0.2），因此评估结果说的是“在我们的方法能处理的那类提示上表现如何”，而不是“在一般提示上表现如何”。

外部效度低。这是方法论文的通病，也是作者自己承认的：结论建立在两个模型（18L 与 Claude 3.5 Haiku）上，而姊妹篇的九个案例研究全在 Haiku 上；加法之外的案例都是一两个提示的个案研究，没有系统性的跨任务评估。方法能不能推广到更大的模型、更长的提示、更复杂的推理链，论文没有给出证据；博客也承认，理解一个几十词提示的电路就需要几小时人工，扩展到现代模型数千词的思考链还需要方法与理解方式的双重改进。

构念效度中等。论文对“特征”“电路”“机制忠实度”这些核心概念都给了操作化定义，这是优点。但“超节点”这个概念的操作化是薄弱的：分组标准是“共享与提示相关的侧面”，由研究者按个案决定；“特征”的标签本身也是研究者贴的，而作者在“加法的教训”里承认，仅凭数据集样本贴标签时犯过许多错误。标签错误会直接污染图的解读，而论文没有系统地量化标签的可靠性。

统计结论效度中等。定量评估的数字都带明确条件，这是优点；但关键的可解释性度量（排序评估与对照评估）的具体分数只在图里，正文没有给出数字，无法复核；图评估的样本量只有 260，而且筛选条件本身就有利于方法；干预验证的相关系数 0.72 来自 20 个提示，样本很小，也没有报告置信区间。

可复现性中等。论文分享了交互界面的前端代码、CLT 实现指导、剪枝方法的细节与伪代码，以及训练超参数的部分细节（JumpReLU 带宽 1.0、初始阈值 0.03、预激活损失系数 3×10⁻⁶ 等），一个有能力的读者可以按描述重建一个类似的流程。但 CLT 与 Haiku 的训练权重没有公开，特征可视化的数据集生成细节、评估用的完整提示集、排序评估与对照评估的完整流程只在正文里做了部分描述；要重跑出同样的数字基本不可能。训练成本也不低：按附录的估算，即使在 Gemma 2 9B 模型上，一个 500 万特征、30 亿 token 的 CLT 也要约 3,844 个 H100 小时。

### 科学价值判断

认知价值上，这篇工作确立了一个存在性结论：语言模型的内部计算可以被重写为一张可画图、可干预、可验证的归因图，而不是只能停留在“模型里有这些概念”的清单上。它同时也确立了一个反面结论：这种重写在注意力机制面前会失效，在机制忠实度上会随层数衰减。后一个结论的价值不亚于前一个，因为它给整个可解释性议程划出了一条清晰的边界。

方法价值上，这篇工作留下的最耐用的东西是“替换模型加归因图”这套范式：跨层转码器、局部替换模型、间接影响剪枝、受约束补丁、TWERA，每一步都有明确的定义和可复用的实现细节。这套范式可以直接搬到别的模型、别的字典学习方法上——作者自己也说，换成逐层转码器甚至原始神经元，保留同样的步骤，也能得到有用的结果。相比之下，具体的案例结论（例如加法的三条路径）迁移价值有限。

边界价值上，这篇工作没有证明的东西要说清楚：它没有证明归因图揭示的就是原模型实际使用的机制（忠实度实验恰恰显示了差距）；没有证明方法在注意力主导的行为上管用（归纳与选择题的反例说明它在那里基本失效）；没有证明超节点的分组是客观的（分组是人工的、按个案的）；也没有证明全局权重已经解决了干扰问题（TWERA 只是部分解决）。读者最容易误读的推论是“我们画出了模型思考的电路图”——准确的说法是“我们画出了替换模型在一个提示上的计算图，它在局部与原模型一致，但机制是否相同仍需逐案验证”。

启示价值上，最值得先做的下一步实验是：把机制忠实度评估从“方向”做到“量级”——具体做法是，对一组固定的特征对，在多个层距上系统地比较替换模型与原模型对同一扰动的响应，画出忠实度随层距衰减的曲线，并检验“超节点聚合是否真的能去噪忠实度误差”这个作者在附录里提出的猜想。如果聚合确实能去噪，超节点就从权宜之计升级为有理论支撑的抽象；如果不能，那么目前所有基于超节点的干预结论都要打折扣。这个实验比继续扩大 CLT 规模更值得先做，因为它直接检验整篇工作的最承重假设：我们画的图到底在多大程度上是原模型的图。

## 八、证伪器、替代解释、接下来看什么

### 证伪器与替代解释

有几个具体、可观测的结果能动摇这篇论文的主要结论。如果在一组随机抽取的提示上，图的影响分数对消融效应的预测能力与激活大小基线没有显著差异，“归因图比简单显著性方法更能揭示机制”这个主张就站不住了。如果把注意力模式也纳入扰动（即不再冻结注意力），发现干预效应与图的预测系统性地不一致，“冻结注意力只是无害的简化”这个假设就被证伪了。如果在加法之外的另一个封闭问题域（例如多位数乘法或固定格式的推理任务）里，查找表特征与平行四边形约束的论证不再成立，“CLT 特征必然产生中间步骤”这个机制解释就要修正。

替代解释至少有三个。第一，替换模型走捷径：CLT 特征可能学会的是“用线性近似拟合 MLP 输出”的捷径，而不是原模型真正的计算步骤；输出吻合与干预方向一致都可能是这种近似的副产品。区分办法是构造原模型与替换模型预测分歧最大的提示，看分歧是否集中在图里声称“关键”的边上——如果分歧与图的关键边无关，捷径解释就更有力。第二，超节点掩盖分歧：把含义相近的特征打包成超节点，会让干预实验看起来验证了图，实际上验证的只是一组特征加总起来的效应，单个特征的真实作用可能完全不同。区分办法是对超节点内的特征逐个干预，看效应是否均匀分布，还是集中在一两个特征上。第三，案例选择偏差：三个案例都是作者精挑细选的、方法表现好的提示；评估用的 260 个提示又排除了注意力主导的案例。区分办法是在随机抽取的、未经过筛选的提示集上报告完整性与替换分数的分布，而不是只报告平均值。

### 作者没说的局限

除了局限一节列出的七点，还有两点作者没有明说。第一，特征标签的可靠性没有量化。全文的解读都建立在研究者给特征贴的标签上（“say DAG”“继续写缩写”“抑制缩写”），而“加法的教训”一节承认，仅凭数据集样本贴标签时犯过许多错误。标签错误会直接污染图的解读，但论文没有报告任何标签一致性检验（例如两个研究者独立贴标签的一致率），也没有讨论标签错误对案例结论的影响。第二，方法论文与姊妹篇的分工让这篇论文的“成功”部分依赖于另一篇论文的案例：方法本身的验证主要来自三个案例，而更引人注目的九个行为案例（规划、幻觉、思维链忠实度等）都在姊妹篇里。这篇论文的读者无法仅凭本文判断，那些案例的结论在多大程度上依赖于本文方法的可靠性——而姊妹篇的读者又需要先接受本文的方法。两篇论文互相支撑，但也互相把举证责任推给了对方。

### 接下来看什么

最值得先做的，是把机制忠实度评估从“方向”做到“量级”：对一组固定的特征对，在多个层距上系统地比较替换模型与原模型对同一扰动的响应，画出忠实度随层距衰减的曲线，并检验超节点聚合是否真的能去噪忠实度误差。判据是：如果聚合确实能去噪，超节点就从权宜之计升级为有理论支撑的抽象；如果不能，那么目前所有基于超节点的干预结论都要打折扣。这个实验比继续扩大 CLT 规模更值得先做，因为它直接检验整篇工作的最承重假设：我们画的图到底在多大程度上是原模型的图。

### 未解问题

- 归因图方法在注意力主导的行为上能不能用？需要把 QK 电路也纳入归因，论文只给出了方向，没有给出可用的方法。
- 超节点的分组有没有客观标准？目前是人工、按个案的，需要一种分层的稀疏编码变体来回答。
- 机制忠实度随层距衰减的完整曲线是什么样的？附录只给出了方向性的结果，没有系统的量级曲线。
- 替换模型与原模型的机制差异到底有多大？论文没有给出一个总体的、可比较的度量。

## §I 收尾综合

**一句话结论：** 在冻结注意力模式、补上重建误差的前提下，语言模型的内部计算可以被重写为一张可解释、可干预的归因图；但这张图是替换模型的图，不是原模型本身的图，它的机制忠实度随层数衰减，在注意力主导的行为上基本失效。

**核心结论：**

1. 跨层转码器加局部替换模型的方法是可行的：最大的 18L CLT 替换模型在约 50% 的提示上复现原模型的最高概率输出；最大的 18L CLT 达到归一化平均重建误差约 11.5%、平均 L0 为 88，Haiku 的 3,000 万特征 CLT 达到 21.7%、L0 为 235。置信度：中。证据在数字台账第 1、3、4 条；“约 50%”本身说明差距仍然显著。
2. 归因图揭示的机制在三个案例研究里得到了干预验证：缩写、事实回忆与加法的图结构都按预测对扰动产生了方向正确的效应；图的影响分数与消融效应的 Spearman 相关系数为 0.72。置信度：中。证据在数字台账第 10 条；验证存在事后选择（干预层取效应最大者、转向因子凭经验设定），且样本只有 20 个提示。
3. 跨层转码器在各项度量上优于逐层转码器与截断神经元：未剪枝图的完整性分数 0.80 对 0.78、替换分数 0.61 对 0.37；成本匹配比较中，100 万特征 CLT 用 5–10 倍更少的算力全面优于 1,000 万特征 PLT。置信度：中。证据在数字台账第 9、19 条；可解释性度量的具体分数只在图里，未核实。
4. 机制忠实度随层数衰减，是全篇最诚实的定量结果：干预后一层时余弦相似度约 0.8、归一化均方误差约 0.4；分歧随层数显著累积，量级上的影响是灾难性的，且词典越大越严重。置信度：高。证据在数字台账第 11、12 条；这是作者自己用系统性实验量出的结果，不是推论。
5. 方法有明确的失效边界：在注意力主导的行为（归纳、选择题）上归因图基本失效；误差节点在分布外提示上会完全遮住模型的计算；超节点分组是人工的、按个案的。置信度：高。这不是需要证据的结论，而是作者自己在局限一节用具体反例承认的边界。

**关键结果表：**

| 结果 | 数字与条件 |
|---|---|
| 替换模型复现输出 | 最大的 18L CLT 在约 50% 的提示上与原模型最高概率 token 一致；仅限原模型预测正确且置信度 <80% 的 token |
| 重建误差与稀疏性 | 18L 1,000 万特征：归一化平均重建误差 ~11.5%，平均 L0 88；Haiku 3,000 万特征：21.7%，L0 235 |
| 图的完整性与替换分数 | 未剪枝图：CLT 1,000 万为 0.80 / 0.61；PLT 1,000 万为 0.78 / 0.37 |
| 剪枝 | 默认参数下节点数 ~10 倍缩减、边数 ~500 倍缩减，完整性只降 ~20%；阈值 0.8 时完整性 0.70、节点 55 个 |
| 干预验证 | 图影响与消融效应的 Spearman 相关系数 0.72（20 个提示） |
| 机制忠实度 | 干预后一层：余弦相似度 ~0.8，归一化均方误差 ~0.4；随层数显著累积恶化 |
| 加法 | 18L 在 10,000 个两位数加法提示上 top-1 准确率 98.6%，Haiku 为 100% |
| 成本 | Gemma 2 9B 上 500 万特征、30 亿 token 的 CLT 估算约 3,844 H100 小时（50% 效率） |

**科学价值总评：** 认知上，它确立了“语言模型的计算可以被重写为可解释的归因图”这个存在性结论，同时也确立了“这种重写在注意力与忠实度上会失效”这个反面结论，两者都重要。方法上，它留下的替换模型加归因图范式是这篇工作最耐用的贡献，每一步都有明确定义和可复用的实现细节。边界上，它没有证明归因图揭示的就是原模型实际使用的机制，也没有证明方法在注意力主导的行为上管用。启示上，最值得先做的下一步，是把机制忠实度评估从方向做到量级，系统地画出忠实度随层距衰减的曲线并检验超节点聚合是否真的能去噪。总体上，这篇工作值得因为它造出了一套可用的“AI 显微镜”并诚实地量出了它的误差而被记住，而不是因为它画出了模型思考的完整电路图。

**适用边界：** 这篇工作不证明归因图揭示的就是原模型实际使用的机制，不证明方法在注意力主导的行为上管用，不证明超节点的分组是客观的，也不证明全局权重已经解决了干扰问题。任何人都不应该拿“我们画出了模型思考的电路图”来为“我们已经理解模型为什么这么回答”背书——准确的说法始终是：在冻结注意力、补上重建误差的前提下，替换模型在一个提示上的计算可以被重写为一张可解释的图，而这张图与原模型的机制是否相同，仍需逐案验证。
