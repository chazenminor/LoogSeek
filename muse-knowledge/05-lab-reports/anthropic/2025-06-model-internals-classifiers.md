## 一、背景与问题

### 宪法分类器很好用，但太贵

足够先进的 AI 系统可能带来灾难性风险，例如帮助制造化学、生物、放射与核（CBRN）武器。Anthropic 的宪法分类器（Constitutional Classifiers，Sharma et al., 2025）证明，用一个单独训练的模型来识别危险输入，可以大幅提高对越狱（jailbreak）攻击的鲁棒性。

但这个办法有一个实际问题：它贵。用一个单独的模型做安全过滤，意味着每一次推理都要多跑一个模型。博客给了一个具体数字：用 Claude 3.5 Haiku 给 Claude 3.5 Sonnet 做安全过滤，会让推理成本增加约 25%。

25% 不是一个小数目。如果安全过滤要成为默认配置，它必须便宜得多。否则部署者会在成本压力下把它关掉，或者只在少数场景里开——而安全措施一旦变成可选项，它的实际保护作用就会大打折扣。

### 这篇博客要回答的问题

问题可以说得很直接：能不能复用被保护模型自己已经算出来的东西，来做越狱检测，从而把监测成本降下来，同时不明显损失检测性能？

博客的思路是：策略模型在生成回答的过程中，已经把输入的丰富表征算出来了。与其另起一个模型从头算一遍，不如直接用这些现成的表征。有两种具体的办法：

第一，在模型的内部激活（internal activations）上训练线性探针（linear probe）——一个轻量分类器，读模型某一层的激活，判断输入是否有害。

第二，只重训模型的最后几层——从某一层开始分叉，复用模型的大部分计算，只让最后几层学会做安全分类。

### 为什么这个问题值得做

这个问题的重要性不在“发现了什么新现象”，而在“能不能把一个已证明有效的安全措施变成可部署的默认配置”。宪法分类器已经证明了它能挡住越狱攻击，但如果它贵到没人愿意一直开着，那它的实际安全价值就大打折扣。把成本从 25% 降到 4% 甚至更低，改变的是“这个安全措施能不能成为默认项”，而不是“它能不能工作”。

博客也把边界说得很清楚：这篇工作只解决成本问题，不解决鲁棒性问题。所有结论都建立在“攻击者不知道、也接触不到这些检测方法”的前提下。自适应对抗攻击（adaptive adversarial attacks）——也就是攻击者直接针对这些探针和分类器本身来设计攻击——完全没有测试。

## 二、方法与设计

### 只做输入分类器，不做输出分类器

宪法分类器原本是双分类器架构：一个只看输入（prompt-only classifier），一个只看输出（completion-only classifier）。这篇博客只研究输入分类器，有两个原因。

第一，输入分类器看到的文本和策略模型看到的文本是同一份，所以两者可以共享计算，方法之间可以直接比较。第二，输入 token 占处理总 token 数的绝大部分，所以降低输入分类的成本是最紧迫的。

这意味着，博客的所有结论都只针对输入侧。输出侧的监测能不能用同样的方法便宜下来，这篇博客没有回答。

### 方法一：线性探针（三种变体）

线性探针的想法很简单：在模型某一层的激活上训练一个线性分类器。具体做法是，对输入序列 x，取第 l 层的激活 h（形状是 token 数 × 隐藏维度），用一个池化函数（pooling function）把它压成一个向量，再用逻辑回归（logistic regression）学一个权重向量和偏置，输出“有害”的概率。

博客比较了三种探针变体：

**均值 token 探针（mean-token probe）。** 把所有 token 的激活取平均，再分类。优点是每个序列只用一个向量训练，每个 token 位置都有信号。缺点是在长输入上表现差——危险内容可能只占上下文的一小部分，取平均之后信号会被噪声淹没。

**指数移动平均探针（EMA probe，exponential moving average probe）。** 这是对均值探针的改进。训练方式和均值探针一样，但在评估时，先对每个 token 单独算分，再对这个分数序列做指数移动平均（α = 0.5，取整个序列上的最大值作为最终分数）。这样一来，危险内容即使只出现在少数几个 token 上，也不会被平均掉。α = 0.5 是在预实验里表现最好的取值。

**后缀探针（suffix probe）。** 先前的研究表明，在同一个固定的 token 位置上做探针，效果会更好。博客的做法是，在输入后面追加一段后缀，让模型判断输入是否包含有害生物信息（例如生物武器）。这样探针读到的就是后缀 token 位置上的表征——那个位置被迫汇总了与任务相关的信息。这个方法还能自然地处理“回答以预填文本开头”的情况。

### 方法二：只重训最后几层（部分微调分类器）

最直接的监测办法，是把策略模型本身训练成既能完成主任务、又能做安全分类，或者把鲁棒性直接做到模型行为里（例如短路机制，short-circuiting）。但博客指出，这个办法有代价：可能影响模型的主任务性能、降低打补丁的灵活性、让本来就复杂的策略模型训练过程更复杂。

替代方案是：从模型的某一层开始分叉，复用大部分计算，只重训最后几层，同时保持安全分类器与生产模型之间的隔离。这样既用了策略模型的表征，又不碰它的主任务。

为了找到表达能力与成本之间的最优权衡点，博客训练了多个变体：只重训最后 1 层、2 层、4 层、8 层、16 层，最多到模型一半的层数。选择“只训少数几层”的依据，是早期的探针实验显示，线性探针的质量一直到模型的最后一层都保持很高。

这些部分微调的分类器用下一个 token 预测（next-token prediction）目标训练：补全附录 A 里的后缀，用“有害”或“无害”作答。学习率与训练的层数成反比——如果只训练模型最后 10% 的层，学习率就是训练整个模型时学习率的 10 倍。

### 方法三：多阶段分类器

有了成本不同的分类器，自然的想法是把它们串起来：先用便宜的分类器做第一阶段过滤，把几乎肯定安全的输入筛掉，只把不确定或可能危险的输入交给更贵、更强的模型。第一阶段的分类器给输入打分，低于某个阈值的当作无害，高于阈值的交给第二阶段做最终判断。

博客把第二阶段固定为表现最好、但最贵的后训练 XL 模型，然后比较不同的第一阶段。这个设计有一个内在风险，博客也明确写了：在对抗场景里，即使第一阶段分类器在非对抗数据上的质量只下降一点点，也可能给攻击者很大的优势——如果攻击者能找到稳定绕过第一阶段的方法，那些输入就永远到不了更强的模型。

### 对照基线：更小的专用模型与提示法

作为对照，博客还训练了同一模型家族（Claude 3 Sonnet 家族）里更小的模型作为专用分类器，用的数据混合与大模型相同，并且经过过度训练（overtrained）以优化推理成本。按规模从大到小，这些模型在图里标记为 L、M、S、XS，近似计算开销分别是最大模型的 25%、9%、2% 和 0.6%。

博客也承认一个局限：这些小模型是按“数据量与参数量成正比”的方式训练的。如果为了低推理成本而用远大于这个比例的数据量去训练小模型，它们的性能还会提高。所以这些小模型基线可能低估了“过度训练的小模型”能达到的最好性能。

另一个基线是提示法（prompted XL）：直接把后缀探针的后缀追加到策略模型上，让模型本身判断输入是否有害，不做任何训练。

均值探针和 EMA 探针只需要极少的计算，示意成本定为策略模型成本的千分之一（0.1%）。真实成本取决于架构细节。

后缀探针和只重训一层的模型，都需要对策略模型多跑一段后缀 token。后缀长 150 个 token，假设平均输入长度是 5,000 个 token，所以后缀带来 3% 的开销。博客没有花力气把后缀缩到最短，并指出这个开销很可能可以大幅降低，例如把后缀压缩成一个“要点”（gist）token。

只重训一层的模型，开销是 1 除以策略模型的层数。为了示意，博客借用了 Llama 3 70B 的层数——80 层，对应 1.25% 的开销——再加上 3% 的后缀成本，合计 4.25%。借用 Llama 3 70B 的原因是，它是与 Claude 3 家族大致同期发布的开源权重 Llama 3 家族里的中型模型。

博客给出的示意成本表如下（带星号的数字只是示意，真实值取决于未公开的架构细节）：XS 专用模型 0.6%，S 专用模型 2%，M 专用模型 9%，L 专用模型 25%，EMA 探针 0.1%，均值探针 0.1%，后缀探针 3%，XL 只重训一层 4.25%。

两阶段分类器的成本按公式计算：总成本 = 第一阶段成本 + f × 第二阶段成本，其中 f 是通过第一阶段过滤的无害样本比例。博客只算无害样本的成本，因为它假设在生产系统中，有害输入只占实际流量的极小一部分。

### 延迟的考量

在分类输入时，只有后缀探针和只重训一层的模型可能增加延迟，因为后缀需要对策略模型做额外的推理。小型的专用分类器虽然也要处理稍长的文本，但因为模型小得多、可以并行运行，不需要增加首 token 的生成时间。两阶段流程会增加延迟，但只影响一小部分输入。

博客还指出一个在输入分类设置里看不出来的优势：如果是在输出分类的设置里，探针和部分微调的分类器还有额外的延迟优势——它们的输出可以与主模型的采样同时产生，而独立分类器至少要多等一次前向传播的延迟。

### 实验设置：数据与指标

训练数据约 70,000 条提示，有害与无害各占一半。它是宪法分类器论文所用训练数据集的早期版本。所有样本都由 Claude 3.5 系列模型按书面宪法合成生成，宪法规定了允许与受限的内容类别，其中“教模型新的密码”属于受限类别。这些样本经过“变换”（transformations）处理，例如转换成越狱模板、多种语言、密码、助手预填。

评估数据是留出集（held-out），设计用来检验从合成训练数据到真实用户流量中未见过的越狱的泛化。有害测试样本来自两个来源：约 4,000 条，由一组固定的危险生物学问题经过分布内与分布外的变换组合生成；另外约 2,500 条，是宪法分类器论文红队（red-teaming）阶段收集的、曾触发策略模型有害回答的输入（由输出分类器判定）。

无害测试样本来自两个来源：WildChat 的单轮输入，以及 OR-bench 的“困难”（Hard）子集。由于 OR-bench 包含大量边缘案例和看似有害的提示（虽然不聚焦 CBRN），它上面的误报率预计会显著高于典型用户交互。

评估指标是对数空间 AUROC（log-space AUROC）：把真正例率（TPR）对误报率（FPR）画曲线，但 FPR 取对数间隔。博客用这个指标，是因为它关心低误报率下的性能——这决定了分类器是否适合生产使用。常规 AUROC 在低误报率下不可靠，而只看某一个误报率下的真正例率又太 noisy。对数空间 AUROC 取 FPR 在 1e-3 到 1e-1 之间的范围，能用一个不那么 noisy 的数字概括这个区间的权衡。训练好的模型的分数是多个数据排序（data orderings）下的平均值——图 1 的图注说三个排序，图 2 的图注与附录 B 说两个排序，两处说法不一致（见未核实清单）。

训练方面，所有模型都在约 70,000 条数据上恰好训练一个 epoch，约 2,200 个 batch，batch 大小为 32。对部分微调的分类器，学习率与训练的层数成反比，这个设置来自小数据集上的初步实验——初步实验显示，这个规律接近最大化测试性能的学习率。初步实验还显示，部分微调模型的最优学习率对“微调多少层”很敏感；但用更小的 batch 时，这种敏感性会下降，所以博客用了小 batch 来降低次优设置带来的风险。

## 三、主要发现

### 只重训最后一层，性能接近只比全量重训差一点

博客的核心发现是：只重训最后一层（一个 MLP 加注意力模块）的 XL 模型，性能相当接近全量重训的 XL 模型，在所有方法里仅次于它。它的水平与扫描里次大的专用模型 L（25% 开销）相当，而它自己的成本只有策略模型成本的约 4%（含后缀处理成本）。

换句话说，用一层 resblock 的代价，换到了一个四分之一大小的专用分类器的性能。这是博客标题里“低成本”的最直接证据。

### 探针：EMA 与后缀探针都强，均值探针不行

后缀探针与 EMA 探针的表现彼此接近，介于 S（2% 开销）与 M（9% 开销）专用模型之间。EMA 探针在可以忽略不计的成本下，超过了一个参数量为策略模型 2% 的专用分类器；按博客的插值说法，它的表现相当于一个 3% 开销的分类器。后缀探针的表现稍好一些，大致相当于一个插值后 4% 开销的分类器，但它的成本也高得多，接近专用分类器的成本–性能前沿。

只看输入 token 均值的探针表现最差，甚至不如测试过的最小模型（XS，0.6% 开销）。这个结果验证了 EMA 探针的设计动机：危险内容只占长输入的一小部分时，取平均会把信号淹没。

### 多训几层没有明显更好

博客还测试了重训最后 2、4、8、16 层的情况。结果出人意料：随着训练层数的增加，性能没有明显的趋势。部分微调模型的性能始终略低于全量训练的模型，任何潜在的性能提升都在运行间噪声（inter-run noise）之内。

这个“没有趋势”本身就是一个发现：它说明，只重训一层就已经拿到了这条路的大部分收益，再多训几层并没有带来可测量的回报。结合探针实验里“探针质量一直到最后一层都保持很高”的观察，一个合理的解释是，策略模型最后一层之前的表征已经包含了分类所需的全部信息，分类任务本身并不需要更多的可训练参数。

### 一个反直觉的现象：验证损失与测试性能脱节

部分微调模型的强性能没有反映在验证损失上：它们的验证损失显著高于测试性能相同的全量训练模型。博客在附录 C 里比较了分布内数据的验证损失与对数空间 AUROC，发现部分微调模型的验证损失与那些测试性能差得多的小模型相近。

博客的解释是：部分微调的分类器基于一个更大的模型，这让它对分布外样本的泛化更好，而这种泛化优势没有反映在训练数据的损失里。换句话说，验证损失在这里不是一个可靠的模型选择指标——如果只看验证损失，会错误地低估部分微调模型。

### 两阶段分类器：成本降 10 倍以上，性能基本不降

在两阶段设置里，博客把第二阶段固定为表现最好、最贵的后训练 XL 模型，比较不同的第一阶段。结果是，探针分类器与单层分类器在整个成本范围里都优于更小的专用模型，尤其是在把成本压得越来越低的时候。单层模型总体上表现更好，而 EMA 探针因为成本更低，在低成本端胜过后缀探针。

关键数字是：如果要求开销低于最大模型的 5%，EMA 探针是最好的第一阶段；而 EMA 探针与单层模型作为第一阶段，都能把成本降低 10 倍以上，同时不显著降低整个系统的性能。

还有一个反直觉的发现：两阶段分类器的性能有时会略高于只用最强分类器本身，而且不需要对分类器的分数做平均。博客认为，这是因为两个模型的错误不相关——在第一阶段阈值足够低时，第一阶段会筛掉很多“本来会是误报”的样本，而筛掉的“本来会是真正例”的样本相对较少。但博客也提醒，这个在固定评估集上的改进，不一定能转化为对抗攻击者存在时的系统鲁棒性——如果攻击者能找到稳定绕过第一阶段的方法，整个系统就变弱了。

## 四、作者的结论与局限

博客的结论是：线性探针、部分微调与多阶段分类，都是降低监测系统成本的可行途径。只微调策略模型的一层，性能与一个四分之一大小的专用模型相当，成本只有一个额外的 resblock；对每个 token 做评估的线性探针，性能与一个 2% 大小的模型相当，而计算开销极小。把单层分类器作为第一阶段、与全量模型组合，可以在固定红队输入上做到零性能回归，同时进一步降低成本。

博客的结论里有一个明确的保留条件：这些方法的自适应对抗鲁棒性没有测试，在真实部署之前必须测试。博客希望这些方法能通过让高质量监测不那么昂贵，来改善 AI 安全。

作者自述的局限主要有四条：

第一，这些分类器没有经过宪法分类器论文里那种红队测试。防止危险误用本质上是对抗性问题，红队测试是判断分类器是否真正提供强鲁棒性的必要条件。

第二，多阶段分类器尤其可能打开新的攻击面：如果攻击者能让较弱的模型确信某个输入不危险，这个输入就永远到不了更强的模型。

第三，测试用的小模型都是按“数据量与参数量成正比”训练的。如果为了低推理成本而用远大于这个比例的数据量训练小模型，它们的性能还会提高；更大的数据量，或者模型蒸馏（model distillation）等小模型专用技术，可能会让天平重新倒向小模型。

第四，红队人员攻击的是 Claude 3.5 系列模型，他们不知道、也接触不到博客里的检测方法；而博客的探针与基线用的是 Claude 3 Sonnet 模型，训练数据也不同。所以在直接攻击下的相对鲁棒性可能更差——部分原因是探针集成在被攻击的模型内部。

博客没有明说、但值得注意的另一点是：所有成本数字都是示意性的，不是真实成本。真实成本取决于未公开的架构细节，读者不能把 4.25%、0.1% 这些数字当作部署时的实际开销。

## 六、精读点评

### 这篇东西是什么，不是什么

这是一篇工程方法学博客，不是科学发现论文。它没有提出新的现象，也没有推翻任何理论；它做的是成本–性能权衡的测量：三类便宜的监测方法，与专用小模型基线比，到底能便宜多少、性能损失多少。按精读模板来套，它的格子填得比多数博客满：有明确的问题、有对照基线、有可核对的成本与数据规模数字、有作者自己的局限分析。

但它也比一篇正式论文薄。没有同行评审，没有 arXiv 版本，没有代码与数据发布，所有性能数字只在图里，正文没有逐项列出。这意味着读者无法从正文核对“单层模型到底比 L 模型好多少”这种关键比较，只能相信图里的曲线。

### 这篇博客要回答的问题是什么

博客要回答的问题可以还原成五句话。反常是：宪法分类器已经证明能挡住越狱攻击，但它贵——用 Haiku 给 Sonnet 做过滤要多花约 25% 的推理成本。重要性在于：如果安全过滤贵到没人愿意一直开着，那它的实际安全价值就大打折扣；把成本降下来，改变的是“这个安全措施能不能成为默认项”。之前做不了的原因不是没人想到复用表征，而是没人系统地量过“复用表征到底能便宜多少、性能损失多少”——blocker 是“没有成本–性能的实测比较”。这篇工作的办法是：把线性探针、只重训最后几层、两阶段级联这三类方法，放在同一套数据与指标下，与专用小模型基线直接比较。方法与问题的匹配点在于：成本问题恰好是一个可以实测的问题——不需要新理论，只需要把几种方法放在同一把尺子下量一量。答案改变了什么：认知上，证明了策略模型最后一层之前的表征已经包含了分类所需的全部信息——多训几层没有可测量的回报；实践上，给出了两条可部署的路线（单层重训约 4% 成本、EMA 探针几乎零成本），以及一个两阶段级联的设计。

### 最值得注意的一点：最后一层之前，信息已经够了

这篇博客最有分量的发现，不是“单层模型达到 L 模型的性能”，而是“多训几层没有更好”。重训 2、4、8、16 层，性能没有可测量的趋势，全部落在运行间噪声里。结合探针实验里“探针质量一直到最后一层都保持很高”的观察，这说明分类任务需要的信息，在策略模型最后一层之前就已经存在了。

这个发现的含义是：越狱检测在信息层面是一个“浅”任务——它不需要模型重新学习什么，只需要读出模型已经算出来的东西。这就是为什么线性探针这种几乎不花钱的方法能打到 2% 大小专用模型的水平，也是为什么只重训一层就拿到了大部分收益。

但这个解释也有一个反面：如果分类信息早就存在于表征里，那么攻击者同样可以针对这些表征做文章。博客自己也承认，探针集成在被攻击的模型内部，直接攻击下的鲁棒性可能更差。这个“信息早就存在”的发现，既是这篇博客乐观结论的来源，也是它悲观保留条件的来源。

### 验证损失与测试性能脱节，是一个值得记住的方法论细节

部分微调模型的验证损失显著高于测试性能相同的全量训练模型。这个现象值得单独提，因为它违反了一个常见的直觉：验证损失越低，模型越好。

博客的解释是，基于更大模型的分类器对分布外样本的泛化更好，而这种泛化优势没有反映在训练数据的损失里。这个解释是合理的，但它也是一个事后解释——博客没有做实验来验证“泛化优势来自模型规模”这个机制（例如，比较同一规模下、不同训练方式的验证损失与测试性能）。

对读者的实际教训是：在这个任务上，不要用验证损失来选模型。如果只看验证损失，会错误地低估部分微调模型，甚至可能选错方法。这个细节比博客的主结论更通用：它提醒我们，分布内损失与分布外性能之间的关系，在安全分类任务上是不可靠的。

### 成本数字是示意的，这一点不能轻轻放过

博客里最容易被误读的，就是成本数字。4.25%、0.1%、3% 这些数字看起来很精确，但博客明确说了，它们是示意值，不是真实成本。真实成本取决于未公开的架构细节，而且小模型的成本假设（开销与参数量成正比）在注意力成本占主导时就不成立。

更重要的是，两个关键假设是博客自己承认可以改进的：后缀长 150 个 token，没有花力气缩短；小模型的训练数据量与参数量成正比，没有按“为低推理成本而过度训练”的方式训练。这两个假设的方向是相反的——前者高估了后缀方法的成本，后者低估了小模型基线的性能。所以，博客里“探针与单层模型优于小模型”的结论，是在一个对小模型不利、对后缀方法也不利的假设组合下得到的。结论的方向可能是对的，但优势的大小是不确定的。

### 科学价值

认知价值：中等。它没有推翻任何信念，但确认了一个有用的事实——策略模型内部表征里已经包含了越狱检测所需的全部信息，分类任务在信息层面是“浅”的。方法价值：高。它留下了两条可直接复用的路线（单层重训、EMA 探针）与一个两阶段级联的设计，以及一个明确的评估方法（对数空间 AUROC，关注低误报率区间）。边界价值：高。博客对局限的讨论比较诚实——没有自适应对抗测试、成本数字是示意的、小模型基线可能被低估、多阶段可能打开新攻击面，都写明了。启示价值：中等偏高。它直接指向下一步：对这些方法做自适应红队测试——这是博客自己说的、部署前必须做的事。

### 总体判断

作为一篇工程方法学博客，它是扎实的：问题意识清晰、方法比较系统、对照基线合理、局限讨论诚实。它的主要弱点是证据的完整性：性能数字只在图里、正文没有逐项列出，成本数字是示意的而非实测的，最关键的自适应对抗测试完全没有做。但即使把这些弱点都算进去，核心结论——只重训一层或用一个线性探针，就能以很低的成本达到专用分类器的检测水平——仍然站得住，因为它在多个方法与多个基线上都得到了同样的方向性结果。置信度：高，针对“博客写了什么”与“实验里发生了什么”；中，针对“这些方法的优势在真实部署里有多大”——成本是示意的，鲁棒性是没测的。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

- 如果对 EMA 探针与单层分类器做自适应对抗攻击（攻击者直接针对这些检测方法本身设计攻击），发现它们的性能跌幅远大于专用小模型基线，那么“便宜的方法同样鲁棒”的隐含前提就被削弱，博客的部署建议就要修正。
- 如果用远大于“数据量与参数量成正比”的数据量训练小模型（或用模型蒸馏），发现小模型的性能超过单层模型与 EMA 探针，那么“复用表征优于专用小模型”的结论就要修正。
- 如果把后缀缩短（例如压缩成一个要点 token），发现后缀探针的成本大幅下降、同时性能不变，那么博客里“后缀探针成本高”的判断就要修正——这个结果会加强而不是削弱博客的结论。

### 替代解释

- 替代解释一：单层模型与探针的强性能不是因为“复用了策略模型的表征”，而是因为“分类任务本身很简单”——有害与无害的区分在这个问题上本来就容易，任何 reasonable 的分类器都能做到。如果这个解释是对的，那么在更难的分类任务上（例如更微妙的有害内容、更对抗性的变换），探针与单层模型的优势应该会缩小。区分办法是：在更难的测试集上（例如分布外程度更高的变换、更隐蔽的有害内容）比较探针、单层模型与专用小模型，看优势是否还存在。博客的测试集里已经有分布外变换，但没有按难度分层报告结果。
- 替代解释二：两阶段分类器“有时略高于只用最强分类器”的现象，不是“错误不相关”的功劳，而是评估集的偶然——第一阶段筛掉的样本恰好是评估集里容易误报的那部分，换一个评估集就消失了。区分办法是：在另一个独立的评估集上重复两阶段实验，看“略高于最强分类器”的现象是否还出现。博客没有做这个重复。

### 作者自述的局限与分析者发现的局限

作者自述的局限：没有自适应对抗测试；多阶段分类器可能打开新攻击面；小模型基线可能被低估（数据量与参数量成正比）；成本数字是示意的；红队人员不知道、也接触不到这些检测方法。

分析者发现的局限：所有性能数字只在图里，正文没有逐项列出；图注有一处不一致（图 1 说三个数据排序，图 2 与附录 B 说两个排序）；博客本身没有 arXiv 版本与同行评审；验证损失与测试性能脱节的解释是事后解释，没有验证实验；两阶段“略高于最强分类器”的现象没有在独立评估集上重复；附录 A–D 本次通读，但图 1–图 6 的具体曲线形状未逐项核对（只读了图注与正文对图的描述）。

### 接下来看什么

最便宜的决定性实验，是对 EMA 探针与单层分类器做自适应对抗攻击：让红队人员直接针对这些检测方法本身设计攻击（而不是像这次一样，攻击不知道这些方法存在的 Claude 3.5 系列模型），比较它们与专用小模型基线在攻击下的性能跌幅。判据是一句话：如果探针与单层模型的跌幅与专用小模型相当，博客的部署建议就得到了关键支持；如果它们的跌幅远大于专用小模型，那么“便宜的方法同样可用”的结论就要修正。这个实验比别的后续工作更值得先做，因为它是博客自己承认的、部署前必须做的事，而且它直接检验这篇博客最核心的未验证前提。

其次值得看的是：用过度训练的小模型（远大于“数据量与参数量成正比”的数据量，或模型蒸馏）重做基线比较，看“复用表征优于专用小模型”的结论是否还成立；以及把后缀缩短后重测后缀探针的成本–性能，看它的成本能不能降到 EMA 探针的水平。

### 未解问题

## §I 收尾综合

**一句话结论：** 这是一篇扎实的工程方法学博客——它证明只重训策略模型的最后一层、或在模型内部表征上加一个线性探针，就能以约 4% 甚至可以忽略不计的额外算力，达到一个四分之一大小的专用分类器的检测水平；但所有性能数字只在图里，而且最关键的自适应对抗攻击测试根本没做，所以这是一份“成本–性能权衡成立、鲁棒性待验证”的半成品证据。

**核心结论：**

1. 只重训最后一层（一个 MLP 加注意力模块）的 XL 分类器，性能仅次于全量重训，相当于一个 25% 开销的 L 专用模型，而它自己的示意成本只有策略模型的约 4%（含后缀处理成本）。置信度：高。证据：数字台账 E3。
2. EMA 探针在可以忽略不计的成本（示意值 0.1%）下，超过了一个参数量为策略模型 2% 的专用分类器；按插值相当于一个 3% 开销的分类器。后缀探针稍强一些，大致相当于一个 4% 开销的分类器。置信度：高。证据：数字台账 E4–E5。
3. 均值 token 探针表现最差，甚至不如最小的 XS 专用模型（0.6% 开销）。置信度：高。证据：§三。
4. 重训 2、4、8、16 层没有带来可测量的性能提升，全部落在运行间噪声里；部分微调模型的验证损失显著高于测试性能相同的全量训练模型。置信度：高。证据：§三。
5. EMA 探针与单层模型作为两阶段分类器的第一阶段，能把成本降低 10 倍以上，同时不显著降低整个系统的性能；如果要求开销低于最大模型的 5%，EMA 探针是最好的第一阶段。置信度：高。证据：数字台账 E12。
6. 这些分类器没有经过自适应对抗测试，红队人员攻击的是不知道这些方法存在的 Claude 3.5 系列模型；成本数字是示意的，不是真实成本。置信度：高。证据：§四。

**关键结果表：**

| 结果 | 数字 | 条件 |
|---|---|---|
| Haiku 给 Sonnet 做过滤的成本增加 | 约 25% | 专用分类器设置；宪法分类器论文的部署配置 |
| 只重训一层的示意成本 | 约 4%（表 1：4.25%） | 1 层 / 80 层 = 1.25%，加 3% 后缀成本；示意值 |
| EMA 探针与均值探针的示意成本 | 0.1% | 策略模型成本的千分之一；示意值 |
| 后缀探针的示意成本 | 3% | 后缀 150 个 token，平均输入 5,000 个 token |
| 专用模型基线 XS / S / M / L 的开销 | 0.6% / 2% / 9% / 25% | 占最大模型（XL）成本的比例 |
| 训练数据 | 约 70,000 条 | 有害与无害各占一半；合成生成 |
| 有害测试样本 | 约 4,000 条变换生成；约 2,500 条红队收集 | 生物武器相关；留出集 |
| 两阶段分类器的成本降低 | 10 倍以上 | EMA 探针或单层模型作第一阶段；性能无显著降低 |
| 各方法的对数空间 AUROC 值；各误报率下的真正例率 | 仅图内 / 未核实 | 图 1–图 6；正文未逐项列出 |

**科学价值总评：** 认知上中等——确认了策略模型内部表征里已经包含了越狱检测所需的全部信息，分类任务在信息层面是“浅”的；方法上高——留下了两条可直接复用的路线（单层重训、EMA 探针）与一个两阶段级联的设计，以及对数空间 AUROC 这个关注低误报率区间的评估方法；边界上很诚实——没有自适应对抗测试、成本数字是示意的、小模型基线可能被低估、多阶段可能打开新攻击面，都写明了；启示上中等偏高——直接指向下一步的自适应红队测试。总体上，这篇工作值得因为“它把宪法分类器从一个贵而有效的原型，变成了一个便宜到可以成为默认配置的方案——至少在成本账上是这样”被记住。

**适用边界：** 不要拿这篇博客去主张“便宜的监测方法同样鲁棒”——自适应对抗攻击根本没测，红队人员攻击的是不知道这些方法存在的模型；不要拿 4.25%、0.1% 这些数字当作部署时的实际开销——它们是示意值，真实成本取决于未公开的架构细节；不要拿它去主张“小模型不如复用表征”——小模型基线是按数据量与参数量成正比训练的，过度训练后可能反超；不要拿它去主张输出侧监测也能同样便宜——这篇博客只研究了输入分类器。
