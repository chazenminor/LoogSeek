## 一、背景与问题

### 报告之前是什么局面

AlphaFold 2 在 2020 年解决了蛋白质结构预测问题，2021 年开源后成为结构生物学的标准工具。但它有一个根本的边界：它只预测蛋白质。真实的生物学不是只有蛋白质——蛋白质与 DNA、RNA、小分子配体、离子结合才执行功能，药物发现的核心问题正是小分子如何结合蛋白质。AlphaFold 2 的架构（基于氨基酸骨架 frame 与侧链扭转角的结构模块）本质上只适用于蛋白质，换不了一套坐标系就容纳不了配体与核酸。

与此同时，配体对接（docking）这个老问题一直由基于物理的方法主导：AutoDock Vina、Gold 等工具在已知蛋白结构的前提下预测配体姿态。深度学习方法（DiffDock、RoseTTAFold All-Atom）开始进入这个领域，但成绩参差，尚未形成压倒性优势。

所以 AlphaFold 3 要回答的问题是：能不能用一个统一的模型，预测蛋白质、核酸、小分子、离子与共价修饰共同构成的复合物结构，并且在配体对接这类任务上超过基于物理的传统工具？

### 报告自己的说法

Nature 论文的摘要称，AlphaFold 3 能以前所未有的准确率预测蛋白质与其他分子类型的相互作用，相对现有预测方法至少提升 50%，某些重要类别的准确率翻倍。博客的说法更直接：AlphaFold 3 是“世界上最准确的预测蛋白质与其他分子相互作用的工具”，在 PoseBusters 基准上比最好的传统方法准确 50%，且不需要任何结构输入，是首个超越基于物理的工具的 AI 系统。

博客还宣布推出 AlphaFold Server：科学家可以免费使用 AlphaFold 3 的大部分能力，用于非商业研究，只需几次点击即可建模蛋白质、DNA、RNA 及一部分配体、离子与化学修饰。

## 二、方法与设计

### 架构：三处根本改动

相对 AlphaFold 2，AlphaFold 3 做了三处根本改动。

第一，主干从 Evoformer 换成 Pairformer。AlphaFold 2 的 Evoformer 被更简单的 Pairformer 取代（48 个 block，基本与 AlphaFold 2 的 pair 处理 block 数相同）。Pairformer 只处理 pair representation（维度 n×n×128 通道）与 single representation（n×384 通道），不再保留 MSA representation，所有信息都经 pair representation 传递；也不做 Evoformer 中耦合 MSA 与 pair 的 outer-product mean 操作。

第二，MSA 大幅弱化。MSA 处理缩减为一个小得多的 embedding block：block 数减至 4，用廉价的 pair-weighted averaging，只把 pair representation 用于后续步骤。动机很直接：配体、离子等没有进化比对信息，MSA 不再是必需品。但论文也承认，AlphaFold 3 对 MSA 深度的依赖与 AlphaFold-Multimer v2.3 很相似，浅 MSA 的蛋白质预测精度仍较低。

第三，结构模块换成扩散模块（diffusion module）。AlphaFold 2 的结构模块基于氨基酸特异性刚性骨架 frame 与侧链扭转角，只适用于蛋白质；AlphaFold 3 改为直接预测原始原子坐标的扩散模型：训练时给真实坐标加不同水平的高斯噪声，网络学习去噪还原；推理时从随机噪声出发反复去噪得到最终结构。没有旋转 frame，没有等变（equivariance）处理。

与扩散模块配套的是一处关键取舍：去掉立体化学硬约束。扩散的多尺度特性（低噪声水平迫使网络学好局部结构）使作者得以取消立体化学 violation 损失和大部分键合模式的特殊处理，从而容纳任意化学组分。这是“以通用性换取硬约束”的关键取舍，也是后遗症的来源。

### 生成式带来的幻觉与对策

扩散是生成式过程，会在无序区“发明”看似合理的结构。缓解办法是 cross-distillation：用 AlphaFold-Multimer v2.3 预测的结构丰富训练数据（其中无序区多呈伸展环状），教 AlphaFold 3 模仿这种行为；另在排序中加入鼓励溶剂可及表面积的项。论文称这大幅减少了幻觉（Extended Data Fig. 1，CAID 2 基准）。

置信度头的做法也变了：扩散训练只训单步去噪，无法直接回归全结构误差，因此用 diffusion “rollout”（训练时用较大步长生成完整预测）来训练置信度头，输出 pLDDT、PAE 矩阵及新增的 PDE（distance error matrix，预测与真实距离矩阵之差）。

### 训练与推理制度

三阶段训练，crop 尺寸 384 → 640 → 768 tokens；每 optimizer step 用 256 个样本、12,288 个扩散样本（微调阶段 8,192 个）。一般训练数据截止 2021-09-30；PoseBusters 评估用单独模型，截止 2019-09-30。推理默认从 5 个 model seeds × 每 seed 5 个扩散样本，共 25 个样本中按置信度取最优；抗体–抗原评估则用了 1,000 个 seeds。

训练曲线有一个值得记录的观察：局部结构学得快（20,000 步内达到初始训练最高值的 97%），全局界面学得慢（蛋白质–蛋白质界面 LDDT 到 60,000 步后才过 97% 线）；某些能力过早见顶甚至下降（疑似过拟合），作者通过调整各训练集采样概率和 early stopping（以各指标加权平均选最优 checkpoint）应对。

### 评估设计

评估覆盖多个分子类别。蛋白–配体用 PoseBusters v1（2023 年 8 月版），428 个 2021 年及以后 released 到 PDB 的蛋白–配体结构；AlphaFold 3 用训练截止 2019-09-30 的单独模型评估，确保未训过测试结构。指标是口袋对齐的配体 RMSD 小于 2 Å 的占比，口袋定义为配体周围 10 Å 内重原子的主链原子。

蛋白–核酸用近期 PDB 评估集（2022-05-01 至 2023-01-12 released 的 8,856 个复合物，少于 5,120 tokens；低同源子集要求与训练集序列一致性不超过 40%）。指标是蛋白–核酸界面用 interface LDDT（iLDDT）。蛋白–蛋白用低同源近期 PDB 子集（少于 20 条蛋白链、少于 2,560 tokens），成功率定义为 DockQ 大于 0.23 的占比。抗体–抗原用 71 个复合物、166 个界面、65 个界面 cluster。共价修饰只纳入高质量实验数据（RCSB 验证报告 ranking_model_fit 大于 0.5，即高于中位数的 X 射线结构质量）。

### 样本、提示与指标

输入为聚合物序列、残基修饰与配体 SMILES，输出为复合物的联合 3D 结构。覆盖的分子类型包括：蛋白质（含多肽）、DNA、RNA、小分子配体（药物样分子）、离子，以及共价修饰（糖基化、磷酸化等翻译后修饰、修饰的蛋白残基与核酸碱基、键合配体）。论文称可覆盖 PDB 中“几乎所有分子类型”。

### 统计、算力与可得性

统计方面，论文给出了多项显著性检验的 p 值（见数字台账）。但一个重要的不对称是：AlphaFold 3 的分数是 25 个样本（抗体为 5,000 个样本）中按置信度挑最优的结果，而多数基线是单次预测；抗体比较中 AlphaFold-Multimer 也用了 1,000 seeds（双方同等采样，相对公平），但其他类别的基线是否同等采样未在正文交代。

算力：论文正文未给出训练算力的具体数字（本次精读未在正文提取文本中找到；方法部分只给出样本数与 crop 尺寸）。可得性是本篇最大的争议点，见下文：发布时 Nature 的 Code availability 栏明确写着“Code is not provided”，只有伪代码与受限的免费服务器。

## 三、主要发现

### 蛋白–配体：大幅领先传统对接工具

PoseBusters 基准上，AlphaFold 3 的成功率（口袋对齐配体 RMSD 小于 2 Å 的占比）为 76.4%，AutoDock Vina 为 52.3%，RoseTTAFold All-Atom 为 42.0%。这三个百分比来自图 1c 的柱状图，正文提取文本未逐项列出；Fisher 精确检验的 p 值是正文直接给出的：AlphaFold 3 对 Vina，P = 2.27×10⁻¹³；对 RoseTTAFold All-Atom，P = 4.45×10⁻²⁵。

条件不对称很重要，而且这个不对称对 AlphaFold 3 不利：Vina 等传统对接方法输入了真实的蛋白–配体复合物结构（holo 结构，即现实中不可得的特权信息），AlphaFold 3 只用蛋白序列与配体 SMILES，不用任何结构输入，仍大幅胜出。从这个角度看，这个胜利比数字看起来更强。

但比较时也要注意任务定义的不同：AlphaFold 3 的 76.4% 是盲测成绩（不知道口袋位置），与 Vina 的有口袋成绩直接并列比较时，需要说明任务定义不同。另有一个“给出口袋信息”的 AlphaFold 3 变体版本，成功率据二手来源称升至 90.2%，但论文正文只说该版本结果见 Extended Data Fig. 4a，未在正文给出数字——两个版本不可混淆。

博客称 AlphaFold 3 在 PoseBusters 上“比最好的传统方法准确 50%”。按 76.4% 对 52.3% 计算，相对提升约 46%，博客的“50%”应为约数或宣传口径。博客“首个超越基于物理的工具的 AI 系统”的定性断言是博客措辞，论文摘要的措辞是“far greater accuracy… compared with state-of-the-art docking tools”。

### 蛋白–核酸与 RNA：领先，但数字多在图内

蛋白–核酸界面，论文正文只定性称 AlphaFold 3 高于 RoseTTAFold2NA，未在正文给出具体值。图 1c 的数值据二手来源称：蛋白–双链 DNA 界面 iLDDT，AlphaFold 3 约 64.8，对 RoseTTAFold2NA 约 28.3——未在正文核对，须查 Extended Data Table 1。

CASP15 RNA 的 10 个公开 RNA 靶标上，AlphaFold 3 平均表现高于 RoseTTAFold2NA 与 AIchemy_RNA（CASP15 最佳 AI 方法），但未达到最佳人工专家辅助提交 AIchemy_RNA2 的水平。因数据集小，作者未报告显著性统计。

### 共价修饰：明显弱项

多残基聚糖的成功率为 42.1%（n = 131 clusters，全质量实验数据），单残基聚糖为 46.1%（n = 167），这两个数字是正文直接给出的。它们明显低于非键合配体的 76.4%，修饰预测仍是弱项。而且键合配体与糖基化数据集未按与训练集的同源性过滤（低同源过滤后只剩 5 个键合配体 cluster、7 个糖基化 cluster，样本极少）。

### 蛋白–蛋白、抗体–抗原、蛋白单体

正文给出的显著性：蛋白–蛋白 DockQ 成功率相对 AlphaFold-Multimer v2.3 提高，配对 Wilcoxon 检验 P = 1.8×10⁻¹⁸；抗体–蛋白预测显著改善，P = 6.5×10⁻⁵；蛋白单体 LDDT 改善，P = 1.7×10⁻³⁴。

抗体–抗原的具体百分比未核实：以“62.9% 对 37.4%”为查询词检索，未得到可确认的来源；正文只说抗体结果需从 1,000 个 seeds 中排序（常规为 5 个 seeds），且图 5a 显示即使到 1,000 个 seeds，top-ranked 预测质量仍在继续提升（5 对 1,000 seeds：正确率 P = 2.0×10⁻⁵，极高精度率 P = 0.009）。蛋白单体提升幅度据二次来源称约 1.5%，未在正文核对，列为未核实。

### 置信度校准

pLDDT 与 ipTM 与真实精度良好相关：按 chain-pair ipTM 分箱，蛋白–蛋白 DockQ、蛋白–核酸 iLDDT、蛋白–配体成功率均随 ipTM 单调上升。但这是“top-ranked 预测”的统计性质，不能保证单个预测。

### 具体结构示例

论文举了三个大复合物示例：细菌转录调控因子结合 DNA 与 cGMP（PDB 7PZB，全复合物 LDDT 82.8、GDT 90.1）；人冠状病毒 OC43 刺突蛋白 4,665 个残基、高度糖基化、结合中和抗体（PDB 7PNM，LDDT 83.0、GDT 83.1）；人 40S 核糖体小亚基 7,663 个残基、含 18S rRNA（PDB 7TQL，LDDT 87.7、GDT 86.9）。

药物相关示例：临床阶段抑制剂 LGK974 结合 PORCN（PDB 7URD，配体 RMSD 1.00 Å）；NIH-12848 类似物结合 PI5P4Kγ 变构位点（PDB 7QIE，RMSD 0.37 Å）；(5S,6S)-O7-sulfo DADH 结合 AziU3/U2（PDB 7WUX，RMSD 1.92 Å）。

## 四、作者的结论与局限

### 作者的结论

论文的结论是：AlphaFold 3 用一个统一的扩散框架，把结构预测从蛋白质推广到几乎所有生物分子类型，并在除一个类别外的所有类别上高于专攻该任务的强方法。博客的结论更直接：这是世界上最准确的预测蛋白质与其他分子相互作用的工具，AlphaFold Server 让科学家免费使用其大部分能力。

药物发现方面的宣称（博客）：AlphaFold 3 对药物常用分子（配体、抗体）与蛋白的结合预测达到“前所未有的准确率”，抗体–蛋白结合预测对理解免疫应答与设计新抗体至关重要；Isomorphic Labs 正结合 AlphaFold 3 与内部其他 AI 模型，为内部项目与制药合作伙伴做药物设计，“加速并提高药物设计的成功率”。

### 作者自己说的局限

Nature 的“Model limitations”一节列出了七点，博客本身未提任何局限。

第一，立体化学。手性：模型输出不总遵守手性，尽管输入的参考结构手性正确；即使在排序公式中加入手性惩罚，PoseBusters 上手性违规率仍为 4.4%，例证是 PDB 7CTM（预测为 α-D-葡糖醛酸，实为 β 型）。原子重叠：偶尔出现重叠原子，极端时同源多聚体整条链重叠（图 5e，三核小体 PDB 7PEU）；排序惩罚可减少但不能消除；几乎所有残留 clash 集中在超过 100 个核苷酸且总残基超过 2,000 的蛋白–核酸复合物。

第二，无序区幻觉：扩散生成式会在无序区产生虚假结构有序，且不像 AlphaFold 2 那样呈现标志性的 ribbon 状外观（图 5d，核孔复合物 PDB 7F60，1,854 个未解析残基）；幻觉区通常置信度很低，但外观上可能以假乱真。

第三，静态结构，非动力学：预测的是 PDB 式静态结构，不是溶液中的动力学行为；用多个随机 seed 跑扩散或整个网络，不能得到溶液系综的近似。

第四，构象态可能错误：模型可能只预测一种构象而漏掉另一种。例证是 E3 泛素连接酶 cereblon 天然 apo 态为开放构象、仅结合配体时为闭合构象，但 AlphaFold 3 对 apo 与 holo 均只预测闭合态（图 5c，PDB 8CVP / 8D7U）。

第五，高精度需大量采样，成本高：抗体–抗原类靶标尤其如此，1,000 个 seeds 仍在改善；其他分子类别无此现象。用 1 个而非 5 个扩散样本每 seed 对结果影响不大，关键是 model seeds 的数量。

第六，仍有许多靶标难以准确建模。

第七，论文称“在除一个类别外的所有类别上”均高于专攻该任务的强方法，但正文未指明是哪一个类别——须查图 1c 或 Extended Data Table 1。

博客自述的风险工作：发布前咨询了 50 多位领域专家及专业第三方，覆盖生物安全、研究与产业；参与了社区论坛。未披露具体评估结果或受限内容清单。

### 论文没有交代的事

发布时的开放状态是本篇最大的未交代之事。Nature 的 Code availability 栏原文是：“AlphaFold 3 will be available as a non-commercial usage only server at alphafoldserver.com, with restrictions on allowed ligands and covalent modifications. Pseudocode describing the algorithms is available in the Supplementary Information. Code is not provided.”即 2024-05-08 发布时：无代码、无权重，只有伪代码与受限的免费服务器。代码与权重直至 2024-11-11 才向学术界发布（博客更新注）。这与 AlphaFold 2 的开源形成鲜明对比，是当时学界公开信批评的焦点。

博客的另一处未交代是 Server 的具体限制：仅限非商业使用；配体只能从固定清单中选，不支持任意 SMILES 配体（与论文模型本身支持 SMILES 输入形成对照）；每个 job 上限 5,000 tokens、每用户每天 30 个 jobs——这些数字来自当前 Server FAQ 与 EBI 课程页，不是 2024-05-08 博客原文，发布时口径是否相同未核实。

## 五、精读点评

### 这篇论文真正要回答的问题

AlphaFold 3 要回答的问题是：结构预测能不能从“只预测蛋白质”推广到“预测蛋白质与一切生物分子的复合物”？这个问题的反常在于，AlphaFold 2 的成功恰恰建立在一个只适用于蛋白质的架构上——氨基酸骨架 frame 与侧链扭转角。把这套架构推广到配体与核酸，不是调参能解决的，需要换掉结构预测的核心表示。AlphaFold 3 的答案是换成扩散模型，直接预测原始原子坐标。

这个问题为什么重要？因为真实生物学是相互作用的生物学：药物结合蛋白质、转录因子结合 DNA、RNA 结合蛋白质。只预测单个蛋白质，离药物发现与机制生物学都还差一步。AlphaFold 3 的价值不在于把蛋白质预测再提高几个百分点，而在于把“能预测什么”的边界向外推了一大圈。

为什么之前做不了？卡住的点是表示：蛋白质有统一的残基结构，可以用 frame 表示；配体、核酸、离子没有统一的表示，硬套蛋白质的表示就行不通。AlphaFold 3 的办法是放弃 frame、放弃等变处理、放弃立体化学硬约束，直接对原子坐标做扩散。这个办法的代价与收益是同一枚硬币的两面：通用性换来了，但立体化学的保证丢了。

### 科学问题还原：五问

第一，反常是什么？AlphaFold 2 只预测蛋白质，而生物学功能发生在相互作用中；配体对接长期由基于物理的方法主导，深度学习方法尚未形成压倒性优势。第二，为什么重要？对领域而言，它决定结构预测能不能从“蛋白质结构”走向“生物分子相互作用”；对实践而言，它决定药物发现能不能用上 AI 预测的复合物结构。第三，为什么之前做不了？表示的障碍：蛋白质的 frame 表示无法容纳配体与核酸。第四，为什么这个方法能回答？扩散模型直接预测原子坐标，绕过了表示障碍；去掉立体化学硬约束换取了通用性。第五，答案改变了什么？认知上，证明了统一框架可以覆盖几乎所有生物分子类型；实践上，PoseBusters 上的 76.4% 证明 AI 对接可以超过基于物理的工具——但手性错误与原子重叠提醒人们，这个胜利是有代价的。

### 价值判断

认知价值：高。它证明了“一个模型预测所有生物分子相互作用”这条路是走得通的，而且在配体对接上超过了基于物理的传统工具。如果这篇论文不存在，结构预测领域会继续停留在“蛋白质归蛋白质、对接归对接”的分工里。

方法价值：高。扩散加 Pairformer 的统一框架、cross-distillation 缓解幻觉的做法、diffusion rollout 训练置信度头的做法，都是别人能直接拿走复用的东西。伪代码公开了算法，半年后代码与权重也发布了。

边界价值：论文的边界写得相当诚实。第 6 节“Model limitations”逐项列出了手性错误、无序区幻觉、静态结构、构象态错误、采样成本。读者最容易误读的推论是“结构预测等于药物发现”——论文证明的是 pose 与界面的几何预测，不预测结合亲和力，博客与 Isomorphic 的叙事延伸到“药物设计成功率”时，中间缺了亲和力、选择性、成药性、临床转化等全部环节。

启示价值：最便宜的决定性下一步，是把立体化学保证做进架构而不是做进排序惩罚：例如在扩散采样中加入手性约束，或在训练损失中恢复一部分立体化学项，判据是 PoseBusters 上手性违规率能否从 4.4% 降到接近零，同时配体成功率不下降。如果降不下来，说明“通用性换取硬约束”这个取舍比作者承认的更根本。

### 最弱的一环

最弱的一环是立体化学。去掉立体化学硬约束换来通用性，但留下 4.4% 的手性错误与整链重叠等 AlphaFold 2 时代没有的失败模式。排序惩罚是事后补丁，不是架构保证。对药物化学而言，手性错误不是小瑕疵——对映体的活性可能天差地别。一个预测了错误手性的配体 pose，即使 RMSD 小于 2 Å，也可能在化学上是无意义的。

第二个弱点是采样依赖的诚实度。抗体结果依赖 1,000 个 seeds 的暴力采样，实际 Server 用户能否或是否会跑这么多样本？论文默认的 5 seeds 成绩与 1,000 seeds 成绩是两个数字，精读时应当区分“默认配置性能”与“极限采样性能”。论文没有给出默认配置下的抗体成功率。

第三个弱点是发布时的不开放。Nature 明确写着“Code is not provided”，只有伪代码与受限服务器。代码与权重半年后才发布。这直接影响可复现性评价，也是当时公开信争议的核心。精读应当把“发布时状态”与“事后补发”分开写，不可把 11 月的开放写成 5 月的事实。

### 效度判断

内部效度：高。评估设计严谨：PoseBusters 用训练截止 2019 年的单独模型，确保未训过测试结构；近期 PDB 评估集做了低同源过滤；显著性检验明确。但有一个不对称：AlphaFold 3 的分数是多样本中按置信度挑最优的结果，多数基线是单次预测；这个不对称对 AlphaFold 3 有利，应当在引用数字时说明。

外部效度：中等。各类别精度不均匀（配体 76.4% 对聚糖约 42–46%），核酸大复合物的 clash 集中爆发。“一个模型解决所有生物分子”的叙事应当让位于按类别拆分的诚实评估。

构念效度：中等偏高。PoseBusters 的 RMSD 小于 2 Å 是对接领域的标准指标，但 pose 预测不等于亲和力预测，更不等于药物发现成功。论文的指标量的是几何，不是功能。

统计结论效度：高。关键比较都给出了 p 值，样本量与过滤条件明确。但图内百分比（图 1c）未在正文逐项列出，本次精读未能逐项核对，引用时须注明。

可复现性：发布时低，事后改善。发布时无代码、无权重，只有伪代码与受限服务器；2024-11-11 代码与权重向学术界发布后，可复现性大幅改善。但本次精读未核实 11 月发布的具体许可范围。

### 其他可能的解释

一种替代解释是：AlphaFold 3 的配体成绩主要来自“规模与数据”，而非“扩散架构”。也就是说，换成其他生成式架构，只要训练数据与采样策略相同，也可能得到类似成绩。区分两者的证据是消融实验：论文没有给出“去掉扩散、保留其他部分”的对照，扩散本身的贡献无法从现有数据中分离。

另一种替代解释是：PoseBusters 上的胜利部分来自评估协议的宽松。口袋对齐的 RMSD 小于 2 Å 以配体周围 10 Å 内的主链原子对齐，这个定义下，即使蛋白整体预测有偏差，配体局部的 RMSD 也可能显得好看。如果改用全局对齐的 RMSD，数字会难看得多。论文没有报告全局对齐的结果。

### 什么观察能反驳这些主张

“统一框架覆盖几乎所有生物分子类型”：如果后续研究发现，在某一类分子（例如 RNA 大复合物或高度糖基化蛋白）上 AlphaFold 3 的成绩系统性地差，且无法通过更多采样改善，那么“统一”的宣称就需要收回到“部分统一”。

“AI 对接超过基于物理的工具”：如果 Vina 等工具改用 AlphaFold 3 预测的蛋白结构作输入（而非真实 holo 结构），成绩大幅下降——据二手来源称跌至 13.1%，未核实——那么比较的公平性就需要重新评估：AlphaFold 3 赢的是“从序列出发的端到端任务”，不是“在同一输入条件下的对接任务”。

“手性错误只是小问题”：如果药物化学界反馈，4.4% 的手性错误率在实际药物发现流程中不可接受（因为手性错误的 pose 会误导后续的亲和力评估与合成），那么立体化学的取舍就需要重新权衡。

### 接下来看什么

最值得先做的是把立体化学保证做进架构：扩散采样中加入手性约束，或在训练损失中恢复一部分立体化学项，判据是 PoseBusters 上手性违规率能否从 4.4% 降到接近零，同时配体成功率不下降。

其次看 2024-11-11 开放代码与权重之后，独立复现的结果与论文数字是否一致。复现是检验 PoseBusters 76.4% 是否站得住的最直接办法。

再次看 AlphaFold Server 的实际使用数据：真实用户在默认配置（5 seeds）下得到的成绩与论文的极限采样成绩差距有多大。这决定 AlphaFold 3 在实践中的真实价值。

### 声称的贡献和实际支持的贡献

论文声称的贡献是“以前所未有的准确率预测蛋白质与其他分子类型的相互作用，相对现有方法至少提升 50%，某些类别翻倍”。实际支持的贡献是：配体对接上确实大幅领先（76.4% 对 52.3%，相对提升约 46%），蛋白–蛋白与抗体–抗原显著改善，统一框架确实覆盖了几乎所有分子类型。但“某些类别翻倍”具体指哪些类别，博客与正文均未指明，未核实；“除一个类别外均更高”中较差的是哪一类，正文未指明，未核实。这两处宣传口径超出了论文正文实际给出的证据。

## I. 结论、结果与价值总览

**一句话结论：** AlphaFold 3 用扩散加 Pairformer 的统一框架，把结构预测从蛋白质推广到几乎所有生物分子，并在配体对接上大幅超过基于物理的传统工具，但代价是立体化学保证的丢失与发布时的不开放。

**核心结论：**

1. 统一框架覆盖蛋白质、DNA、RNA、小分子、离子与共价修饰，预测的是复合物的联合 3D 结构。（置信度：高；架构与示例充分支持）
2. PoseBusters 上配体 pose 成功率 76.4%，大幅领先 Vina 的 52.3% 与 RoseTTAFold All-Atom 的 42.0%，且 AlphaFold 3 不用任何结构输入。（置信度：中；百分比来自图 1c，需核对 Extended Data Table 1；p 值来自正文，高度显著）
3. 共价修饰预测明显弱于配体：多残基聚糖 42.1%、单残基聚糖 46.1%。（置信度：高；正文直接给出）
4. 立体化学是代价：手性违规率 4.4%，偶有原子重叠，极端时整条链重叠。（置信度：高；正文直接给出）
5. 发布时无代码、无权重，只有伪代码与受限服务器；代码与权重半年后（2024-11-11）才发布。（置信度：高；Nature 原文与博客更新注均支持）

**关键结果表：** 见数字台账 E1–E7。决定性结果是 PoseBusters 76.4% 对 52.3%（E1），聚糖 42.1% 与 46.1%（E3），手性违规率 4.4%（E5）。其中 E1 的百分比来自图 1c（二手转述），须核对 Extended Data Table 1，不可直接当正文数字引用。

**科学价值总评：** 认知价值高——证明了统一框架覆盖几乎所有生物分子类型的可行性；方法价值高——扩散加 Pairformer 的框架与 cross-distillation 等做法可复用；边界价值明确——论文自己的局限一节写得诚实，各类别精度不均匀，结构预测不等于药物发现；启示价值高——最便宜的下一步是把立体化学保证做进架构。总体上，这篇工作值得因为它把结构预测的边界向外推了一大圈而被记住，同时也值得因为它在开放性上的倒退而被记住。

**适用边界：** 它证明的是 pose 与界面的几何预测，不证明结合亲和力，不证明药物发现成功。谁都不该拿 PoseBusters 的数字为“AI 能设计药物”背书，也不该把 11 月的代码开放写成 5 月的事实。
