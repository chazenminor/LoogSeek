## 一、背景与问题

### 博客之前是什么局面

到 2025 年 2 月，OpenAI 的模型路线已经分叉成两条线。一条是推理（reasoning）线：o1 和 o3-mini 被教会“先想一想再回答”，在复杂的科学、技术、工程、数学（STEM）与逻辑问题上表现突出。另一条是 GPT 线：GPT-3.5、GPT-4、GPT-4o 靠无监督学习（unsupervised learning）推进，强在世界知识、直觉与对话。

博客开篇把这两条线说成智能的两个互补轴：无监督学习提高世界模型的准确性与直觉；推理则教模型在回答前产出思维链（chain of thought）。GPT-4.5 是前一条轴的最新一步：靠扩大算力与数据，加上架构与优化上的创新，把无监督学习继续往上推。

博客要回答的问题于是很明确：只靠扩大预训练（pre-training）与后训练（post-training）的规模，不加推理，还能不能造出一个前沿模型？它能带来什么新东西？博客的答案是：能，GPT-4.5 是“迄今为止最大、最适合聊天的 GPT 模型”，以及“无监督学习前沿上可能的模型”。

### 这篇博客要宣布什么

博客宣布 GPT-4.5 以研究预览（research preview）的形式发布：先给 ChatGPT Pro 用户与所有付费层级的开发者用，目的是“更好地理解它的优势与局限”。OpenAI 说自己“还在探索它能做什么”，期待用户发现意料之外的用法。

博客要让读者相信三件事。第一，GPT-4.5 更懂世界、更少幻觉：通过扩大无监督学习，它更善于识别模式、建立联系、产生创造性见解，而且不需要推理。第二，它更像一个好的对话伙伴：知识面更广、更能跟随用户意图、更有“情商（EQ）”，写东西、编程、解决实际问题时更有用。第三，即使只靠扩大无监督学习，它在传统上与推理相关的学术基准上也比 GPT-4o 有明显进步——附录里有一张基准表为这句话背书。

### 这是一篇什么样的文档

标题是 Introducing GPT-4.5，中文可译为“发布 GPT-4.5”。署名是 OpenAI（组织署名），另列有基础贡献者（foundational contributors）、研究（research）、规模化（scaling）、安全系统（safety systems）、部署（deployment）与执行领导层（executive leadership）名单。这是一篇产品发布博客，不是同行评审论文，也不是预印本论文：没有摘要、方法节、实验节、参考文献，只有一段发布说明、几节能力介绍、一节安全说明、两节使用安排、一段结论与一份附录基准表。

分析者是子代理深度精读，分析日期是 2026-11-23。已完成两遍：第一遍通读发布说明、能力介绍与附录；第二遍逐节核对数字台账里的每一个数字。第三遍（虚拟重实现）不适用，因为博客没有给出可重实现的方法。

## 二、方法与设计

### 模型是什么：把无监督学习再推一个量级

GPT-4.5 的定位，博客只用两句话讲清。第一句是路线的划分：无监督学习与推理是两条互补的智能轴，GPT-4.5 走的是前一条。第二句是做法：通过扩大算力与数据，加上架构与优化创新来扩大无监督学习；模型在微软 Azure AI 超级计算机（Microsoft Azure AI supercomputers）上训练。

博客没有给出任何一个具体数字来支撑“扩大”这个说法：没有算力规模、没有数据量、没有参数量、没有架构细节、没有训练时长。读者只知道它“更大”，不知道大了多少。

博客说，这样做的结果是模型拥有更广的知识与更深的世界理解，从而在广泛话题上减少幻觉、提高可靠性。这是一个因果宣称——“规模扩大导致幻觉减少”——但博客没有给出能检验这条因果链的证据：没有消融实验，没有“只扩大数据、不改架构”的对照，也没有训练过程的任何数据。

### 为人类协作而训练

博客单独开了一节讲后训练。说法是：随着模型解决越来越复杂的问题，教它们更好地理解人类需求与意图变得越来越重要。为此，OpenAI 开发了新的、可扩展的技术，让更大的模型可以用源自更小模型的数据来训练。这些技术提高了 GPT-4.5 的可控性（steerability）、对细微差别的理解与自然对话能力。

这段话是博客里关于方法最具体的一段，但仍然没有给出任何可操作的信息：新技术叫什么、怎么工作、用了哪些更小模型、数据怎么生成与筛选，博客一概没说。读者无法判断，这里的“新技术”是真实的方法创新，还是对常规蒸馏（distillation）与合成数据（synthetic data）做法的换一种说法。

博客把这节的结果说成：把对世界的深刻理解与更好的协作能力结合起来，模型能在温暖、直觉的对话里自然地融合想法，更贴合人类协作。GPT-4.5 更理解人类的意思，能以更大的细微差别解读微妙暗示或隐含期待，也有更强的审美直觉与创造力，在写作与设计上表现突出。

### 评估：两张图与一份附录表

博客的评估部分由三块组成，但只有一块的数字能从正文核实。

第一块是“更深的世界知识”一节下的两张图：SimpleQA 准确率（越高越好）与 SimpleQA 幻觉率（越低越好）。正文只给了一句图注：SimpleQA 衡量大语言模型在简单但有挑战性的知识问题上的事实性。两张图的具体数值只在图里，正文没有给出，无法核实。

第二块是“与人类测试者对比评估”一节下的一张图：人类偏好（human preference），即测试者在多大比例的查询里更喜欢 GPT-4.5 而不是 GPT-4o。图的具体数值同样只在图里，正文没有给出，无法核实。

第三块是附录里的“模型评估分数”表。这是博客里唯一一份能从正文核实的数字：GPQA（科学）、AIME '24（数学）、MMMLU（多语言）、MMMU（多模态）、SWE-Lancer Diamond（编码）、SWE-Bench Verified（编码），每项都列出 GPT-4.5、GPT-4o 与 o3-mini（high）的分数。表下有一行脚注：“所展示的数字代表最佳内部成绩（best internal performance）。”

除此之外，博客没有给出任何评估方法：没有样本量、没有运行次数、没有误差范围、没有统计检验、没有评估所用的提示词或解码设置。读者拿到的是三张成绩单，而不是一次可复核的评估。

## 三、主要发现

### 附录基准表：比 GPT-4o 强，比 o3-mini 弱得多

附录的表格是博客里唯一可核对的成绩单。按博客自己的说法，列出这些结果是为了说明：即使只靠扩大无监督学习，GPT-4.5 在传统上与推理相关的任务上也比 GPT-4o 有“有意义的进步”。

数字本身是这样的。GPQA（科学）：GPT-4.5 为 71.4%，GPT-4o 为 53.6%，o3-mini（high）为 79.7%。AIME '24（数学）：GPT-4.5 为 36.7%，GPT-4o 为 9.3%，o3-mini（high）为 87.3%。MMMLU（多语言）：GPT-4.5 为 85.1%，GPT-4o 为 81.5%，o3-mini（high）为 81.1%。MMMU（多模态）：GPT-4.5 为 74.4%，GPT-4o 为 69.1%，o3-mini 的分数未列出（表中为横线）。SWE-Lancer Diamond（编码）：GPT-4.5 为 32.6%（对应 186,125 美元），GPT-4o 为 23.3%（138,750 美元），o3-mini（high）为 10.8%（89,625 美元）。SWE-Bench Verified（编码）：GPT-4.5 为 38.0%，GPT-4o 为 30.7%，o3-mini（high）为 61.0%。

这张表同时讲了两个故事。第一个故事是博客想讲的：GPT-4.5 在每一项上都超过 GPT-4o，其中数学（AIME '24）从 9.3% 涨到 36.7%，科学（GPQA）从 53.6% 涨到 71.4%，涨幅确实不小。第二个故事是博客没有展开的：GPT-4.5 在推理任务上远远落后于 o3-mini——AIME '24 是 36.7% 对 87.3%，SWE-Bench Verified 是 38.0% 对 61.0%，GPQA 是 71.4% 对 79.7%。也就是说，“只靠扩大无监督学习”能追上 GPT-4o，但离推理模型还差得很远。博客承认这一点的方式，是在附录开头写了一句：学术基准不总能反映真实世界的用处。

还有一处值得注意：MMMLU 上 GPT-4.5 的 85.1% 超过了 o3-mini 的 81.1%，是整张表里 GPT-4.5 唯一超过推理模型的一项；SWE-Lancer Diamond 上 GPT-4.5 的 32.6% 也明显高于 o3-mini 的 10.8%。这两项说明，GPT-4.5 的优势集中在知识广度与某些编码任务上，而不是需要多步推理的任务。

但这张表有一个博客自己标明的限定：数字是“最佳内部成绩”。这意味着它们不是一次标准运行的结果，而是内部多次尝试里最好的那一次。没有运行次数、没有误差范围、没有平均值，读者无法判断这些差距里有多少是真实提升、有多少是挑了最好的一次。

### SimpleQA 与人类偏好：博客的核心论据，数字只在图里

博客的核心卖点——“更少幻觉”“更自然、更有 EQ 的对话”——依赖的正是那两张没有文字数字的图。SimpleQA 的准确率与幻觉率，本应是“幻觉更少”这个宣称的直接证据；人类偏好对比，本应是“更适合聊天”这个宣称的直接证据。但正文没有给出任何一个数字，读者无法从文字里知道：SimpleQA 准确率到底是多少、比 GPT-4o 高多少、幻觉率低了多少；人类测试者在多大比例的查询里更喜欢 GPT-4.5。

博客正文里关于幻觉的说法，只有一句期望式的表述：“我们预期它会更少幻觉（We also expect it to hallucinate less）。”“预期”不是测量结果。也就是说，博客最核心的两个宣称——幻觉更少、对话更好——在正文里都没有可核查的数字支撑。

### 推理在望：GPT-4.5 不思考，但为推理打基础

博客有一节专门讲 GPT-4.5 与推理模型的关系。说法是：GPT-4.5 在回答前不思考，这让它的优势与 o1 这类推理模型很不一样；与 o1 和 o3-mini 相比，GPT-4.5 是一个更通用、天生更聪明的模型。OpenAI 认为推理将是未来模型的核心能力，预训练与推理这两条扩大路线会互相补充：像 GPT-4.5 这样的模型通过预训练变得更聪明、知识更广之后，会成为推理与工具使用智能体更强的基座。

这节话的潜台词是：GPT-4.5 不是终点，而是一个基座。它的价值不在于赢过推理模型，而在于为下一代推理模型提供一个更强的起点。这个说法本身没有数字支撑，它是一个路线判断，不是测量结果。

## 四、作者的结论与局限

### 作者的结论

博客的结论只有一段，写在“结论”一节里：每增加一个数量级的算力，都会带来新的能力。GPT-4.5 是无监督学习所能达到的前沿上的一个模型。OpenAI 继续对社区发现新能力与意料之外的用法的创造力感到惊讶，并邀请读者一起探索无监督学习的前沿、发现新的能力。

博客没有写“结论”之外的总结性判断。它的结论就是发布本身：GPT-4.5 今天以研究预览的形式上线，Pro 用户与开发者先用；它在聊天上更强、幻觉更少；往前看，预训练与推理两条路线会互相补充。

### 作者自述的局限

博客没有像 deep research 那篇那样单独写一节“局限”，但它的局限散落在各节里，值得原原本本记下来。

第一，GPT-4.5 在回答前不思考。它不是推理模型，在需要多步推理的任务上落后于 o1 与 o3-mini——附录的数字把这一点摆得很清楚。

第二，功能不完整。发布时，GPT-4.5 支持搜索、文件与图片上传、canvas 写作与代码协作，但不支持语音模式（Voice Mode）、视频与屏幕共享等多模态功能。

第三，又大又贵。博客明说：GPT-4.5 是一个非常大、计算密集的模型，比 GPT-4o 更贵，而且不是 GPT-4o 的替代品。正因为成本高，OpenAI 正在评估是否长期在 API 里继续提供它，要根据它是否带来独特价值与用户反馈来决定。

第四，这是一次研究预览，不是正式发布。OpenAI 说自己还在探索它能做什么，发布的目的之一就是了解它的优势与局限。换句话说，博客承认自己对这个模型的了解还不完整。

第五，关于安全，博客只讲了一段话：GPT-4.5 用新的监督技术训练，并结合与 GPT-4o 类似的监督微调（SFT）与基于人类反馈的强化学习（RLHF）；部署前按准备度框架（Preparedness Framework）做了一套安全测试；详细的评估结果发表在随附的系统卡里，不在这篇博客里。博客本身没有给出任何一项安全评估的数字。

### 访问安排：Pro 用户先用，Plus 与 Team 随后

博客发布当天，ChatGPT Pro 用户可以在网页、移动与桌面端的模型选择器里选 GPT-4.5。Plus 与 Team 用户下周开始陆续获得，企业（Enterprise）与教育（Edu）用户再下一周。

API 方面，GPT-4.5 同时在 Chat Completions API、Assistants API 与 Batch API 里以预览形式提供给所有付费层级的开发者。模型支持函数调用（function calling）、结构化输出（Structured Outputs）、流式传输（streaming）与系统消息（system messages），也支持通过图片输入实现视觉能力。

博客建议开发者在受益于更高情商与创造力的应用里使用它——写作帮助、沟通、学习、辅导、头脑风暴；它在智能体规划与执行上也表现强劲，包括多步编码工作流与复杂任务自动化。这些是博客基于早期测试的说法，没有给出任何支撑数字。

## 五、精读点评

这一节是分析者的判断，和上面对博客的呈现分开写。

### 这篇博客真正要回答的问题

这篇博客真正要回答的问题不是一个科学问题，而是一个路线问题：只靠扩大预训练的规模，不加推理，还能不能造出一个前沿模型？它给出的答案是：能，GPT-4.5 就是证明；证据是附录里它对 GPT-4o 的全面超越。

但博客真正留下的、值得追问的问题是另一层：GPT-4.5 到底是“无监督学习这条路还有很大 headroom”的证据，还是“这条路已经接近天花板”的证据？博客的数字同时支持两种读法。支持“还有 headroom”的读法是：只靠扩大规模，AIME '24 从 9.3% 涨到 36.7%，GPQA 从 53.6% 涨到 71.4%，涨幅不小。支持“接近天花板”的读法是：花了这么大的规模，AIME '24 也只到 36.7%，离 o3-mini 的 87.3% 还差一倍多；SWE-Bench Verified 的 38.0% 对 o3-mini 的 61.0% 也是同样的差距。博客没有回答这个问题，因为它没有给出任何能区分这两种读法的证据——没有规模曲线，没有消融实验，没有成本数字。

### 科学问题还原：五问

**现象是什么？** 推理模型在硬科学问题上大胜，但聊天这件事——自然对话、理解言外之意、写东西、解决实际问题——是另一条轴。反常不在于某一次回答出错，而在于“答对难题”与“好用”之间出现了分叉：o1 能解数学题，却未必是更好的对话伙伴。博客的切入点是把“只靠扩大预训练”这条老路再推一个量级，看它能不能在“好用”这个维度上立住。

**为什么重要，不解决会怎样？** 对实践来说，写作、编程、解决实际问题、辅导与头脑风暴是用户每天都在做的事；如果预训练这条路走不下去了，OpenAI 就只能把全部希望押在推理这一条线上，而推理模型的成本与延迟都更高。对认知来说，这个问题关系到一个基本判断：智能的增长是不是只有“学会思考”这一条路，还是“知道得更多、理解得更深”本身就能走得很远。博客没有明说这一层，但它的结论句——“每增加一个数量级的算力，都会带来新的能力”——正是在为这条路辩护。

**为什么之前做不了？** 博客在方法段落里暗示了两点：第一，训练更大的模型需要新的、可扩展的技术，特别是用源自更小模型的数据来训练；第二，成本。GPT-4.5 非常大、计算密集，比 GPT-4o 更贵，以至于 OpenAI 都不确定要不要长期提供它。博客没有交代训练数据的规模、算力与架构细节，所以 blocker 是否真的被移走了，读者无从判断。

**方法与问题是否匹配？** 从路线角度看，匹配点是真实的：问题是“只靠扩大无监督学习还能走多远”，方法是“扩大算力与数据，加上架构与优化创新”。但从证据角度看，方法与宣称的匹配没有被证明：博客用附录的基准分数来证明“扩大预训练有效”，而这些分数是“最佳内部成绩”，没有误差范围与运行次数；更关键的是，博客最核心的两个宣称——幻觉更少、对话更好——依赖的恰恰是那两张没有文字数字的图。用一张挑过最好成绩的表和两张没有数字的图，来证明一条路线的生命力，中间隔了一层没有被检验的跳跃。

**答案改变了什么？** 认知上，博客确立了一件事：只靠扩大无监督学习，确实能在传统上与推理相关的基准上超过 GPT-4o，而且幅度不小。但它同时也确立了另一件事：这条路追不上推理模型，在数学与编码推理上差距仍然巨大。读完之后应该改变的信念是：预训练规模仍然有效，但它不是通向推理能力的替代品；它更像是一个更强的基座，而不是终点。实践上，它改变了一件事：从 2025 年 2 月起，Pro 用户与开发者可以多用一个“更适合聊天”的模型，但要付出更高的成本，而且 OpenAI 自己都不确定会长期提供它。

### 价值判断

认知价值是中等的。博客没有提出、检验或推翻一个科学主张，但它给出了一个有信息量的路线信号：纯粹扩大预训练能在 GPT-4o 之上取得全面进步，同时在推理任务上仍然远远落后于推理模型。反事实是：如果这篇博客不存在，GPT-4.5 这个模型本身仍然存在，附录的数字仍然可以从别处查到；但“预训练路线还有 headroom，同时追不上推理”这个判断的原始出处就是这篇博客，离开它就少了一个公开的锚点。

方法价值是低的。博客没有留下任何别人能拿走复用的东西：没有训练方法细节、没有评估协议、没有数据、没有代码、没有消融实验、没有规模曲线。一个想复现 GPT-4.5 的读者，从博客里得不到任何可操作的信息。唯一可复用的，是它展示的路线判断本身——“预训练与推理两条路线会互相补充”——但这只是一个方向性说法，不是方法。

边界价值是中等偏高，这正是这份精读记录最有价值的部分。博客明确不证明的东西包括：SimpleQA 与人类偏好图里的具体数字（正文没有给出）；GPT-4.5 的幻觉率到底比 GPT-4o 低多少；它的成绩里有多少来自规模扩大、多少来自架构与优化创新；它在真实世界里的用处是否配得上它的成本。读者最容易误读的推论，是把“迄今为止最强、最适合聊天的 GPT 模型”读成“最强的模型”——博客的标题与开篇恰恰在鼓励这种读法，而附录的数字只支撑“比 GPT-4o 强、在聊天上可能更好”，不支持“比推理模型强”。

启示价值在于，最便宜的决定性实验不是再跑一遍基准，而是把博客已经画出来的两张图变成数字：公布 SimpleQA 的准确率与幻觉率、人类偏好的具体比例，并附上样本量、评估协议与误差范围。具体设计在下面“接下来看什么”里写。

### 最弱的一环

最弱的一环在博客的核心宣称与它的证据之间。整篇博客的说服力，最终依赖于一个没有被检验的假设：SimpleQA 与人类偏好图里的数字，确实支持“幻觉更少、对话更好”。

这个假设之所以承重，是因为它是博客全部证据的支点——博客最核心的两个卖点（更少幻觉、更自然的对话）只靠这两张图背书，而这两张图的数字在正文里根本没有出现。读者既无法复核，也无法反驳。如果这两张图的数字其实提升很小，或者评估条件有偏，博客的核心宣称就立不住，而附录的基准表救不了它——附录量的是学术基准，不是幻觉率与对话质量。

第二弱的一环是“最佳内部成绩”这个脚注。附录的每一项数字都是内部多次尝试里最好的那一次，但博客没有报告运行次数、平均值与误差范围。读者无法判断，GPT-4.5 对 GPT-4o 的领先里有多少是真实提升、有多少是挑了最好的一次。MMMLU 上 85.1% 对 81.5% 这类 3 到 4 个百分点的差距，在没有误差范围的情况下尤其站不住。

第三弱的一环是方法透明度。博客没有给出任何训练细节：没有算力、数据量、参数量、架构、新技术的描述。读者无法判断，GPT-4.5 的进步里有多少来自规模扩大、有多少来自架构与优化创新，也无法判断同样的规模换一个做法会不会得到同样的结果。

### 效度判断

下面是针对博客作为证据的评分，满分 5 分，评的是证据，不是产品本身。

内部效度 2 分。博客没有描述任何评估方法：没有样本量、没有运行次数、没有误差范围、没有对照组、没有统计检验。唯一值得肯定的是附录表格的脚注：主动说明数字是“最佳内部成绩”，而不是假装它们是一次标准运行的结果。但这一个披露救不了整篇博客的方法透明度。

外部效度 2 分。结果能推广到什么范围，博客没有讨论。附录的六项基准都是学术与编码基准，推广到“写作、沟通、学习、辅导、头脑风暴”等真实使用场景没有证据；推广到“更适合聊天”这个核心宣称，依赖的是那张没有数字的人类偏好图。发布时只给 Pro 用户与付费开发者用，博客里的成绩对应的是发布时的研究预览版，后续版本如何，博客没有交代。

构念效度 2 分。博客声称 GPT-4.5 是“最适合聊天的 GPT 模型”，但它用来证明这一点的指标是学术基准分数与一张没有数字的人类偏好图。学术基准量的是“答对科学、数学与编码题”，不是“聊天质量”——对话的自然程度、对言外之意的理解、写作的帮助，这些博客都没有量。指标与声称的构念之间隔了一层没有被检验的跳跃。

统计结论效度 1 分。博客没有报告任何统计量：没有误差棒、没有运行次数、没有显著性检验、没有多重比较。附录的数字是“最佳内部成绩”，连平均值都没有。GPQA 上 71.4% 对 53.6% 的差距看起来很大，但读者无法判断它是否稳健；MMMLU 上 3.6 个百分点的差距更是如此。

可复现性 1 分。博客没有给出任何可复现的材料：没有训练方法、没有评估协议、没有数据、没有代码、没有提示词、没有规模数字。一个能干的读者按博客的描述，无法重建 GPT-4.5，也无法重跑它的评估。博客的价值不在复现，而在宣布产品与公布分数。

### 其他可能的解释

同一个结果，至少有三种别的解释也能说得通。

第一种是“规模解释”。附录里 GPT-4.5 对 GPT-4o 的全面领先，可能主要来自“用了更多算力与数据”，而不是来自博客提到的架构与优化创新，也不是来自“用更小模型的数据训练更大模型”的新技术。证据是：博客没有给出任何消融实验，无法分离规模与方法的贡献。区分证据是：公布规模曲线，或者做一组对照——同样规模下，有没有新技术，分数差多少。

第二种是“挑成绩解释”。附录的数字是“最佳内部成绩”，GPT-4.5 对 GPT-4o 的领先里，可能有一部分来自挑了最好的一次，而不是模型的真实差距。预测是：如果公布平均值与误差范围，部分项目的领先会缩小，甚至消失。区分证据是：公布每次运行的分数分布，而不只是一个最好值。

第三种是“风格解释”。人类偏好图里测试者更喜欢 GPT-4.5，可能反映的是它的回答风格——更温暖、更长、更体贴、更有“情商”——而不是它的回答更正确。博客自己也在强调温暖与直觉的对话，这与偏好测试常常奖励风格的现象是一致的。预测是：如果让人评估回答的事实正确性而不是“更喜欢哪一个”，GPT-4.5 对 GPT-4o 的优势会明显缩小。区分证据是：一次把“偏好”与“正确性”分开测量的盲评。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

“GPT-4.5 比 GPT-4o 更少幻觉”：公布 SimpleQA 的准确率与幻觉率数字，并附上评估协议。如果 GPT-4.5 的幻觉率与 GPT-4o 没有显著差别，或者只在图里好看、换一组事实性问题就消失，这个宣称即被反驳。

“GPT-4.5 是最适合聊天的 GPT 模型”：做一次把“偏好”与“正确性”分开测量的盲评。如果人类测试者更喜欢 GPT-4.5 的回答，但这些回答的事实错误并不比 GPT-4o 少，“最适合聊天”的说法就要收回到“最讨人喜欢”这个更窄的范围。

“只靠扩大无监督学习就能取得有意义的进步”：公布规模曲线或消融结果。如果同样规模下、去掉架构与优化创新之后，分数没有明显变化，“扩大规模有效”的说法仍然成立，但“新技术有效”的说法即被反驳；如果更小的规模也能得到接近的分数，“必须扩大规模”的说法即被反驳。

“附录的领先是真实提升”：公布每次运行的分数分布与误差范围。如果平均值与 GPT-4o 的差距远小于“最佳内部成绩”所显示的差距，附录的领先就要打折。

### 替代解释

替代解释一：规模解释。GPT-4.5 对 GPT-4o 的领先可能主要来自更多算力与数据，而不是架构、优化创新或新训练技术。预测：同样规模下，有没有新技术，分数差不大。区分证据：规模曲线或消融实验，博客没有给出。

替代解释二：挑成绩解释。附录的数字是“最佳内部成绩”，领先里可能有一部分来自挑了最好的一次。预测：公布平均值与误差范围后，部分项目的领先会缩小。区分证据：每次运行的分数分布，博客没有给出。

替代解释三：风格解释。人类偏好可能反映的是回答风格（更温暖、更长、更体贴），而不是回答更正确。预测：分开测量偏好与正确性时，GPT-4.5 的优势会缩小。区分证据：一次把偏好与正确性分开的盲评。

### 作者自述局限与分析者发现的局限

作者自述的局限见第四节：回答前不思考、在推理任务上落后于推理模型；不支持语音模式、视频与屏幕共享；非常大、计算密集、比 GPT-4o 更贵、不是 GPT-4o 的替代品；是否长期在 API 里提供还不确定；这是一次研究预览，OpenAI 自己还在探索它的能力；安全评估的详细结果在系统卡里，不在博客里。

分析者发现的、作者没说的局限有四点。第一，博客最核心的两个宣称——幻觉更少、对话更好——依赖的两张图没有文字数字，正文无法核实。第二，附录的数字是“最佳内部成绩”，没有运行次数、平均值与误差范围，读者无法判断差距是否稳健。第三，博客没有给出任何训练细节：没有算力、数据量、参数量、架构与新技术的描述，规模与方法的贡献分不开。第四，博客的原始发布日期无法从页面正文核实（索引日期 2025-02-27 与页面显示之间存在出入），而页面又是不断叠加更新的活页面，引用时需要说明读的是哪个版本。

### 接下来看什么

最值得先做的，是把博客已经画出来的两张图变成数字。这是启示价值里最便宜的决定性实验，也是全篇最缺的一块。

具体设计：OpenAI 公布 SimpleQA 的准确率与幻觉率、人类偏好的具体比例，并附上样本量、评估协议（测试者人数、查询来源、盲评与否）与误差范围。成本很低，这些数字 OpenAI 在写博客时已经有了。

判据很简单：如果 GPT-4.5 的幻觉率显著低于 GPT-4o，且人类偏好比例显著高于五成，博客“幻觉更少、对话更好”的说法就得到支持；如果幻觉率没有显著差别，或者偏好比例接近五成，博客的核心宣称就被证伪，GPT-4.5 的价值就要收回到“附录基准表上比 GPT-4o 强的那个模型”这个更窄的范围。

其次是补上规模与方法的分离：公布规模曲线，或者做一组对照——同样规模下，有没有新技术，分数差多少。这能回答“预训练路线还有多少 headroom”这个博客真正留下的问题。

再往后看三件事：公布附录六项基准每次运行的分数分布，让“最佳内部成绩”变成可判断的数字；做一次把偏好与正确性分开测量的盲评，检验风格解释；跟踪 OpenAI 是否长期在 API 里继续提供 GPT-4.5，以及它在真实使用场景里的反馈——博客自己把这个决定留给了用户反馈，答案不在博客里。

## I. 结论、结果与价值总览

### 一句话结论

这是一篇产品发布博客，不是研究论文——它宣布 GPT-4.5 是“迄今为止最强、最适合聊天的 GPT 模型”，并用附录里对 GPT-4o 的全面超越为这句话背书；但它最核心的两个宣称（幻觉更少、对话更好）依赖的两张图没有文字数字，附录的数字又明确标注是“最佳内部成绩”，读完只能知道它声称变强了，不知道强了多少、强在哪里。

### 核心结论

1. **GPT-4.5 在附录六项基准上全面超过 GPT-4o（置信度：高）。** 博客附录表格原文；其中 AIME '24 从 9.3% 涨到 36.7%，GPQA 从 53.6% 涨到 71.4%。但数字是“最佳内部成绩”，无误差范围。
