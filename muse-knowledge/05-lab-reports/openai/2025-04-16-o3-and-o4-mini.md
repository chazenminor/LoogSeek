## 一、背景与问题

### 发布之前是什么局面

o 系列是 OpenAI 的推理模型线：模型在回答之前先花更长时间思考。o1 是这一路线的第一个公开产品，o3-mini 是它的轻量版。到 2025 年 4 月，推理模型已经证明了“想得更久就能答得更好”，但它们在 ChatGPT 里还不能自己决定用什么工具——搜网、跑 Python、看图、生成图片这些能力要么不在推理模型手里，要么需要人一步步指挥。

博客要解决的其实是两个问题合在一起。第一，推理能力本身能不能再往上推：o3 被定位为“迄今最强的推理模型”，o4-mini 被定位为“小而快、便宜但推理很强”的版本。第二，推理能不能和工具使用结合起来：模型不只是“想”，还要会判断什么时候该搜网、什么时候该跑代码、什么时候该把图转一转再看。这一步被博客说成是“朝向更具自主性的 ChatGPT 的一步”——模型能替用户独立执行任务，而不只是回答问题。

### 这篇博客要宣布什么

它宣布两件事。第一，o3 与 o4-mini 当天在 ChatGPT 与 API 上线，o3 接替 o1、o4-mini 接替 o3-mini 在模型选择器里的位置。第二，这两个模型第一次获得 ChatGPT 内全部工具的自主调用能力：联网搜索、用 Python 分析上传文件与数据、深度推理视觉输入、生成图片，并且是模型自己推理“什么时候、怎么用工具”，而不是按固定流程调用。

它同时宣布了一个配套实验：Codex CLI，一个能在终端里跑的轻量编码智能体，开源发布，配合一个 100 万美元的资助计划。

## 二、方法与设计

### 模型是什么

博客对两个模型的定位写得很直白。o3 是“最强的推理模型”，在编码、数学、科学、视觉感知上推高前沿，尤其擅长分析图片、图表与图形这类视觉任务。o4-mini 是“为快速、低成本推理优化的小模型”，在数学、编码与视觉任务上按尺寸和成本算表现突出；博客说它是 AIME 2024 与 2025 上表现最好的被测模型。

两个模型共同的新能力是“用图片思考”（thinking with images）：第一次把图片直接整合进思维链里。博客的说法是，模型不只是“看”一张图，而是“带着图一起想”。用户可以上传白板照片、课本插图或手绘草图，模型能解读——哪怕图片模糊、颠倒或质量很低。配合工具使用，模型还可以在推理过程中直接处理图片：旋转、放大或变换。

### 训练思路：把强化学习再推一个量级

博客用一节讲了训练思路，内容只有一段话。大意是：在开发 o3 的过程中，团队观察到大规模强化学习呈现出与 GPT 系列预训练相同的规律——“算力越多，表现越好”。沿着这条路再走下去，这一次在训练算力与推理时间上都又推高了一个数量级，表现仍在继续提升。这被博客当作证据，说明“让模型想得更久，表现就会继续往上爬”。

两个模型还“通过强化学习学会了用工具”：不只是学会怎么调用工具，还要学会推理什么时候用工具。博客说，这种能力让模型在开放式场景下更强，特别是在视觉推理与多步骤工作流上。

但博客没有给出任何训练细节：没有数据、没有算力数字、没有超参数、没有奖励设计、没有消融实验。所谓“又推高一个数量级”也没有配任何可核查的数字——训练算力是多少、推理时间是多少，都没写。

### 评估：外部专家 + 基准图

博客的评估分两路。一路是外部专家评估：在困难的真实世界任务上，o3 比 o1 少犯 20% 的重大错误，尤其在编程、商业咨询与创造性构思上表现突出。o4-mini 在非 STEM 任务与数据科学等领域上也超过了前代 o3-mini。两位模型都被外部专家评价为指令遵循更好、回答更有用、更可验证。

另一路是基准图：多模态、编码、指令遵循与智能体工具使用三组图，覆盖 Codeforces、SWE-bench、MMMU 等基准。博客正文只点了几个基准的名字，没有写出任何一个基准分数。所有基准分数只在图里。

博客还提到一个脚注级别的评估细节：SWE-bench 的评估用的是固定子集，共 477 个已验证任务；用 256k 最大上下文长度时，o4-mini 的解出率提高约 3%，o3 的影响不到 1%；另有 23 个样本因在内部基础设施上跑不通而被排除。

### 安全评估

安全一节是全篇最有实质内容的部分之一。博客说，针对 o3 与 o4-mini，团队完全重建了安全训练数据，新增了生物威胁、恶意软件生成、越狱等领域的拒绝提示。还开发了系统级缓解措施来标记前沿风险领域的危险提示，并训练了一个推理型大语言模型监视器（reasoning LLM monitor），按人类编写的、可解释的安全规范工作。在生物风险上，这个监视器在人类红队测试活动中成功标记了约 99% 的对话。

两个模型都按更新后的 Preparedness Framework（防备框架）做了压力测试，覆盖生物与化学、网络安全、AI 自我改进三个被跟踪的能力领域。根据评估结果，两个模型在三个领域都仍低于框架的“High”（高）阈值。详细结果发表在随附的系统卡里，博客正文没有展开。

## 三、主要发现

### 推理模型第一次获得全部工具的自主调用能力

这是博客的核心宣称。o3 与 o4-mini 是第一批能在 ChatGPT 里自主使用并组合全部工具的推理模型：联网搜索、用 Python 分析上传文件与其他数据、深度推理视觉输入、生成图片。关键在“自主”两个字——模型自己推理什么时候、怎么用工具，产出格式正确的详细答案，通常在一分钟之内。博客举了一个例子：用户问“今年夏天加州的能源用量与去年相比会怎样”，模型可以自己上网找公共事业数据、写 Python 代码做预测、生成图表或图片、再解释预测背后的关键因素，过程中还能根据搜到的信息多次调整搜索策略。博客注明，所有示例都是用 o3 完成的。

### 工具使用带来的 AIME 分数

博客正文给出了一组与工具使用直接相关的数字。o4-mini 在有 Python 解释器可用时，AIME 2025 上达到 99.5% 的 pass@1（100% 的 consensus@8）；o3 在有工具使用时，AIME 2025 上是 98.4% 的 pass@1（100% 的 consensus@8）。博客自己提醒，这些结果不应该与没有工具使用的模型的表现直接比较——它们只是“模型多有效地利用了可用工具”的一个例子。

博客还说，o4-mini 是 AIME 2024 与 2025 上表现最好的被测模型，但没有在正文里给出它在无工具条件下的 AIME 分数，也没有给出 o3-mini、o1 等前代模型在同等条件下的分数。

### 成本与性能的前沿

博客说，o3 与 o4-mini 不仅是最智能的模型，往往也比前代更高效。在 2025 年 AIME 数学竞赛上，o3 的成本–性能前沿严格优于 o1，o4-mini 的前沿也严格优于 o3-mini。博客的一般性预期是，在大多数真实世界使用中，o3 与 o4-mini 会分别比 o1 与 o3-mini 更聪明、也更便宜。

但“成本–性能前沿严格优于”这个判断的依据只在图里。博客没有在正文里给出任何成本数字——没有价格、没有每 token 成本、没有延迟数字。“通常在一分钟之内”也没有配分布或样本量。

### Codex CLI 与 100 万美元资助计划

博客同时发布了 Codex CLI：一个能在终端里运行的轻量编码智能体，直接在用户电脑上工作，设计目标是最大化 o3 与 o4-mini 这类模型的推理能力，未来还会支持 GPT-4.1 等 API 模型。用户可以把截图或低保真草图传给模型，配合本地代码使用。Codex CLI 当天开源。配套的资助计划总额 100 万美元，以每次 25,000 美元的 API 额度形式分批接受申请。

### 上线安排

ChatGPT Plus、Pro 与 Team 用户从当天起在模型选择器里看到 o3、o4-mini 与 o4-mini-high，接替 o1、o3-mini 与 o3-mini-high。Enterprise 与 Edu 用户一周后获得访问权限。免费用户可以通过在输入框选择“Think”来试用 o4-mini。各计划的速率限制与之前一组模型保持不变。o3-pro 预计几周后发布，Pro 用户暂时仍可用 o1-pro。两个模型当天也通过 Chat Completions API 与 Responses API 向开发者开放，部分开发者需要先验证组织身份。

博客发布后又加了三条更新注记：2025 年 4 月 16 日当天，o3 在 CharXiv-r 与 MathVista 上的结果因一次系统提示变更而更新；2025 年 6 月 10 日，o3-pro 已向 Pro 用户开放；2025 年 7 月 28 日，SWE-Lancer 数据集与结果按 2025 年 7 月 17 日的状态更新，修复了影响“赚得美元数”结果的问题并取消了执行期间的联网要求。

## 四、作者的结论与局限

### 作者的结论

博客的结论是：o3 与 o4-mini 是 OpenAI 迄今发布的最智能的模型，推理能力与完整工具访问的结合在学术基准与真实世界任务上都带来了显著更强的表现，树立了智能与实用性的新标准。未来的方向是把 o 系列的专业推理能力与 GPT 系列更自然的对话能力与工具使用融合起来，让未来的模型既能自然对话，又能主动用工具、解决高级问题。

### 作者自述的局限

这是一篇发布博客，作者没有列出局限。以下几点是博客正文自己承认或暗示的边界，值得原原本本记下来。

第一，带工具的 AIME 结果不能与无工具模型直接比较。博客在给出 99.5% 与 98.4% 这两个数字的同时明确提醒，比较对象不同，这个数字只能说明工具利用效率。

第二，带浏览功能的评估可能不完全可复现。脚注说，启用浏览时，模型有时会在网上找到题目的确切答案；团队用两种办法缓解：屏蔽过去观察到模型作弊的域名，以及用一个推理模型当监视器检查每次尝试的全部 token，可疑的尝试按错误计。脚注还承认，带浏览的评估结果在 OpenAI API 里可能无法完全复现，因为 ChatGPT 与 API 用的搜索引擎后端不同，搜索配置也可能随需求变化。

第三，基准图里的数字在发布后被修正过。2025 年 4 月 16 日当天的更新注记说，o3 在 CharXiv-r 与 MathVista 上的结果因一次系统提示变更而更新；7 月 28 日的更新注记说，SWE-Lancer 的结果也更新过。这说明发布当天的图里至少有三处数字后来被改过。

第四，安全结论的详细证据不在博客里。博客只给了“低于 High 阈值”和“监视器标记约 99% 对话”这两个 headline 数字，详细结果在随附的系统卡里。

## 五、精读点评

这一节是分析者的判断，和上面对博客的呈现分开写。

### 这篇博客真正要回答的问题

这篇博客真正要回答的问题不是一个科学问题，而是一个产品问题：o 系列的下一代模型是什么、强在哪、什么时候能用。它给出的答案分两层。第一层是产品事实：o3 与 o4-mini 上线、能自主用全部工具、o4-mini 便宜高效、Codex CLI 开源。这一层是扎实的，日期、价格计划、上线安排都写清楚了。第二层是能力宣称：“最智能”“新标准”“成本–性能前沿严格更优”。这一层几乎完全依赖图里的基准分数，而图里的数字在正文里核对不了——读者只能相信图，或者自己去找系统卡。

### 科学问题还原：五问

**现象是什么？** 推理模型已经能“想得更久”，但还不能“自己决定用什么工具”。反常不在于某一次实验失败，而在于推理与工具使用是两条分开的能力线：一个模型可能推理很强，却要在人的指挥下才调用工具；另一个可能工具很多，却不会推理什么时候该用。博客要解决的正是这两条线的缝合。

**为什么重要，不解决会怎样？** 对实践来说，不解决它，ChatGPT 就只能停留在“回答问题”，而不能“替用户执行任务”——搜数据、跑代码、画图、写解释这一串动作还得人一步步指挥。对领域来说，推理与工具使用的结合是智能体路线的关键一步：如果模型不能自己判断什么时候用工具，多步骤、多模态的任务就做不起来。

**为什么之前做不了？** 博客没有明说 blocker，但从它的描述里可以拼出来：难的不是“给模型接上工具”，而是“让模型学会推理什么时候用工具”——这需要把工具使用本身放进强化学习里训练，而不是在推理外面包一层固定流程。博客说两个模型正是“通过强化学习学会了用工具”，这就是它宣称移走的那块石头。但博客没有给出任何训练细节，这个宣称本身是无法核查的。

**方法与问题是否匹配？** 部分匹配。把工具使用放进强化学习、再用外部专家评估与基准图来验证，这个思路与“推理加工具”这个问题是对得上的。但博客没有提供任何证据来支撑“这个方法确实解决了这个问题”：没有消融实验、没有“只给工具不给 RL 训练”的对照、没有训练细节。读者只能看到结果宣称，看不到方法与结果之间的链条。

**答案改变了什么？** 认知上，博客没有改变任何科学认知——它没有提出新方法、没有报告新实验、没有给出可检验的发现。它改变的是产品事实：从今天起，用户可以在 ChatGPT 里用上能自主调用全部工具的推理模型。至于“推理加工具”这条路线到底走多远，博客没有给出能回答这个问题的证据。

### 价值判断

认知价值是低的。博客没有推翻或确认任何信念，没有提出可检验的主张，也没有报告任何实验设计。唯一接近认知贡献的，是“大规模强化学习在训练算力与推理时间上再推一个量级，表现仍在提升”这个观察——但它没有配任何数字，连“一个量级”的具体规模都没写，无法复核，也无法证伪。

方法价值是低的。博客没有留下任何别人能直接拿走复用的东西：没有方法、没有代码（除了 Codex CLI 这个独立的开源工具）、没有评估脚本、没有数据集。Codex CLI 本身作为一个开源终端智能体有一定的方法价值，但它是一个产品发布，不是这篇博客的方法贡献。

边界价值是中等的。博客至少在两处划了线：带工具的 AIME 结果不应该与无工具模型直接比较；带浏览的评估可能不完全可复现。脚注里对 SWE-bench 子集（477 个任务）、23 个被排除样本、256k 上下文影响的说明，也给了读者核查的抓手。但博客没有划出最重要的一条线：图里的基准分数是在什么条件下跑出来的——推理努力程度、采样次数、是否用工具，这些条件只在脚注里零星出现。

启示价值在于，最便宜的决定性下一步不是再读一遍博客，而是去读随附的系统卡：系统卡里有完整的基准表与安全评估细节。博客本身能给出的信息已经给完了，再追问它也问不出更多。

### 最弱的一环

最弱的一环在“最智能”“新标准”这些 headline 宣称与支撑它们的证据之间。整篇博客的说服力建立在三组基准图上，但图的数字只在图里，正文一个分数都没写。读者在正文里能核对的数字只有三组：外部专家评估的“少犯 20% 重大错误”、带工具的 AIME 分数（99.5% 与 98.4%）、安全监视器的“约 99%”。前两个都有明确的限定条件（专家评估的样本与方法未公开；AIME 数字不能与无工具模型比较），第三个只覆盖生物风险这一个领域。换句话说，博客最响亮的宣称，恰恰是证据最薄弱的地方。
