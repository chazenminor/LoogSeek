## 一、背景与问题

### 这次发布在 GPT-5 序列里的位置

GPT-5.4 是 GPT-5 序列在 2026 年 3 月的旗舰更新。它的前一代分了两条线：通用推理线 GPT-5.2（2025-12-11 发布）与专门做编码的 GPT-5.3-Codex（2026-02-05 发布）。GPT-5.4 的定位是把两条线合起来：一个通用前沿模型，同时具备 GPT-5.3-Codex 的编码能力，再加上三样新东西——原生电脑操作（computer use）、工具搜索（tool search）、最高 100 万 token 的上下文窗口。

OpenAI 给它起的版本号本身就是个信号。博客在“可用性与定价”一节里专门解释：GPT-5.4 是第一个把 GPT-5.3-Codex 的前沿编码能力带进主线推理模型的版本，编号跳到 5.4 是为了反映这个跳跃，也为了简化在 Codex 里选模型的难度。往后，即时模型（Instant）与思考模型（Thinking）会以不同的速度各自演进。

### 反常在哪里

这次发布真正的新东西不是某项基准分，而是一件事：通用模型第一次被当作“网络安全 High 能力”来对待。GPT-5.4 Thinking 是第一个实现网络安全 High 能力缓解措施的通用模型。在它之前，这个定级只落在专门的编码模型 GPT-5.3-Codex 头上。也就是说，OpenAI 自己的评估认为，一个通用前沿模型的网络攻击能力已经越过了需要特殊防护的门槛——这不是营销话术，它触发了整套部署防护：监控、受信任访问控制、对零数据保留（Zero Data Retention，ZDR）客户的高风险请求异步拦截。

与此同时，博客的基调与以往的旗舰发布一致：面向专业工作（professional work），强调“把真实工作做完”，而不是单项基准。知识工作、电脑操作、编码、工具使用四块内容平分了博客篇幅。

### 主要主张

按博客与系统卡的说法，这次发布立了四条主张。

第一，GPT-5.4 是 OpenAI 迄今“最有能力、最高效”的面向专业工作的前沿模型，在知识工作（GDPval 83.0%）、电脑操作（OSWorld-Verified 75.0%，超过人类基线 72.4%）、编码（SWE-Bench Pro 57.7%）上都创了新纪录。

第二，它是第一个原生支持电脑操作的通用模型：能通过截图与鼠标键盘操作电脑，也能写 Playwright 代码操作电脑；同时支持最高 100 万 token 上下文。

第三，它是 OpenAI 迄今 token 效率最高的推理模型：工具搜索（tool search）让工具密集型工作流的 token 用量大幅下降，在 250 项 MCP Atlas 任务上减少 47%，准确率不变。

第四，它的事实性是历代最好的：相对 GPT-5.2，单个主张出错的可能性低 33%，整条回答含错的可能性低 18%。

## 二、方法与设计

### 文档结构

博客按这个顺序展开：发布声明与定位 → 四项基准对照表 → 知识工作 → 电脑操作与视觉 → 编码 → 工具使用（工具搜索、智能体工具调用、改进的网络搜索）→ 可操控性（steerability）→ 安全 → 可用性与定价 → 末尾附完整的评估表。

系统卡是配套的安全评估文档，共 35 页：第 1 节引言、第 2 节模型数据与训练、第 3 节基线模型安全评估（违规内容、越狱、提示注入、视觉、健康、避免意外破坏性操作、电脑操作中的用户确认、偏见）、第 4 节思维链评估（可监测性、可控性）、第 5 节准备度框架（Preparedness Framework，能力评估与网络安全防护）、附录第 6 节讲后来发布的 GPT-5.4 mini。

### 评估是怎么做的

博客的基准分全部来自 OpenAI 自己的评估环境，脚注写明：除特别注明外，推理努力（reasoning effort）设为 xhigh；基准在研究环境中运行，与生产版 ChatGPT 的输出可能略有不同。几个关键条件写在正文里：GDPval 里 GPT-5.4 用 xhigh，GPT-5.2 用 heavy（ChatGPT 里稍低的一档）；MMMU-Pro 用 xhigh；OmniDocBench 用推理努力 none（反映低成本低延迟表现）；τ2-bench 用 none。

系统卡的评估设计更值得细看。它用了三层不同性质的材料：其一是生产基准（Production Benchmarks），故意挑难的、已有模型答得不理想的生产对话，指标是 not_unsafe（输出不违规的比例），作者明说错误率不代表平均生产流量；其二是代表性提示的生产基准试点，用去标识化的 GPT-5.2 Thinking 生产流量重采样，外推违规率；其三是准备度框架下的能力评估，明确写着“评估只是能力下限”，更好的提示、微调、更长的 rollout 或脚手架可能激发出测不到的行为。

### 按检查表，什么是“未报告”

这是一则产品发布公告加系统卡，不是研究论文，NeurIPS / Pineau 检查表里的许多项本来就不适用。但按“没报告就记下来”的规矩，以下项目在博客与系统卡里都没有：训练数据构成与规模、模型参数量、训练算力、任何消融实验、基准的运行次数与误差棒、评估的随机种子。博客引用的三家外部评价（Mercor、Harvey、Mainstay、Cursor、Zapier）都是被挑选的客户引言，不是独立评测。系统卡里 CTF、CVE-Bench、Monorepo-Bench、MLE-Bench 的具体分数只在图里，正文没有给出数字，本次精读不引用，见文末未核实清单。

## 三、主要发现

### 知识工作：GDPval 大幅领先，个别项反而退步

博客开头的对照表里，GPT-5.4 在 GDPval（胜或平）上拿到 83.0%，GPT-5.2 与 GPT-5.3-Codex 都是 70.9%。GDPval 测的是智能体完成 44 个职业、美国 GDP 贡献前九大行业的真实知识工作产品（销售演示、会计表格、急诊排班、制造图纸、短视频）的能力，胜负由与行业专业人士的对照决定。12.1 个百分点的差距是这份公告里最大的代际跃升。

但评估表里也有不利于 GPT-5.4 的数字。FinanceAgent v1.1 上 GPT-5.4 是 56.0%，低于 GPT-5.2 的 59.5%，只有 Pro 版（61.5%）超过了 GPT-5.2。Terminal-Bench 2.0 上 GPT-5.4 是 75.1%，低于 GPT-5.3-Codex 的 77.3%。长上下文 Graphwalks BFS 在 0K–128K 区间是 93.0%，还低于 GPT-5.2 的 94.0%。这些退步博客正文没有提，只出现在末尾的评估表里。

内部基准方面，投行分析师式电子表格建模任务上 GPT-5.4 平均 87.3%，GPT-5.2 是 68.4%；演示文稿评估里人类评审员 68.0% 的时间更喜欢 GPT-5.4 的演示。事实性方面，在用户标记过事实错误的去标识化提示集上，GPT-5.4 的单个主张出错可能性比 GPT-5.2 低 33%，整条回答含错的可能性低 18%。

### 电脑操作：第一次原生支持，超过人类基线

这是博客的头条能力。GPT-5.4 是第一个原生支持电脑操作的通用模型：既能写代码（例如 Playwright）操作电脑，也能直接根据截图发鼠标键盘指令。OSWorld-Verified（桌面环境导航）上 75.0%，大幅超过 GPT-5.2 的 47.3%，也超过了人类基线 72.4%。WebArena-Verified（浏览器使用）67.3%，GPT-5.2 是 65.4%；Online-Mind2Web（同样测浏览器使用）92.8%，对照的 ChatGPT Atlas 智能体模式是 70.9%。

视觉能力是电脑操作的基础。MMMU-Pro（视觉理解与推理）无工具 81.2%，GPT-5.2 是 79.5%；有工具 82.1%，GPT-5.2 是 80.4%。OmniDocBench（文档解析，平均归一化编辑距离，越低越好）0.109，GPT-5.2 是 0.140。博客还引入了一个新的图像输入细节档位 `original`，支持最高 10.24M 总像素或 6000 像素最大边；`high` 档现在支持最高 2.56M 总像素或 2048 像素最大边。

### 编码与工具使用：把 Codex 的能力收进主线

编码上，GPT-5.4 结合了 GPT-5.3-Codex 的编码能力与知识工作、电脑操作能力。SWE-Bench Pro（公开版）57.7%，GPT-5.3-Codex 是 56.8%，GPT-5.2 是 55.6%。博客说它在长任务上更能用工具迭代、把工作推进得更远，同时延迟低于 GPT-5.3-Codex。Codex 里的 /fast 模式用 GPT-5.4 时 token 速度最高快 1.5 倍，模型与智能程度不变，只是更快。

工具搜索是这次发布里技术上最有意思的一处。以前模型拿到工具时，所有工具定义都要预先塞进提示里；工具多的系统每请求要多花数千甚至数万 token。工具搜索改为只给一个轻量工具清单，模型需要时再按需查定义、追加进对话。在 Scale 的 MCP Atlas 基准 250 项任务、全部 36 个 MCP 服务器开启的条件下，工具搜索配置把总 token 用量减少 47%，准确率不变。Toolathlon（多步骤真实工具任务）上 GPT-5.4 是 54.6%，GPT-5.2 是 46.3%（见数字台账 E8 的注释：评估表里 GPT-5.2 的同一项写的是 45.7%，博客内部不一致）。BrowseComp（持续网络搜索找难定位信息）82.7%，GPT-5.2 是 65.8%；GPT-5.4 Pro 达到 89.3%，是新的最高纪录。不过博客脚注里承认：GPT-5.4 的测试日期比 GPT-5.2 晚，分数反映的是模型、搜索系统与互联网状态三者的变化，而且 GPT-5.4 用了更长、更新的搜索屏蔽列表。

### 可用性与定价

发布当天起，GPT-5.4 在 ChatGPT（称 GPT-5.4 Thinking）、API（`gpt-5.4`）与 Codex 里逐步推出；GPT-5.4 Pro 在 ChatGPT 与 API（`gpt-5.4-pro`）同步推出。ChatGPT 里 GPT-5.4 Thinking 取代 GPT-5.2 Thinking，Plus、Team、Pro 用户当天可用；GPT-5.2 Thinking 在 Legacy Models 里保留三个月，2026-06-05 退役。API 定价：gpt-5.4 输入每百万 token 2.50 美元、缓存输入 0.25 美元、输出 15 美元；gpt-5.4-pro 输入 30 美元、输出 180 美元。超过 272K 上下文的请求按 2 倍输入价、1.5 倍输出价计费。模型快照为 gpt-5.4-2026-03-05，知识截止日期 2025-08-31。

## 四、作者的结论与局限

### 系统卡的核心结论：网络安全 High，生化 High，自我改进未达 High

系统卡第 5 节是整份文件里分量最重的一节。OpenAI 把 GPT-5.4 Thinking 定为两个维度的 High 能力：生物与化学、网络安全。自我改进（AI self-improvement）则明确未达 High，理由是评估显示它没有可能达到相当于“熟练的中级研究工程师”的阈值。

网络安全的 High 定级值得展开说。准备度框架里 High 的定义是：模型消除了规模化网络行动的现有瓶颈——要么能针对相当加固的目标自动完成端到端网络行动，要么能自动发现并利用有实际意义的漏洞。OpenAI 写明，这个定级是在“不能确定模型真的具备这些能力”的情况下作出的：因为模型达到了全部金丝雀阈值（canary thresholds），不能排除它确实是 Cyber High 的可能，所以按 High 对待。这是一种预防性定级，不是能力确认。

三项网络能力评估里，Cyber Range（15 个端到端仿真网络场景）综合通过率 73.33%（11/15），低于 GPT-5.3-Codex 的 80%（12/15），但高于 GPT-5.2 Thinking 的 47%。GPT-5.4 Thinking 失败的四个场景是 CA/DNS 劫持、EDR 规避、防火墙规避、泄露 token；其中防火墙规避是相对 GPT-5.3-Codex 的退步。外部评估里，Irregular 的原子挑战套件上网络攻击模拟 88%、漏洞研究与利用 73%、规避 48%；CyScenarioBench 平均成功率 11%，解出 5/11，GPT-5.2 只解出 1 个。

生化方面，GPT-5.4 Thinking 的四项评估（多选多模态病毒学排障 50.37%、ProtocolQA 开放式 42.48%、默会知识与排障 65.00%、TroubleshootingBench 35.75%）大多高于 GPT-5.2 Thinking，但默会知识一项在计入拒绝与安全完成时达到 83.8%，超过 80% 的专家共识基线。OpenAI 仍按 High 对待，理由是谨慎，而非某一项分数单独越线。

### 思维链：能监测，且模型藏不住推理

系统卡第 4 节是这次发布里安全研究上最有新意的一节。OpenAI 引入了一个新的开源评估 CoT 可控性（CoT controllability），测模型能不能故意模糊自己的推理以逃避监测。GPT-5.4 Thinking 在 1 万字符长的思维链上只能成功控制 0.3%，GPT-5.2 Thinking 是 0.2%——可控性低是好事，说明模型缺乏隐藏推理的能力，思维链监测仍然有效。

但可监测性（monitorability）一节报告了两处退步：反图谋（Anti-Scheming）与记忆（Memory）两个环境组的监测指标下降。OpenAI 的人工复核认为，这更像是评估本身的失配（通用监测器与任务评分标准对不上），而不是模型监测性真的下降，并表示未来系统卡会先撤下这两项评估，直到修好为止。这个处理方式本身值得记下：它既是诚实的自我批评，也是把不利的测量先移出视野。

Apollo Research 的外部评估（防沙袋、反欺骗）方面：无提示条件下的总体欺骗率约 1%，与 GPT-5.3-Codex 相当、低于 GPT-5.2；没有观察到针对开发者的隐蔽颠覆实例；只有在给了明确的工具性目标时模型才会压低表现（Sandbagging QA 准确率下降 6 个百分点）；平均破坏（sabotage）得分 0.56（best-of-10 为 0.74），与 GPT-5.2 相当、低于 GPT-5.3-Codex 的 0.88；评估意识（evaluation awareness）21.3%，高于以往模型。

### 作者自述的局限

博客与系统卡各自承认的边界有四处。第一，系统卡明确写着，全部三项网络评估都有重要局限：CTF 只测预设攻击路径与孤立技能，CVE-Bench 只测 Web 应用，Cyber Range 的目标未经加固、噪声比真实网络少——三项全优是 High 的必要条件，不是充分条件。第二，BrowseComp 的分数不可直接跨代比较，因为测试日期、搜索系统与屏蔽列表都变了。第三，ZDR 客户的高风险请求拦截仍在完善中，分类器改进期间可能出现误报。第四，系统卡承认，对内部部署的失调风险（模型自我渗出、破坏内部研究）目前没有证据表明 GPT-5.4 Thinking 有这种倾向或具备所需的长程自主能力，但正在加速完善内部部署姿态。

## 五、精读点评

### 这篇材料真正要回答的问题

先把问题还原成它本来的样子。这不是一篇研究论文，没有科学问题；它回答的是一个产品问题：下一代旗舰模型凭什么取代上一代，以及凭什么值得信任。反常是：通用模型的能力已经越过了需要特殊安全对待的门槛——网络攻击能力不再是编码专用模型的专利，而是任何一个通用前沿模型自带的属性。OpenAI 的回应是把定级与防护一起发布：能力越线，就把防护也写进同一份公告。

为什么重要？对领域来说，它标志着“通用模型默认安全”这个假设的终结：从 GPT-5.4 起，旗舰通用模型发布时就要自带 High 级网络防护。对实践来说，电脑操作与工具搜索是真正改变工作流的东西——前者让智能体能直接操作真实软件，后者让大规模工具生态在经济上变得可行。基准分本身反而是最不重要的部分：它们是 OpenAI 自己跑的、没有误差棒、没有独立复核。

为什么之前做不了？卡住的点不是某一个技术，而是一组工程约束的叠加：电脑操作需要视觉、长上下文与工具调用同时够好；工具搜索需要模型学会“先查工具定义再用工具”；100 万 token 上下文需要长程推理不崩。这次发布把三件事同时做到了可用的程度，才敢把它们打包成一个旗舰版本。

答案改变了什么？认知上，它确认了“通用模型 = 高网络能力”这个新常态，往后每个通用旗舰大概都要过同一道安全门。实践上，它给出了两条可复用的工程模式：工具搜索的按需加载、电脑操作的双路径（写代码操作与直接发鼠标键盘指令）。至于基准纪录本身，改变不了什么：下个版本就会被刷新。

### 最值得怀疑的三处

第一，博客内部有一处数字不一致：开头的对照表里 GPT-5.2 的 Toolathlon 是 46.3%，末尾评估表里同一项写的是 45.7%。GPT-5.4 自己的 54.6% 两处一致，但对照值变了，差距就从 8.3 个百分点变成 8.9 个百分点。数字不大，但它说明这份公告的数字没有经过严格的交叉核对——读者没有理由假设其他表格都干净。

第二，GDPval 的 12.1 个百分点跃升看起来很大，但对照条件并不对称：GPT-5.4 用推理努力 xhigh，GPT-5.2 用 heavy（ChatGPT 里稍低的一档）。博客在脚注里写明了这一点，算不上隐瞒，但标题性的“83.0% 对 70.9%”在传播中一定会被当作同条件比较，而它不是。

第三，系统卡把两处不利的监测指标退步归因于“评估失配”，并宣布未来撤下这两项评估。这个解释可能是对的——人工复核的细节写得相当具体——但处理方式值得警惕：撤下不利的测量，而不是修好它再重新测量，等于让未来的系统卡失去了一个本可以继续追踪的信号。同样，Cyber Range 上相对 GPT-5.3-Codex 的退步（防火墙规避从通过变失败）被一句话带过，没有解释原因。

### 价值判断

认知价值：低。作为产品公告，它没有提出或回答任何科学问题；它确认的只是一个工程事实——通用模型的能力已经越过网络安全 High 的门槛。反事实是：如果没有这份公告，业界迟早也会从别处知道这一点。

方法价值：中等。它留下的可复用东西有两件：工具搜索的按需加载设计（已给出 47% 的 token 节省与不变的准确率），以及电脑操作的双路径实现。CoT 可控性作为新的开源评估，也是一件可复用的方法贡献。

边界价值：高——但这是系统卡的功劳，不是博客的。系统卡花了相当篇幅写评估的局限（CTF、CVE-Bench、Cyber Range 各自的盲区）、定级的预防性质、以及内部部署风险的未解状态。读者最容易误读的推论是“75.0% 超过人类 72.4% 所以电脑操作已经超过人类”——OSWorld-Verified 只是一个基准上的人类基线，不是“人类操作电脑的能力”本身。

启示价值：最值得看的下一步，是 GPT-5.4-Cyber（索引 #91，受限发布的网络安全专用模型）与后续系统卡里 Cyber Range 场景的通过率变化——如果防火墙规避这类场景持续失败，说明 73.33% 不是噪声，而是通用模型相对专用编码模型的结构性短板。

### 效度判断

内部效度不适用：这不是实验，没有对照组、没有随机化、没有统计推断。外部效度窄：基准分只在 OpenAI 自己的评估环境与给定的推理努力下成立，博客自己承认研究环境的输出与生产版 ChatGPT 可能略有不同。构念效度方面，“GDPval 胜率”量的是模型在 44 个职业任务上与行业专业人士的对照胜率，不是“专业工作能力”本身；“OSWorld-Verified 成功率”量的是基准任务通过率，不是真实桌面工作的成功率。可复现性低：没有公开训练细节、没有评估代码与运行条件，第三方无法重跑标题数字；系统卡的评估方法描述得相当细，但关键分数只在图里，正文不给数字，连引用都做不到。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

- 第三方用同一推理努力与同一评估 harness 复跑 GDPval，GPT-5.4 对 GPT-5.2 的领先从 12.1 个百分点大幅缩水，“知识工作大幅领先”的主张即被削弱。
- OSWorld-Verified 上换一个人类基线口径（例如不用 72.4% 这个数），“超过人类表现”的说法即不成立。
- Cyber Range 的 15 个场景里再跑一轮，GPT-5.4 Thinking 的通过率跌破 GPT-5.2-Codex 的 53.33%，“网络能力接近 GPT-5.3-Codex”的说法即被削弱。
- CoT 可控性在更长的思维链或更强的诱导指令下显著上升，“监测仍然有效”的主张即被削弱。

### 替代解释

替代解释一：GDPval 的跃升主要来自推理努力不对称（xhigh 对 heavy），而不是模型本身的进步。区分的办法是在同一推理努力下重测两代模型；博客没有给出这个对照，所以目前无法裁决。

替代解释二：Cyber Range 上相对 GPT-5.3-Codex 的退步，说明 GPT-5.4 把通用能力与编码能力合起来时，在网络攻防这个窄域上反而丢了专用模型的锐度。区分的办法是看后续系统卡里同一批场景的通过率是否回升；如果持续低于 GPT-5.3-Codex，通用化确有代价。

### 作者自述局限与分析者发现的局限

作者自述的局限：三项网络评估各有盲区且全优只是 High 的必要条件；BrowseComp 不可跨代直接比较；ZDR 拦截可能误报；内部部署失调风险未解但正在加强。

分析者发现的局限，作者没有明说的有三点。第一，博客内部 Toolathlon 对照值不一致（46.3% 对 45.7%），说明数字未经严格交叉核对。第二，博客正文只讲领先的项，FinanceAgent 与 Terminal-Bench 上的退步只出现在末尾评估表里。第三，系统卡的两个不利监测指标被归因于评估失配并宣布撤下，而不是修好重测，未来的系统卡将失去这两个追踪信号。

### 接下来看什么

排第一的是 GPT-5.4-Cyber（总索引 #91，受限发布的网络安全专用模型）：它的系统卡与评估会说明 OpenAI 打算怎么处理“通用模型 High、专用模型更 High”这个局面，以及 Cyber Range 上那四个失败场景有没有被补上。

其次看下一份系统卡里 CoT 可监测性的 Anti-Scheming 与 Memory 两项是否真的被撤下、以及撤下之后用什么替代——这会决定思维链监测这个安全支柱是被加固了还是被悄悄绕过去了。

再其次看独立第三方对 GDPval 与 OSWorld-Verified 的复核。博客的数字全部来自 OpenAI 自己的评估环境，没有误差棒、没有运行次数，第三方复跑是唯一能给这些数字定价的办法。

### 未解问题

- GPT-5.4 相对 GPT-5.2 的真实提升有多少来自模型本身、多少来自推理努力与评估条件的变化？说不清，需要同条件复测。
- Cyber Range 上防火墙规避从通过变失败的原因是什么？说不清，系统卡没有解释。
- 100 万 token 上下文在真实长任务里的可用性如何？说不清，超长区间的 Graphwalks 与 MRCR 分数都很低，且没有真实任务对照。

## I. 结论、结果与价值总览

### 一句话结论

GPT-5.4 是一次把编码、电脑操作、工具搜索与长上下文打包进通用旗舰的版本更新，基准分全面领先但全部来自 OpenAI 自报、没有独立复核；真正值得记住的是它作为第一个通用模型被定为网络安全 High 能力并配套整套防护，以及思维链监测仍然有效的证据。

### 核心结论

1. GPT-5.4 在知识工作、电脑操作与编码上全面领先 GPT-5.2，GDPval 83.0% 对 70.9%、OSWorld-Verified 75.0% 对 47.3%。置信度中。证据：数字台账 E1、E2；但全部来自 OpenAI 自报，无误差棒、无独立复核，且 GDPval 对照推理努力不对称。
2. 它是第一个原生支持电脑操作的通用模型，并支持最高 100 万 token 上下文。置信度高。证据：博客正文与 API 模型页的模型标识一致；超长区间准确率大幅下降（数字台账 E17），可用性不等于同等质量。
3. 工具搜索在 250 项 MCP Atlas 任务上减少 47% token 用量、准确率不变。置信度中。证据：数字台账 E6；内部基准，未公开任务细节。
4. GPT-5.4 Thinking 被定为生物与化学、网络安全两个维度的 High 能力，网络定级是预防性的（达到金丝雀阈值、不能排除 High 的可能）。置信度高。证据：系统卡 §5 与数字台账 E18、E21。
5. 思维链可控性低（10k 字符链上 0.3%），监测仍然有效；但可监测性在反图谋与记忆两组评估上退步，原因未定。置信度中。证据：数字台账 E19；系统卡 §4.1 的人工复核把退步归因于评估失配，未完全排除监测性真下降的可能。

### 科学价值总评

认知价值：低。没有科学问题，没有新发现；它确认的只是一个工程事实——通用模型的能力已经越过网络安全 High 的门槛。方法价值：中等。工具搜索的按需加载、电脑操作的双路径、CoT 可控性评估，都是别人能直接拿走复用的东西。边界价值：高。系统卡对评估局限与定级预防性质的交代相当坦率，这是这份材料最可信的部分。启示价值：下一步最值得看的是 GPT-5.4-Cyber 的系统卡与 Cyber Range 通过率的变化，以及第三方对 GDPval 与 OSWorld-Verified 的复核。

总体 verdict：这是一份分量真实但性质明确的产品发布材料，值得因为它标志着“通用模型默认进入 High 级网络防护”这个转折点被记住，不值得因为它标题里的基准纪录被当作能力进步的精确度量。

### 适用边界

它不证明 GPT-5.4 在真实专业工作里比行业专业人士强 83% 的时间，不证明电脑操作已经全面超过人类，不证明网络安全 High 定级等于模型确实具备端到端攻击能力。拿 GDPval 或 OSWorld 的数字为“AI 已经能替代专业工作”背书，是对这份材料的误读。
