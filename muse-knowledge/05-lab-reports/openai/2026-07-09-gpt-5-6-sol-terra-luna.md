## 一、背景与问题

### 从一个模型到一个家族

GPT-5.6 是 OpenAI 在 2026 年 6 月 26 日有限预览（limited preview）之后的全面上市（general availability）。与以往一次只发一个旗舰模型不同，这次一次发了三个档位：Sol 是旗舰，Terra 是日常工作的均衡款，Luna 是最快、最便宜的一款。帖子开篇就把命名规则讲清楚了：数字代表代际，Sol、Terra、Luna 是可以各自独立升级的能力档位（durable capability tiers），Sol 可以先升级，Terra 不必跟着变。

这个改变本身就是帖子要回答的问题：前沿智能不再只拼绝对分数，还要拼性价比。帖子的核心主张可以浓缩成一句话：GPT-5.6 Sol 在编码、知识工作、网络安全与科学这四个领域达到或接近最前沿水平，同时用的 token 更少、花的钱更少；而 Terra 和 Luna 把接近旗舰的水平带到了更低的价格上。

### 发布之前发生了什么

在全面上市之前，GPT-5.6 经历了一段有限预览期，只向受信任的合作伙伴开放 API 与 Codex。帖子说，在这段时间里 OpenAI 与外部专家组织合作做了“迄今为止最广泛的评估”，包括人工红队（red teaming）与大规模自动化测试，并据此在全面上市前加强了防护。这是帖子为安全主张铺垫的背景。

### 主要主张

帖子的主张大致有五条。

第一，Sol 是 OpenAI 迄今最好的编码模型，在 Terminal-Bench 2.1 与 DeepSWE 上创下新纪录，并在多项基准上以更少的 token、更低的成本超过上一代与竞争对手。

第二，效率是全家族的特征，不只是旗舰的特征：Terra 的表现与 GPT-5.5 相当，价格是它的一半；Luna 接近 GPT-5.5 的峰值表现，成本不到它的一半。

第三，新的推理力度（reasoning effort）档位让用户可以按任务花钱：`max` 比最高的常规档位 `xhigh` 给模型更多推理时间；`ultra` 是最高能力档位，默认协调四个智能体（agent）并行工作，以更高的 token 用量换更强的结果与更快的完成时间。

第四，GPT-5.6 是 OpenAI 迄今最强的知识工作与科学研究助手：它能把杂乱的文档与 Slack、Notion、Microsoft 365、Google Drive 里的工作流程，转化成可分享的专业成果；它在 OpenAI 内部也被用于加速 AI 研究本身。

第五，安全防护是 OpenAI 迄今最 robust（最稳固）的一套：生物与网络安全两个类别都没有越过 Critical（关键）阈值；防护是分层的，模型内训练的防护与实时检查、持续监控、账号级执行结合在一起。

### 文档结构

### 评估是怎么做的

帖子没有描述评估方法本身。它引用的是两类评估：一类是公开的第三方基准（Terminal-Bench 2.1、SWE-Bench Pro、GPQA Diamond、OSWorld 2.0、BrowseComp、ARC-AGI-3 等），另一类是 OpenAI 自己的内部评估（Agents' Last Exam、SEC-Bench Pro、ExploitBench、ExploitGym、内部研究调试评估、KernelGen、RSI Index 等）。对照组包括上一代 GPT-5.5，以及 Claude Fable 5、Claude Opus 4.8、Claude Mythos 5、Gemini 3.1 Pro Preview、Gemini 3.5 Flash 等竞争模型。表里有不少空格（用“—”表示），即某些模型在某些基准上没有分数，帖子没有解释为什么缺。

## 三、主要发现

### 三档定位与价格

三档的价格（按每百万 token 计，发布时价格）是：Sol 输入 5 美元、输出 30 美元；Terra 输入 2.50 美元、输出 15 美元；Luna 输入 1 美元、输出 6 美元。Terra 正好是 Sol 的一半，Luna 是 Sol 的五分之一。帖子还提到，GPT-5.6 引入了更可预测的提示缓存（prompt caching），包括显式缓存断点（explicit cache breakpoints）与 30 分钟最短缓存寿命；缓存写入按未缓存输入价的 1.25 倍计费，缓存读取继续享受 90% 的折扣。

需要注意的是，页面顶部有两条发布后的更新：2026 年 7 月 30 日，Luna 降价 80%、Terra 降价 20%；2026 年 8 月 21 日，Sol 的 API 与 credit 价格下调超过 20%（为期 3 个月）。这些是发布后的价格变动，不是发布时的价格，读表时不要混淆。

### 上市范围：ChatGPT Work 是重点之一

GPT-5.6 从发布当天起在 ChatGPT、Codex 与 OpenAI API 上线，全球逐步推出，24 小时内完成。分层是：Chat（普通对话）里 Plus、Pro、Business 与 Enterprise 用户在中等（medium）及以上推理力度使用 Sol，Pro 与 Enterprise 还可选 Sol Pro；ChatGPT Work 与 Codex 里，Free 与 Go 用户使用 Terra，Plus 及以上用户可以在 Sol、Terra、Luna 三档之间选择，并为每档设定推理力度。`max` 向所有能用 GPT-5.6 的 Work 与 Codex 用户开放，可在设置里开启；`ultra` 在 Work 里只向 Pro 与 Enterprise 开放，在 Codex 里向 Plus 及以上开放。

### 编码：强，但不是全线领先

Sol 是 OpenAI 迄今最好的编码模型。正文说它在 Terminal-Bench 2.1 与 DeepSWE 上创下新纪录，表里 Sol 的分数分别是 88.8% 与 72.7%。但同一张表也显示，Sol 并不是全线领先：SWE-Bench Pro 上 Sol 只有 64.6%，而 Claude Mythos 5 是 80.3%、Claude Fable 5 是 80%。帖子正文没有提 SWE-Bench Pro 这一项，读者只看正文会错过这个短板。

Artificial Analysis Coding Agent Index 上，Sol（max 档位）是 80 分，比 Fable 5 的 77.2 分高 2.8 分，同时用的输出 token 不到一半、时间不到一半、成本大约低三分之一。Terra 是 77.4 分，略高于 Fable 5；Luna 是 74.6 分，高于 Opus 4.8 的 72.5 分。

### 知识工作与长时程专业任务

Agents' Last Exam 是一项覆盖 55 个领域的长时程专业工作流评估。正文说 Sol 创下 53.6 分的新高，比 Claude Fable 5 高 13.1 分；但文末的表里 Sol 是 52.7%，Fable 5 是 40.5%，差值是 12.2 分，不是 13.1 分。数字对不上，见精读点评。

Artificial Analysis Intelligence Index 上，Sol（max 档位）是 58.9 分，Fable 5 是 59.9 分，Sol 只差 1 分，但并没有超过对手；Terra 是 55 分，Luna 是 51.2 分。GDPval-AA v2 上，Sol 是 1747.8 Elo，Fable 5 是 1759.6 Elo，对手反而略高。帖子正文没有提 GDPval 这一项。

### 计算机使用与浏览

BrowseComp 上，Sol 是 90.4%，Ultra 档位是 92.2%。正文说“Sol 在 BrowseComp 上创下 92.2% 的新纪录”，这个数字实际是 Ultra 档位的，不是 Sol 默认档位的。OSWorld 2.0 上，Sol 是 62.6%，超过 Opus 4.8 的 54.8%，同时用的输出 token 少 85%，这一项正文与表一致。

### 网络安全：提升最大的一块

网络安全是帖子里提升最明显的一块。ExploitBench 上，Sol 是 73.5%，GPT-5.5 是 47.9%，在可比的输出 token 预算下提升了 25.6 个百分点；但同一张表里 Claude Mythos 5 是 78%，比 Sol 更高，帖子正文没有提这一点。ExploitGym 上，Sol 在两小时上限内把 GPT-5.5 的峰值通过率从 15.1% 提升到 24.9%，接近翻倍；放宽到六小时，达到 33.7%。文末的表里 ExploitGym 只有 33.7% 这一行，没有标注时间上限，读者不读正文就不知道这个数字对应的是六小时条件。SEC-Bench Pro 上，Sol 是 71.2%，GPT-5.5 是 45.8%，正文与表一致。

### 科学研究与自我改进

生命科学评估上，帖子说 Sol 对 GPT-5.5 是 Pareto 改进（帕累托改进，即没有哪一项变差）。表里 GeneBench Pro 上 Sol 是 28.7%，GPT-5.5 是 12%；LifeSciBench 上 Sol 是 59.9%，GPT-5.5 是 50.4%。GPQA Diamond 上，Sol 是 94.6%，与 Claude Mythos Preview 的 94.6% 持平，Gemini 3.1 Pro Preview 是 94.3%，几家基本在同一水平。FrontierMath Tier 4（v2）上，Sol 是 83%，Fable 5 是 87.8%，Sol 落后。

自我改进（self-improvement）一组是内部评估：内部研究调试评估 Sol 68.3%、GPT-5.5 50%；KernelGen 1P Sol 61.1%、GPT-5.5 29.3%；RSI Index Sol 57.9%、GPT-5.5 41.7%。这些都是 OpenAI 自己的内部基准，没有公开的任务细节，无法独立复核。

### 内部采用：数字很大，口径不明

帖子用两组内部数字说明 GPT-5.6 在加速 OpenAI 自己的研究：在 GPT-5.6 的内部测试期，研究员平均每日输出 token 超过 GPT-5.5 时期最高水平的两倍；过去六个月，用于内部编码推理的研究算力占比增长了 100 倍，内部智能体 token 用量增长约 22 倍。帖子自己承认，这些采用指标本身并不衡量研究进展，只说明 AI 辅助在快速普及。这两组数字没有给出统计口径与时间窗口，无法复核。

### 安全：最 robust 的防护，但细节在系统卡里

帖子说，GPT-5.6 的防护是 OpenAI 迄今最稳固的一套，生物与网络安全两个类别都没有越过 Critical 阈值。在网络安全上，GPT-5.6 更擅长发现与修复漏洞，而不是可靠地对加固目标完成端到端的自主攻击。在生物上，它可以支持正当研究，但不具备创造、改造或合成高危新型威胁所需的端到端能力。

具体的防护强度数字只有一个：与之前模型相比，GPT-5.6 Sol 的网络安全防护拦截的有害活动大约多十倍。帖子同时承认，这些措施会给正当使用带来摩擦，用户可以在 ChatGPT 与 Codex 里重试低能力模型。全面上市前的安全评估包括大量人工红队、与外部专家的能力与防护测试，以及约 700,000 个 NVIDIA A100 Tensor Core GPU 等效小时的黑盒自动化红队。更详细的防护说明指向另外的 GPT-5.6 系统卡（system card），不在本帖正文里。

## 四、作者的结论与局限

### 作者的结论

帖子的结论是：GPT-5.6 是一个家族，而不是一个模型；它在保持前沿水平的同时，把智能的成本大幅打了下来；新的 `max` 与 `ultra` 档位让用户可以按任务的难度花钱；它的安全防护是 OpenAI 迄今最强的一套，经过了最广泛的上市前评估。帖子没有像研究论文那样设结论节，这些结论散落在开篇总述与各主题段落里。

### 作者自述的局限

帖子没有设“局限”一节。以下边界是它在行文里自己承认的，散落在各处。

第一，安全没有完美可言。帖子明确说“不存在完美的安全”，新的弱点与越狱方法会被不断发现，每一代新模型都会带来新的攻击面。防护的设计目标是分层、快速修复，而不是一劳永逸。

第二，防护会误伤正当使用。帖子承认，更严格的网络安全防护会给正当使用带来摩擦，并为此提供了重试低能力模型的选项。

第三，内部采用指标不衡量研究进展。帖子自己划清了这条线：研究员 token 用量与算力占比的增长，只说明 AI 辅助在普及，不能当作研究进展的证据。

第四，过度拦截本身就是安全风险。帖子指出，在网络安全上过度拦截会妨碍防御者测试系统与部署补丁，而恶意行为者会继续使用其他模型与既有工具。有效的防护要考虑请求的情境与可能的后果，而不是一味拦截。

帖子没有明说的局限，见下一节精读点评。

## 五、精读点评

### 这篇工作真正要回答的问题

先把问题还原成它本来的样子。这不是一篇研究论文，没有科学发现要报告；它要回答的是一个产品问题：当旗舰模型越来越贵、越来越难用的时候，OpenAI 能不能一次给出三个档位，让不同预算的用户都拿到接近前沿的水平，并且让用户按任务的难度决定花多少钱。反常不在于某个基准分数，而在于发布方式本身的变化：从“一个旗舰加几个缩水版”变成“一个代际、三个可以独立升级的档位”。

为什么重要？对实践来说，这改变了用户选模型的方式：以前是在“旗舰”与“便宜版”之间二选一，现在是在三个档位与两个新的推理力度档位之间组合。对行业来说，它把竞争的焦点从绝对分数拉向了性价比：帖子通篇都在强调“更少的 token、更低的成本”，而不是只强调“更高的分数”。对领域来说，`ultra` 这种默认协调四个智能体并行工作的档位，是把多智能体协作做成产品功能的一步，值得留意。

为什么之前没做？帖子没有回答这个问题。合理的推测是，三个档位需要三条训练与部署管线，以及一套能让档位独立升级的命名与版本管理，这在 GPT-5.5 之前还没有准备好。但这只是推测，帖子本身没有给出任何解释，这里记下来，不当作结论。

方法与问题是匹配的：作为产品发布帖，它用价格表、上市范围与基准表来回答产品问题，这是对的；但它没有提供任何可以独立复核评估方法的信息，这一点与研究论文的要求相去甚远，读者应当按产品公告的标准去读它，而不是按论文的标准去读它。

答案改变了什么？认知上，它确认了“性价比正在成为前沿模型竞争的主战场”，并且确认了“多智能体并行”可以作为产品档位卖给用户。实践上，它给出了一个清晰的选型表：最难的任务用 Sol，需要省钱的日常工作用 Terra，高并发、低成本的批量工作用 Luna。至于它没有改变的东西：它没有证明 Sol 在所有任务上都是最强的，表里恰恰有几项是对手领先的。

### 证据链：表很全，但正文与表对不上

这篇帖子的证据主体是文末的十张表，表本身是诚实的：对手领先的项目也照实列出来了。问题出在正文对表的转述上，至少有三处对不上。

最明显的一处是 Agents' Last Exam。正文说 Sol 创下 53.6 分的新高，比 Fable 5 高 13.1 分；表里 Sol 是 52.7%，Fable 5 是 40.5%，差值是 12.2 分。两个数字都对不上。正文还说“即使在中等推理力度下，Sol 也比 Fable 5 高 11.4 分，成本大约是四分之一”，但表里根本没有中等推理力度这一行，这个说法在表里找不到对应。

第二处是 BrowseComp。正文说 Sol 创下 92.2% 的新纪录；表里 Sol 是 90.4%，92.2% 是 Ultra 档位的分数。正文没有说明这是 Ultra 的成绩，读者会以为是 Sol 默认档位的成绩。

第三处是 ExploitGym。表里 Sol 是 33.7%，GPT-5.5 是 15.1%；正文说两小时上限内 Sol 是 24.9%，六小时才达到 33.7%。表没有标注时间上限，读者只看表会以为 33.7% 是默认条件下的成绩。

这三处有一个共同点：正文引用的都是对 Sol 最有利的那个数字，而表里对应的是另一个条件下的数字。单独看每一处，都可能是写作时的疏忽；三处放在一起，读者应当养成一个习惯：读这篇帖子时，以文末的表为准，正文的数字只作参考。

还有一个结构性的问题：表里没有任何一列说明每个分数是在什么推理力度下测得的。正文只在几处点名“max 档位”，其余分数的档位一律不明。推理力度直接影响分数与成本，一个没有注明档位的分数是无法复核的。这不是某一处数字的问题，是整套表的条件缺失。

### 价值判断

认知价值：它没有提供新的科学认知。它值得被记住的，是“三个档位可以独立升级”这个产品结构，以及“性价比正在成为前沿竞争的主战场”这个信号。反事实是：要推翻这个判断，需要证明 Terra 与 Luna 的性价比优势在独立复测中不存在——而帖子的表本身没有给出复测所需的条件，所以这个判断目前既无法证实，也无法证伪。

方法价值：它没有留下可复用的方法。十张基准表是一组数字，不是一套方法。唯一可能被复用的，是 `ultra` 这种“默认四个智能体并行”的产品设计，以及程序化工具调用（Programmatic Tool Calling）这种让模型在内存里写程序、协调工具的做法。但这两项在帖子里都只有几句话的描述，没有设计细节，别人拿不走。

边界价值：它明确不证明 Sol 在所有任务上最强。表里至少有五项是对手领先的：SWE-Bench Pro 上 Mythos 5 领先近 16 个百分点，ExploitBench 上 Mythos 5 领先 4.5 个百分点，FrontierMath Tier 4 上 Fable 5 领先 4.8 个百分点，Toolathlon 上 Fable 5 领先 3.7 个百分点，GDPval-AA v2 上 Fable 5 的 Elo 略高。读者最容易误读的推论是“Sol 全面领先”，表本身已经否定了这个推论。

启示价值：最便宜的决定性下一步，是第三方用公开的推理力度与成本口径，独立复测这十张表里的关键几项——Terminal-Bench 2.1、SWE-Bench Pro、Agents' Last Exam、BrowseComp 与 ExploitBench，公布每个分数对应的推理力度、token 用量与成本。如果复测结果与表一致，帖子的性价比主张就立住了；如果复测发现 Sol 的领先只在 max 或 ultra 档位下成立，而默认档位并不领先，那么“同样的钱办更多的事”这个主张就要打折扣。其次是看 Terra 与 Luna 的独立复测：帖子说它们“接近旗舰水平”，这个说法最容易在复测中被验证或推翻。

### 最弱的一环

全篇最薄弱的一环，是数字的条件缺失。十张表、几十个分数，没有一个注明推理力度；正文多次提到的“估计成本”没有给出计算方法；内部评估没有任务细节；内部采用指标没有统计口径。没有这些条件，表里的数字只能当作 OpenAI 的自我报告来读，不能当作可复核的测量结果。

这不是说数字是假的，而是说数字是无法独立验证的。按“产品发布帖”的标准去读，它是可信的；按“研究报告”的标准去读，它是不合格的。这篇精读把它当作前者来读，结论也只做到前者的程度。

### 效度判断

内部效度不适用。这不是一项对照实验，没有干预、没有分组、没有随机化。帖子报告的是一组基准分数，而不是一次实验的结果。

外部效度窄。结论只针对 GPT-5.6 这个家族、这些基准、发布时的价格。价格在发布后三周内就变了两次（7 月 30 日与 8 月 21 日的更新），上市范围也在逐步扩大，帖子里的价格与可用性只在发布当天是准确的。

构念效度方面，“基准分高”在这里被当作“能力强”的证据，但帖子没有讨论基准分与真实工作效果之间的关系。Agents' Last Exam 与 GDPval 这类贴近真实工作的评估，比 GPQA 这类学术基准更接近“能力”这个构念，但帖子没有区分这两类评估的权重，而是把它们并列放在一起。

统计结论效度低。没有任何一个分数附带样本量、运行次数、误差棒或置信区间；“估计成本”没有计算方法；正文与表之间还有三处数字对不上。这些数字作为方向性证据是可用的，作为精确的效应量是不可用的。

可复现性低。帖子没有公开评估 harness、提示词、推理力度设置或原始数据，第三方无法重跑表里的分数。好在复核不完全依赖复现：正文与表之间的三处不一致，只需要帖子本身就能发现，不需要任何外部材料。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

- 第三方用公开的推理力度与成本口径复测 Terminal-Bench 2.1，发现 Sol 的分数明显低于表里的 88.8%，或发现 Sol 的领先只在 max 或 ultra 档位下成立、默认档位并不领先，帖子的核心主张即被削弱。
- 复测 SWE-Bench Pro，发现 Sol 的分数与表里的 64.6% 一致、仍远低于 Mythos 5 的 80.3%，“Sol 全面领先”的推论即被否定（表本身已经否定了它，正文只是没有提）。
- 复测 Agents' Last Exam，发现 Sol 的分数是 52.7% 而不是正文说的 53.6%，正文数字的错误即被证实；发现分数是 53.6%，表里数字的错误即被证实——两者必有一处是错的。
- 独立复测 Terra 与 Luna，发现它们与 GPT-5.5 的差距远大于表里显示的水平，“接近旗舰水平、成本减半”的主张即被削弱。

### 替代解释

替代解释一：Sol 的领先主要来自更高的推理力度，而不是模型本身更强。表里没有注明每个分数的推理力度，正文点名的几个高分都明确用了 max 档位。如果 Sol 的分数是在 max 档位下测得，而对照模型的分数是在默认档位下测得，那么“Sol 更强”这个结论就混淆了模型能力与推理预算。区分的办法是固定推理力度重新测：把所有模型放在同一个档位下比较，看 Sol 的领先是否还在。帖子没有提供这样的数据，所以这个替代解释目前无法裁决。

替代解释二：帖子挑选了对 Sol 有利的基准来讲故事。SWE-Bench Pro、ExploitBench、FrontierMath Tier 4、Toolathlon、GDPval 这几项都是对手领先的，正文一概没有提，只讲了 Sol 领先的几项。表本身是完整的，正文的叙事是有选择的。区分的办法是看全表而不是只看正文——本篇正是这样做的。单看正文，读者会得到“Sol 全面领先”的印象；看完全表，这个印象就站不住了。

### 作者自述局限与分析者发现的局限

作者自述的局限：不存在完美的安全；防护会误伤正当使用；内部采用指标不衡量研究进展；过度拦截本身就是安全风险。

分析者发现的局限，作者没有明说的有三点。第一，正文与表之间至少有三处数字对不上（Agents' Last Exam、BrowseComp、ExploitGym 的时间上限），且都是向有利于 Sol 的方向偏。第二，整套表没有注明推理力度，“估计成本”没有计算方法，分数无法独立复核。第三，帖子没有提及任何一项对手领先的基准，正文的叙事是有选择的，读者必须自己读全表才能看到完整图景。

### 接下来看什么

排第一的是第三方独立复测：用公开的推理力度与成本口径，复测 Terminal-Bench 2.1、SWE-Bench Pro、Agents' Last Exam、BrowseComp 与 ExploitBench 这五项，公布每个分数对应的推理力度、token 用量与成本。如果复测与表一致，性价比主张立住；如果 Sol 的领先只在 max 或 ultra 档位下成立，主张就要打折扣。

其次是看系统卡。帖子把安全评估的细节指向了另外的 GPT-5.6 系统卡，生物与网络安全“没有越过 Critical 阈值”的具体测试分数在那里。系统卡的精读是另一篇的工作，但它是验证这篇帖子安全主张的唯一途径。

再其次是看发布后的价格变动是否持续。7 月 30 日 Luna 降价 80%、Terra 降价 20%，8 月 21 日 Sol 降价超过 20%，说明发布时的价格只维持了三周。后续的价格走势会说明“性价比”这个卖点是发布策略还是长期定位。

### 未解问题

- Agents' Last Exam 上，Sol 到底是 53.6 分还是 52.7%？说不清，需要 OpenAI 更正正文或表。
- 表里每个分数对应哪个推理力度？说不清，需要 OpenAI 公布每项的测试条件。

- 约 700,000 个 A100 GPU 等效小时是怎么换算的？说不清，需要换算方法。

## I. 结论、结果与价值总览

### 一句话结论

GPT-5.6 把一次模型发布做成了一个三档家族，核心卖点是性价比与按任务花钱的推理力度；表里的数据大体上支持这个卖点，但正文有三处数字与表对不上、整套表没有注明推理力度，所以它是一篇可信的产品发布帖，不是一份可复核的研究报告。

### 核心结论

1. GPT-5.6 分为 Sol、Terra、Luna 三档，数字代表代际，档位可以独立升级；发布时价格分别为每百万 token 输入 5 / 2.50 / 1 美元、输出 30 / 15 / 6 美元。置信度高。证据：数字台账 E16；价格在发布后三周内已变动两次。
2. Sol 在 Terminal-Bench 2.1（88.8%）与 DeepSWE（72.7%）上领先，但在 SWE-Bench Pro（64.6% 对 Mythos 5 的 80.3%）上明显落后。置信度高。证据：数字台账 E1、E2。
3. Terra 与 Luna 的表现接近 GPT-5.5，成本大约是它的一半或更低。置信度中。证据：数字台账 E5、E6；推理力度未注明，无法独立复核。
4. 网络安全是提升最大的一块：ExploitBench 上 Sol 73.5% 对 GPT-5.5 的 47.9%，SEC-Bench Pro 上 71.2% 对 45.8%。置信度中。证据：数字台账 E9、E11；ExploitBench 上 Mythos 5 的 78% 高于 Sol。
5. 正文有三处数字与文末的表对不上，且都偏向有利于 Sol 的方向；整套表没有注明推理力度，“估计成本”没有计算方法。置信度高。证据：数字台账 E4、E7、E10。
