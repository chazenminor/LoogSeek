## 一、背景与问题

### Terra 这一档是干什么的

GPT-6.1 Terra 是 GPT-6 家族里的快而便宜的一档。按帖子的说法，它结合了细致的视觉推理（detailed visual reasoning）与精确的计算机使用（precise computer use），同时写作更清晰、更自然。相对 GPT-5.6 Terra，它是一个显著的升级，擅长的是填满工作日的沟通与计算机任务——从起草提案、解读技术图纸，到填写表单、编辑视频。

这篇帖子的背景很简单：GPT-6 家族已经有了 Astra（旗舰）、Sol（中档）、Luna（最便宜），Terra 是 Sol 与 Luna 之间的那一档，定位是“高频次、定义明确、可验证的工作”。它要回答的问题是一个产品问题：能不能有一个模型，既比上一代 Terra 强得多，又便宜到可以大规模自动化处理日常工作——比如读进来的发票、把细节录入会计软件。

### 主要主张

帖子的主张大致有四条。

第一，GPT-6.1 Terra 在计算机使用、视觉推理、事实准确性与编码上都比 GPT-5.6 Terra 有大幅提升，而且往往是在更低的成本下取得的。

第二，它的价格是 GPT-5.6 Terra 与 GPT-6.1 Sol 的一半，标准 API 价格是输入每百万 token 1 美元、缓存输入 0.05 美元、输出 5 美元。

第三，它在计算机使用上甚至可以与 GPT-6 Astra 持平（Agents' Last Exam 上与 Astra 持平，价格只有 Astra 的十分之一），同时速度比 Astra 与 6.1 Sol 快三倍以上。

第四，安全上，它达到了 Preparedness Framework 下网络安全的 Critical（关键）阈值，并保持了为 GPT-6 Astra 开发的防护措施。

## 二、方法与设计

### 文档结构

这是一篇产品发布帖，不是实验报告。结构很短：开篇总述 → 计算机使用与视觉推理两项评估（Agents' Last Exam、MMMU-Pro、OSWorld 2.1）→ 事实准确性与编码两项（内部错误诱导提示基准、Terminal-Bench 4.0、Terminal-Bench-Science 0.1）→ 安全与对齐一段 → 价格与上市范围一段。全文没有方法附录，没有统计细节，没有误差棒，没有样本量。

需要特别说明的一点是：这篇帖子同样没有评估表。GPT-5.6 那篇帖子文末有十张基准表，这篇什么表都没有。所有评估数字都嵌在正文的句子里，而且几乎全是差值（比某某高几个百分点）与成本比（大约是某某的几分之一），绝对分数只出现了一个：Terminal-Bench 4.0 上的 50.3% 与 GPT-5.6 Terra 的 21.5%。

### 评估是怎么做的

帖子没有描述评估方法本身。它引用的是五项基准与一组对齐评估，外加一项内部事实准确性评估。对照组包括 GPT-5.6 Terra、GPT-6.1 Sol、GPT-6 Astra 与 Claude Opus 5.5。推理力度（reasoning effort）只在几处点名：Agents' Last Exam 是中等推理力度（medium reasoning effort），OSWorld 2.1 是中等推理力度，错误诱导提示基准分低推理力度与最大推理力度（maximum effort）两档，Terminal-Bench 4.0 与 Terminal-Bench-Science 0.1 是最大推理力度（max reasoning / max effort）。其余评估的推理力度没有说明。

按检查表，什么是“未报告”：每项评估的绝对分数（除 Terminal-Bench 4.0 上的 50.3% 与 21.5% 之外，一个都没有）；样本量、运行次数、误差棒或置信区间；“每任务成本”（cost per task）的计算方法（token 用量、推理力度如何计入成本，帖子没有定义）；“快三倍以上”是怎么测的（token 生成速度还是任务完成时间，帖子没有定义）；Agents' Last Exam、MMMU-Pro、OSWorld 2.1 的任务细节与评分方法；系统卡里的安全评估细节（帖子把细节指向了系统卡，但本篇没有去读系统卡）。

同行评审状态不适用：这不是一篇论文，没有投稿、没有评审。它的可信度取决于 OpenAI 自己公布的数字，而这些数字没有以可下载的原始数据形式公开。

## 三、主要发现

### 价格：这是帖子里最实在的一组数字

标准 API 价格是输入每百万 token 1 美元、缓存输入 0.05 美元、输出 5 美元。帖子说，这个价格比 GPT-5.6 Terra 与 GPT-6.1 Sol 的标准价低 50%。验算一下 6.1 Sol 的那一半：6.1 Sol 的标准价是输入 2 美元、输出 10 美元（见 LR-260），1 美元确实是 2 美元的一半，5 美元确实是 10 美元的一半；缓存输入 0.05 美元是 6.1 Sol 的 0.10 美元的一半，也对得上。GPT-5.6 Terra 的价格没有在这篇帖子里给出，“比 5.6 Terra 低 50%”这个说法只凭本帖没法验算，见未核实清单。

### 计算机使用：Agents' Last Exam 上“与 Astra 持平”

Agents' Last Exam 是一项专业任务基准，包括把建筑图纸变成 3D 模型、逐镜头审看一部动画电影并为修复团队制作带时间码的日志。帖子说，在中等推理力度下，GPT-6.1 Terra 比 GPT-5.6 Terra 高 15 个百分点，成本大约是三分之一；它甚至与 GPT-6 Astra 持平，而每 token 价格只有 Astra 的十分之一。在最大推理力度下，Terra 的 token 效率是 Claude Opus 5.5 的三倍以上，每 token 价格是 Opus 5.5 的四分之一，每任务成本大约低 9 倍。Terra 的速度也快得多，完成任务的速度比 GPT-6 Astra 与 GPT-6.1 Sol 快三倍以上。

这段话里有三个数字值得拆开看。第一，“高 15 个百分点”没有给出任何一方的绝对分数，读者不知道 Terra 与 5.6 Terra 各自考了多少分。第二，“与 Astra 持平”同样没有给出任何一方的绝对分数——持平在 80 分与持平在 40 分，完全是两回事。第三，“大约低 9 倍”这个说法：token 效率三倍以上、每 token 价格四分之一，两者相乘大约是 12 倍，帖子说“大约 9 倍”，比按这两个数字直接相乘算出来的要保守一些。帖子没有解释 9 倍是怎么算的——可能是因为 token 效率“超过三倍”这个说法本身就是约数，也可能是因为每任务成本里还有别的成分。无论如何，9 倍这个数字没法只凭帖子里的两个数字验算出来。

### 视觉推理：MMMU-Pro 上“接近 Astra 与 Sol”

MMMU-Pro 是一项视觉推理基准。帖子说，GPT-6.1 Terra 在每一个推理设置下都超过 GPT-5.6 Terra，甚至几乎追上最强的旗舰模型 GPT-6 Astra 与 GPT-6.1 Sol，而且成本低得多。

这一段比 Agents' Last Exam 那一段还要空：连差值都没有，只说了“超过”与“几乎追上”，没有任何一方的分数。读者只知道方向，不知道幅度。

### 桌面操作：OSWorld 2.1 上超过 5.6 Terra 的最好成绩

OSWorld 2.1 测试 AI 智能体使用桌面应用完成多步骤任务的能力，比如根据技术图纸搭建 3D 模型。帖子说，在中等推理力度下，GPT-6.1 Terra 超过了 GPT-5.6 Terra 的最好成绩，而每任务成本只是后者的一小部分。

同样的问题：没有给出任何一方的绝对分数，也没有说“最好成绩”是在哪个推理力度下测的，更没有说“只是一小部分”具体是多少。这一段的三个说法——超过、最好成绩、一小部分——全都是没有数字的定性说法。

### 事实准确性：错误率从 53.6% 降到 16.7%

OpenAI 今年在减少幻觉与事实错误上投入很大。在内部错误诱导提示基准上，低推理力度下的错误率从 GPT-5.6 Terra 的 53.6% 降到 GPT-6.1 Terra 的 16.7%，下降了近 37 个百分点。验算一下：53.6 减 16.7 等于 36.9，帖子说的“近 37 个百分点”是对的。在最大推理力度下，错误率下降了 18 个百分点，降到 4.3%，几乎追上 GPT-6 Astra 与 GPT-6.1 Sol 的水平。

这段是全篇数字最完整的一段：有绝对值、有对照、有差值，而且差值能用帖子自己的数字验算。但条件要看清：这项评估用的是“错误诱导提示”（error-inducing prompts），也就是故意挑出来容易让模型犯错的提示，不代表典型用法。帖子没有明说这一点，但“内部基准”与“错误诱导”这两个词本身就说明了它的选择性。

还有一个可以推算的细节：最大推理力度下错误率“下降了 18 个百分点，降到 4.3%”，按算术推得 GPT-5.6 Terra 在最大推理力度下的错误率是 22.3%。但这个 22.3% 是本篇按帖子数字推算出来的，不是帖子给出的数字，见未核实清单。帖子没有给出 5.6 Terra 在最大推理力度下的错误率，读者没法直接核对。

### 编码：Terminal-Bench 4.0 上 50.3% 对 21.5%

Terminal-Bench 4.0 测试编码智能体从命令行解决问题的能力，比如修复一个加载时布局会偏移的网页。在最大推理力度下，GPT-6.1 Terra 解决了 50.3% 的任务，是 GPT-5.6 Terra 公布的 21.5% 的两倍以上。帖子还说，对于最复杂的编码任务，GPT-6.1 Sol 与 GPT-6 Astra 仍然是更好的选择。

这是全篇唯一的绝对基准分数：50.3% 对 21.5%。验算一下：50.3 除以 21.5 等于 2.34，确实是两倍以上。但条件要看清：21.5% 是 GPT-5.6 Terra “公布的分数”（published score），帖子没有说这个分数是在哪个推理力度下测的。如果 21.5% 是在默认档位下测的，而 50.3% 是在最大推理力度下测的，那么“两倍以上”这个差距里有多少是模型更强、有多少只是算力更多，帖子的数据区分不了。

Terminal-Bench-Science 0.1 测试智能体用代码完成科学研究任务的能力，比如在延时视频里追踪细胞分裂。在最大推理力度下，GPT-6.1 Terra 超过了 GPT-6.1 Sol，而且成本更低；与 Opus 5.5 的差距在五分以内，估计成本不到 Opus 5.5 的五分之一。同样的问题：没有给出任何一方的绝对分数，“五分以内”与“不到五分之一”都是没有锚点的说法。

### 安全：达到 Critical 阈值，但细节在系统卡里

GPT-6.1 Terra 达到了 Preparedness Framework 下网络安全的 Critical（关键）阈值，并保持了为 GPT-6 Astra 开发的防护措施。帖子还说，Terra 带来了 GPT-6 系列的对齐改进：按 OpenAI 的评估，它比 GPT-5.6 Terra 更可能保持在任务范围内、诚实地披露局限与阻碍；在提示注入测试里，它对试图把模型从用户任务上引开的恶意指令也表现出很强的抵抗力。更多细节在系统卡里，本篇没有去读系统卡。

“达到 Critical 阈值”这个说法值得留意。在 GPT-6 Astra 的精读（LR-258）里，Astra 是第一个达到 Critical 网络安全能力阈值的模型；Terra 现在也达到了同样的阈值。帖子没有说 Terra 是在哪些评估上达到阈值的，也没有说达到阈值之后配套的防护措施具体是什么——这些细节都在系统卡里。

### 上市范围：Work 与 Codex 有，普通 Chat 暂无

GPT-6.1 Terra 从发布当天起向 ChatGPT Work 与 Codex 的 Plus、Pro、Enterprise 与 Edu 用户开放，普通 Chat 里暂未上线——与 GPT-6.1 Sol 的上市范围相同。开发者可以通过 OpenAI API 调用，模型名是 `gpt-6.1-terra`。

## 五、精读点评

### 这篇工作真正要回答的问题

先把问题还原成它本来的样子。这不是一篇研究论文，没有科学发现要报告；它要回答的是一个产品问题：GPT-6 家族里能不能有一个模型，既比上一代 Terra 强得多，又便宜到可以大规模自动化处理日常工作。反常不在于某个基准分数，而在于 Terra 这一档的定位本身：GPT-6 家族已经有了 Astra（旗舰）、Sol（中档）、Luna（最便宜），Terra 是 Sol 与 Luna 之间的那一档——它要证明的是，中档以下的价格能不能买到接近中档的能力。

为什么重要？对实践来说，这改变了高频次、定义明确、可验证的工作的选型：如果 Terra 真的在 Agents' Last Exam 上与 Astra 持平、价格只有 Astra 的十分之一，那么很多原来要调 Astra 或 Sol 的任务都可以降档到 Terra。对行业来说，它把竞争的焦点进一步从绝对分数拉向了性价比——与 6.1 Sol 那篇帖子一样，这篇通篇都在强调“二分之一”“三分之一”“十分之一”“9 倍”这些成本比。

为什么是现在？帖子没有回答这个问题。合理的推测是，GPT-6 家族的定价体系在 10 月底已经成型：Astra、Sol、Terra、Luna 四档的价格分别是输入 10、2、1、0.10 美元，Terra 是补上 Sol 与 Luna 之间那个空档的。但这只是推测，帖子本身没有给出任何解释，这里记下来，不当作结论。

方法与问题是匹配的：作为产品发布帖，它用价格与基准差值来回答产品问题，这是对的；但它没有提供任何可以独立复核评估方法的信息，这一点与研究论文的要求相去甚远，读者应当按产品公告的标准去读它，而不是按论文的标准去读它。

答案改变了什么？认知上，它确认了“性价比正在成为前沿模型竞争的主战场”，并且确认了 OpenAI 愿意用四档价格体系覆盖从旗舰到最便宜的全部场景。实践上，它给出了一个清晰的选型建议：高频次、定义明确、可验证的工作用 Terra，最复杂的编码任务还是用 Sol 或 Astra。至于它没有改变的东西：它没有证明 Terra 在任何一项基准上真正追平或超过了 Astra，帖子自己的数字也不支持这样的读法。

### 证据链：数字比 6.1 Sol 那篇完整，但锚点还是只有一个

先说能验算的部分。价格那一段是全篇最干净的：输入 1 美元、缓存输入 0.05 美元、输出 5 美元，与 6.1 Sol 的 2 美元、0.10 美元、10 美元相比，确实都是一半。事实准确性那一段也能验算：53.6% 降到 16.7%，降幅 36.9 个百分点，帖子说的“近 37 个百分点”是对的。Terminal-Bench 4.0 的 50.3% 对 21.5%，确实是两倍以上。这三处是帖子里少数几个能用它自己的数字验算的说法，而且都站得住。

问题出在验算不了的部分。Agents' Last Exam 上“高 15 个百分点”“与 Astra 持平”、MMMU-Pro 上“几乎追上 Astra 与 Sol”、OSWorld 2.1 上“超过 5.6 Terra 的最好成绩”、Terminal-Bench-Science 0.1 上“与 Opus 5.5 的差距在五分以内”——这五项里，没有一项给出 Terra 自己的绝对分数。读者只知道它比别人高多少、离别人差多少，却不知道它自己考了多少分。差值没有锚点，就没法判断这个差值是大是小。

还有一个口径问题值得点名：Agents' Last Exam 一段里的“大约低 9 倍”没法只凭帖子里的两个数字验算出来。帖子说 Terra 的 token 效率是 Opus 5.5 的三倍以上、每 token 价格是 Opus 5.5 的四分之一，两者相乘大约是 12 倍，但帖子说的是“大约 9 倍”。这个差距可能是因为“超过三倍”本身就是约数，也可能是因为每任务成本里还有别的成分，但帖子没有解释。读者如果按 12 倍去理解，就会高估 Terra 的成本优势；如果按 9 倍去理解，又不知道 9 倍是怎么算出来的。

另外两个说不清的点：21.5% 是 GPT-5.6 Terra “公布的分数”，帖子没有说这个分数是在哪个推理力度下测的——如果它是在默认档位下测的，而 50.3% 是在最大推理力度下测的，那么“两倍以上”这个差距里有多少是模型更强、有多少只是算力更多，帖子的数据区分不了；“快三倍以上”是怎么测的，帖子也没有定义——是 token 生成速度，还是任务完成时间，没有说明。

最后，标题主张的一半证据不在本帖里。“比 GPT-5.6 Terra 低 50%”这个比值需要 5.6 Terra 的标准价是输入 2 美元、输出 10 美元，但 5.6 Terra 的价格没有在这篇帖子里出现。按 6.1 Sol 的价格可以验算“比 6.1 Sol 低 50%”这一半，但“比 5.6 Terra 低 50%”这一半只凭本帖是验算不了的。这一点与 6.1 Sol 那篇帖子相同：标题主张里有一半的证据不在本帖里。

### 价值判断

认知价值：它没有提供新的科学认知。它值得被记住的，是“四档价格体系”这个信号——Astra、Sol、Terra、Luna 的价格分别是输入 10、2、1、0.10 美元，Terra 补上了 Sol 与 Luna 之间的空档——以及“性价比正在成为前沿竞争的主战场”这个方向。反事实是：要推翻这个判断，需要证明 Terra 的性价比优势在独立复测中不存在——而帖子没有给出复测所需的绝对分数与测试条件，所以这个判断目前既无法证实，也无法证伪。

方法价值：它没有留下可复用的方法。五项基准的差值与成本比是一组数字，不是一套方法。唯一可能被留意的是 Agents' Last Exam 与 OSWorld 2.1 这两项评估本身——前者测的是专业任务上的计算机使用，后者测的是桌面应用上的多步骤任务——但帖子没有给出它们的任务细节与评分方法，别人拿不走。

边界价值：它明确不证明 Terra 在所有任务上接近 Astra。帖子自己就划了一条线：最复杂的编码任务还是用 Sol 或 Astra。读者最容易误读的推论是“Terra 已经与 Astra 持平”，帖子在 Agents' Last Exam 上确实写了“与 Astra 持平”，但没有给出任何一方的分数，这个“持平”是没法核实的。

启示价值：最便宜的决定性下一步，是第三方用公开的推理力度与成本口径，独立复测这五项基准里的关键几项——Agents' Last Exam、Terminal-Bench 4.0 与 Terminal-Bench-Science 0.1，公布每个分数对应的推理力度、token 用量与每任务成本。如果复测发现 Terra 的分数确实接近 Astra，标题主张就立住了；如果复测发现“与 Astra 持平”只在最大推理力度下成立，而默认档位差得很远，那么“接近 Astra、一半价格”这个主张就要打折扣。其次是看系统卡的完整版：帖子把安全评估的细节指向了系统卡，但本篇没有去读系统卡，“达到 Critical 阈值”的具体测试分数在那里也没有给出——系统卡的精读是另一篇的工作。

### 最弱的一环

全篇最薄弱的一环，是绝对分数的缺失。五项基准、一项事实准确性评估、一项对齐评估，全篇唯一的绝对基准分数是 Terminal-Bench 4.0 上的 50.3% 对 21.5%。没有绝对分数，差值就没有锚点；没有测试条件，成本比就没法复核；没有样本量与误差棒，任何一个数字都只能当作 OpenAI 的自我报告来读。

这不是说数字是假的，而是说数字是无法独立验证的。按“产品发布帖”的标准去读，它是可信的；按“研究报告”的标准去读，它是不合格的。这篇精读把它当作前者来读，结论也只做到前者的程度。

### 效度判断

内部效度不适用。这不是一项对照实验，没有干预、没有分组、没有随机化。帖子报告的是一组基准差值，而不是一次实验的结果。

外部效度窄。结论只针对 GPT-6.1 Terra 这个模型、这五项基准、发布时的价格。价格与上市范围都可能很快变化，帖子里的价格与可用性只在发布当天是准确的。

构念效度方面，“基准分高”在这里被当作“能力强”的证据，但帖子没有讨论基准分与真实工作效果之间的关系。Agents' Last Exam 与 OSWorld 2.1 这类贴近真实工作的评估，比单纯的学术基准更接近“能力”这个构念，但帖子没有区分这两类评估的权重，而是把它们并列放在一起，而且都没有给出绝对分数。

统计结论效度低。没有任何一个分数附带样本量、运行次数、误差棒或置信区间；“每任务成本”没有计算方法；“与 Astra 持平”“几乎追上”这类说法没有任何一方的绝对分数支撑。这些数字作为方向性证据是可用的，作为精确的效应量是不可用的。

可复现性低。帖子没有公开评估 harness、提示词、推理力度设置或原始数据，第三方无法重跑帖子里的数字。好在复核不完全依赖复现：价格、事实准确性与 Terminal-Bench 4.0 这三段的算术，只需要帖子本身就能验算，而且都站得住；其余的说法验算不了，不是因为复现不了，而是因为帖子根本没有给出足够的信息。

## 七、证伪器、替代解释、接下来看什么

### 证伪器

- 第三方用公开的推理力度与成本口径复测 Agents' Last Exam，发现 Terra 的分数明显低于 Astra，或发现“与 Astra 持平”只在最大推理力度下成立、默认档位差得很远，帖子的标题主张即被削弱。
- 复测 Terminal-Bench 4.0，发现 Terra 的分数并没有达到 50.3%，或发现 5.6 Terra 在最大推理力度下的分数远高于 21.5%，“两倍以上”的说法即被削弱。
- 复测事实准确性评估，发现低推理力度下错误率并没有从 53.6% 降到 16.7%，帖子里唯一一组可验算的数字即被证伪。
- 独立复测 Terminal-Bench-Science 0.1，发现 Terra 与 Opus 5.5 的差距远大于五分，“接近 Opus 5.5”的说法即被削弱。

### 替代解释

替代解释一：Terra 的提升主要来自更高的推理力度，而不是模型本身更强。帖子在几处明确说用了最大推理力度，但对照模型 5.6 Terra 的分数——比如 Terminal-Bench 4.0 上的 21.5%——是在哪个推理力度下测的，帖子没有说。如果 21.5% 是在默认档位下测的，而 50.3% 是在最大推理力度下测的，那么“两倍以上”这个差距里有多少是模型更强、有多少只是算力更多，帖子的数据区分不了。区分的办法是固定推理力度重新测：把所有模型放在同一个档位下比较，看 Terra 的领先是否还在。帖子没有提供这样的数据，所以这个替代解释目前无法裁决。

替代解释二：帖子挑选了对 Terra 有利的说法来讲故事。五项基准里没有一项给出 Terra 自己的绝对分数，读者没法看到它在哪项上离 Astra 还差得远；Terminal-Bench 4.0 上的 50.3% 对 21.5% 是全篇唯一的绝对分数，帖子没有说 Terra 在 Agents' Last Exam、MMMU-Pro、OSWorld 2.1 上到底是多少分。单看正文的差值，读者会得到“Terra 已经与 Astra 持平”的印象；要看到完整图景，需要绝对分数，而帖子没有给。

### 作者自述局限与分析者发现的局限

作者自述的局限：最复杂的编码任务还是用 Sol 或 Astra；事实准确性评估用的是内部错误诱导提示基准，不代表典型用法。

分析者发现的局限，作者没有明说的有三点。第一，全篇没有一张评估表，五项基准里没有一项给出 Terra 自己的绝对分数，差值没有锚点。第二，“大约低 9 倍”没法只凭帖子里的两个数字验算出来，帖子没有解释 9 倍是怎么算的。第三，21.5% 是 5.6 Terra “公布的分数”，其推理力度没有给出；“快三倍以上”的测量方法没有定义，这两个说法都没法理解。

### 接下来看什么

排第一的是第三方独立复测：用公开的推理力度与成本口径，复测 Agents' Last Exam、Terminal-Bench 4.0 与 Terminal-Bench-Science 0.1 这三项，公布每个分数对应的推理力度、token 用量与每任务成本。如果复测发现 Terra 的分数确实接近 Astra，标题主张立住；如果 Terra 的领先只在最大推理力度下成立，主张就要打折扣。

其次是看系统卡的完整版。帖子把安全评估的细节指向了系统卡，但本篇没有去读系统卡，“达到 Critical 阈值”的具体测试分数在那里也没有给出。系统卡的精读是另一篇的工作，但它是验证这篇帖子安全主张的唯一途径。

再其次是看 Terra 的后续命运。GPT-6.1 Sol 发布一周之后就出了 6.1 Sol，Terra 这一档会不会也很快升级，值得在后续的精读里对照着看。

### 未解问题

## I. 结论、结果与价值总览

### 一句话结论

GPT-6.1 Terra 是 GPT-6 家族里快而便宜的一档，价格确实是 6.1 Sol 的一半，事实准确性与 Terminal-Bench 4.0 这两组数字也能验算；但全部基准分数里只有一个绝对分数，Agents' Last Exam 上“与 Astra 持平”没有给出任何一方的分数，所以它是一篇可信的产品发布帖，不是一份可复核的研究报告。

### 核心结论

1. GPT-6.1 Terra 的标准 API 价格是输入每百万 token 1 美元、缓存输入 0.05 美元、输出 5 美元，确实是 GPT-6.1 Sol 价格的一半；发布当天起向 ChatGPT Work 与 Codex 的付费用户开放，普通 Chat 里暂未上线。置信度高。证据：数字台账 E1。
2. 事实准确性上，内部错误诱导提示基准里低推理力度下的错误率从 53.6% 降到 16.7%，下降近 37 个百分点，是全篇最干净的一组数字；但只适用于错误诱导提示，不代表典型用法。置信度高。证据：数字台账 E6。
3. Terminal-Bench 4.0 上，GPT-6.1 Terra 在最大推理力度下解决 50.3% 的任务，GPT-5.6 Terra 公布的分数是 21.5%，确实是两倍以上；但 21.5% 的推理力度没有给出。置信度高。证据：数字台账 E7。
4. Agents' Last Exam 上“比 5.6 Terra 高 15 个百分点”“与 Astra 持平”、MMMU-Pro 上“几乎追上 Astra 与 Sol”、OSWorld 2.1 上“超过 5.6 Terra 的最好成绩”，这四项都没有给出 Terra 自己的绝对分数，无法独立复核。置信度低。证据：数字台账 E2、E4、E5。
5. 安全上达到 Preparedness Framework 下网络安全的 Critical 阈值，并保持为 GPT-6 Astra 开发的防护措施；但具体测试分数没有给出，细节在系统卡里。置信度中。证据：数字台账 E9。
